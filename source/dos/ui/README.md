# Графический модуль DOS

Реализации входят в DOSMOD.COM и не обращается к состоянию NC. Фиксированные входы объявлены в `source/include/mxos.inc`; резидентная таблица DOS перенаправляет вызовы в загруженный модуль. Списки объектов и тексты принадлежат вызывающей программе. Временное смещение X хранится в операнде инструкции; `uiDraw` нереентерабелен, прерывания запрещены штатным контрактом MXOS.

| Вход | Адрес | Параметры и результат |
| --- | --- | --- |
| `uiDraw` | локальный | HL — список объектов; A — смещение X в байтах экрана (0 для левой панели, 24 для правой). Разрушает AF/BC/DE/HL и флаги. |
| `uiInverseRect` | локальный | HL — экранный адрес верхнего левого угла; B — ширина в байтах, C — высота (1..255). Начало выровнено по экранному байту, размеры ненулевые. DE сохраняется; AF/BC/HL и флаги разрушаются. |
| `uiToolbar` | локальный | HL — список полей из ui.inc, B — цвет клавиш, C — цвет подписей. AF/BC/DE/HL и флаги разрушаются; координаты и инверсия BIOS сохраняются. |
| `uiCopyRect` | локальный | HL — источник, BC — назначение, D — ширина в байтах, E — высота. Выход HL/BC += исходная ширина * 256; D=0, E сохранён, AF и флаги разрушены. |

Экран имеет адрес `9000h + (X/8)*256 + Y`. Размеры ненулевые, прямоугольники полностью внутри экрана, Y+высота не больше 256. Цвет для рисования и инверсии задаёт вызывающая программа. `uiToolbar` рисует поля в Y=247..255, сразу с окончательными битмапом и цветом; предварительной очистки экрана и последующей инверсии нет. Обработка клавиш остаётся у вызывающей программы. Для монохромной сборки запись регистров цвета исключена.

`uiCopyRect` обрабатывает столбцы слева направо и вызывает штатный `bios_memcpy_bc_hl` для каждого столбца. Вертикальное перекрытие разрешено в обоих направлениях; при горизонтальном перекрытии назначение должно быть левее источника. Процедура переносит только битмап. Цветовые атрибуты не читаются и не копируются: для прокрутки область должна иметь единый неизменный атрибут. Курсор и разноцветные строки вызывающий код обслуживает отдельно.

Формат объектов задают макросы [ui.inc](../../include/ui.inc). Команда 2: окно `[2|флаги,Y,90h+X/8,высота-6,ширина/8-2]`; команда 1: горизонтальная линия `[1|флаги,Y,90h+X/8,число средних байтов,маска первого,маска последнего]`; команда 3: заполнение вертикального столбца `[3|флаги,Y,90h+X/8,высота,байт]`. Бит 7 команды делает X абсолютным, иначе прибавляется параметр A. Список завершается одним нулём. Размер окна не меньше 24×7 пикселей; горизонтальная линия имеет хотя бы один средний байт; размеры вертикального заполнения ненулевые. За корректные размеры отвечает вызывающая программа.

Проверка: `python scripts/tests/check-ui-abi.py`. Она проверяет 8080, границы прямоугольников, перекрытие, маски линий, относительные/абсолютные координаты, сохранение DE при инверсии и баланс стека. Цвет и аппаратное переключение страниц проверяются отдельно в Emu80 или на машине.

В DOSMOD версии 2 тулбар задаётся последовательностью `[ширина | флаг, текст ASCII до нуля]`, нулевой байт завершает список. Макрос `UI_TOOLBAR_FIELD W,F,TEXT` объявлен в ui.inc. W — ширина от 1 до 4 экранных байтов; F=0 выбирает B и прямой битмап, F=80h выбирает C и инверсный битмап. Текст содержит печатный ASCII 20h–7Fh и должен помещаться в поле: 6 пикселей на знак. Сумма ширин равна 48 байтам; перехода на следующую строку нет. Текст центрируется в поле и использует системный шрифт по FONT_ADDR (настройка charGen не применяется). Одна ячейка собирается в 37-байтном внеэкранном буфере; каждый байт экрана записывается один раз сразу с цветом своего поля. Все поля имеют высоту 9 пикселей независимо от длины текста. Инверсия подписей сохраняет различимость на чёрно-белом дисплее. Формат цельной строки версии 1 заменён согласованно с NC и проверкой версии загрузчиком DOS.

Проверки тулбара: `python scripts/tests/check-toolbar.py` сравнивает битмап с независимой моделью шрифта, перехватывает все 432 записи экрана и проверяет их окончательные значения и цвета при normal → Shift → normal. `python scripts/emu80/check-toolbar.py` проверяет высоту цветных полей по снимкам Emu80 и три цикла Shift с сохранением остального интерфейса.
