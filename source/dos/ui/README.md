# Графический модуль DOS

Реализации входят в DOSMOD.COM и не обращается к состоянию NC. Фиксированные входы объявлены в `source/include/mxos.inc`; резидентная таблица DOS перенаправляет вызовы в загруженный модуль. Списки объектов и тексты принадлежат вызывающей программе. Временное смещение X хранится в операнде инструкции; `bios_uiDraw` нереентерабелен, прерывания запрещены штатным контрактом MXOS.

| Вход | Адрес | Параметры и результат |
| --- | --- | --- |
| `bios_uiDraw` | C8A8h | HL — список объектов; A — смещение X в байтах экрана (0 для левой панели, 24 для правой). Разрушает AF/BC/DE/HL и флаги. |
| `bios_uiInverseRect` | C8ABh | HL — экранный адрес верхнего левого угла; B — ширина в байтах, C — высота. DE сохраняется; AF/BC/HL и флаги разрушаются. |
| `bios_uiToolbar` | C8AEh | HL — строка F1–F8 до нуля, B — цвет клавиш, C — цвет подписей. AF/BC/DE/HL и флаги разрушаются; меняет координаты BIOS. |
| `bios_uiCopyRect` | C8B1h | HL — источник, BC — назначение, D — ширина в байтах, E — высота. Выход HL/BC += исходная ширина * 256; D=0, E сохранён, AF и флаги разрушены. |

Экран имеет адрес `9000h + (X/8)*256 + Y`. Размеры ненулевые, прямоугольники полностью внутри экрана, Y+высота не больше 256. Цвет для рисования и инверсии задаёт вызывающая программа. Инверсия BIOS при вызове строки F-клавиш должна быть выключена. `bios_uiToolbar` рисует строку внизу экрана и раскрашивает восемь групп фиксированной ширины по 8 символов; очистка экрана и обработка клавиш остаются у вызывающей программы. Для монохромной сборки запись регистров цвета исключена.

`bios_uiCopyRect` обрабатывает столбцы слева направо и вызывает штатный `bios_memcpy_bc_hl` для каждого столбца. Вертикальное перекрытие разрешено в обоих направлениях; при горизонтальном перекрытии назначение должно быть левее источника. Процедура переносит только битмап. Цветовые атрибуты не читаются и не копируются: для прокрутки область должна иметь единый неизменный атрибут. Курсор и разноцветные строки вызывающий код обслуживает отдельно.

Формат объектов задают макросы [ui.inc](../../include/ui.inc). Команда 2: окно `[2|флаги,Y,90h+X/8,высота-6,ширина/8-2]`; команда 1: горизонтальная линия `[1|флаги,Y,90h+X/8,число средних байтов,маска первого,маска последнего]`; команда 3: заполнение вертикального столбца `[3|флаги,Y,90h+X/8,высота,байт]`. Бит 7 команды делает X абсолютным, иначе прибавляется параметр A. Список завершается одним нулём. Размер окна не меньше 24×7 пикселей; горизонтальная линия имеет хотя бы один средний байт; размеры вертикального заполнения ненулевые. За корректные размеры отвечает вызывающая программа.

Проверка: `python scripts/tests/check-ui-abi.py`. Она проверяет 8080, границы прямоугольников, перекрытие, маски линий, относительные/абсолютные координаты, сохранение DE при инверсии и баланс стека. Цвет и аппаратное переключение страниц проверяются отдельно в Emu80 или на машине.
