# FORMAT.COM

Команда FORMAT принимает букву диска с двоеточием и необязательные ключи -R и -Y. Например, `FORMAT A:` форматирует дискету, а `FORMAT B: -R -Y` форматирует RAM-диск. Без аргумента запрашивается буква. Подтверждение вводится строкой `Y` + Enter, Escape отменяет ввод. Ключ -Y пропускает запрос подтверждения.

Системный диск C: защищён даже с ключом -Y. Геометрия выбирается по зарегистрированному драйверу.

- Для дисковода 720 КиБ FORMAT создаёт стандартный том FAT12. Геометрия PC DD составляет 80 цилиндров, 2 стороны, 9 секторов по 512 байт на дорожку. Кластер занимает два сектора, предусмотрены две FAT и 112 записей корня. Команда работает с любой буквой, назначенной драйверу FLOPPY.COM. Для FAT12 ключ -R недопустим.
- Для 256-байтных блоков сохраняется разметка MXOS256 с 16-битной FAT и пределом 8192 секторов. Ключ -R оставляет в FAT метки BAD для служебных хвостов страниц RAM-диска.

FORMAT заново записывает загрузочный сектор, все копии FAT и корневой каталог. Дискете нужны уже размеченные физические секторы. Область данных остаётся на месте. После записи DOS перемонтирует том и выбирает корень. Единственный рабочий буфер начинается по 1000h и вмещает 512 байт. MXOS256 использует его первую половину.

Проверки на CPU 8080 находятся в `scripts/tests/check-format-args.py` и `scripts/tests/check-format-stream.py`.

Исправление скорости (04.11.2026): вместо ветвления для каждой FAT-записи
FORMAT обнуляет сектор и точечно отмечает FAT[0]/FAT[1], запас таблицы и
одну BAD-запись в подходящем секторе FAT. Алгоритм по-прежнему использует
первую половину секторного буфера и пишет только boot/FAT/root, область данных
не очищается. Через логический секторный слой DOS форматирование не идёт:
используется `MXOS_BIOS_DISK_DRIVER`, B=1.

В модели CPU 8080 с одинаковым тестовым драйвером FORMAT -R для 1 МиБ
сократился с 1 699 637 до 774 216 тактов, для 2 МиБ — с 3 256 292 до
1 421 399 тактов. Это снижение времени на 54,4% и 56,3%, а не измерение
физического носителя. Измеряется весь вызов FORMAT, включая модель записи.
Команда сравнения: `python scripts/tests/check-format-stream.py --timings`;
`--binary-dir` задаёт каталог контрольных FORMAT.i80/FORMAT.sym/DOS.sys/DOS.sym.
