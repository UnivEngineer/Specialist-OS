# Дисковод «Специалиста-МХ» в MXOS2

`C:\DRIVERS\FLOPPY.COM` регистрирует физический привод 0 контроллера ВГ93 как A:. Таблицу FAT12 обслуживает ядро DOS. В профилях MXOS для Emu80 эту команду выполняет AUTOEXEC. На машине с платой МХ её можно запустить из NC. Установка работает и при пустом приводе.

Физический формат — двусторонняя дискета DD на 720 КиБ, 80 цилиндров, 9 секторов по 512 байт на сторону. LBA 0 соответствует цилиндру 0, стороне 0, сектору 1. Сначала меняется номер сектора, затем сторона и цилиндр. Когда DOS сообщает об окончании записи, команда ВГ93 уже закончилась. Для замены носителя закройте файлы A:, вернитесь в корень A: и переключитесь на C:. Вставьте новую дискету и снова выберите A:.

В основе обмена лежит аппаратная часть драйвера Fifan. Подпрограмма выставляет номер привода, сторону и плотность, выполняет RESTORE при первом обращении и SEEK при смене дорожки. Циклы обмена используют аппаратную синхронизацию через FFF0h. Ошибки позиционирования, CRC, пропущенного байта, отсутствующего сектора или носителя и защиты записи передаются в DOS. Эмулятор моделирует регистры команд и данных, выбор привода и стороны. В модели Fdc1793 команда SEEK сразу присваивает новую дорожку, а READ/WRITE сразу выбирают сектор образа. Импульс INDEX моделируется отдельно. Измерения sequential/random показывают затраты кода MXOS в этой модели. Аппаратные задержки FFF0h и механики требуют измерения на плате. [Исходник контроллера Emu80](https://github.com/vpyk/emu80v4/blob/master/src/Fdc1793.cpp)

В DOS работает одна копия обработчика, которая принимает буфер произвольного выравнивания. Публичные RAW_IO 1 и 2 передают полный физический сектор, RAW_IO 5 выполняет запись и контрольное чтение. Межбанковый запрос использует штатный буфер DOS. Реестр защищает загруженный код дисковода в арене до конца работы DOS. Общий слот H: в MAIN и EXEC по F9C0h–FBFFh вмещает 576 байт. AT2MXF занимает 570, AT2MX — 546, ROM2M — 265. Вариант для совместной работы A: и AT2MXF требует переключать содержимое слота или выделить отдельное место для цикла передачи сектора.

`FORMAT A:` создаёт пустой том FAT12 на дискете 720 КиБ. Для штатного образа `Floppy720.img` в Windows можно открыть файлы через 7-Zip или подключить образ в ImDisk как дискету с размером сектора 512 байт.

Образ дискеты собирается целью `Floppy720`. Игры лежат в `A:\GAMES`, бенчмарки запускаются с `H:\BENCH`. Образы ODI старого MX-DOS с секторами по 1024 байта требуют другой геометрии и файловой системы.

Для сквозной проверки запустите `python scripts/emu80/check-floppy.py --port 19782` со свободным портом тестового пула. Команды вводятся через NC на временной копии дискеты. Тест сверяет скопированную игру и обе FAT, запускает DISKBEN с отдельного тестового H: в MAIN и запускает «Алмаз-2». С ключом `--caller DOS` тест выполняет DISKBEN из банка DOS с посекторной проверкой записи.
