# RAMDISK.COM

RAMDISK.COM — одноразовый установщик с флагом DRIVER, исполняемый по C000h в банке DOS. Он резервирует фиксированный пул через RAMLIMIT, монтирует готовый том либо размечает новую память через FORMAT, затем передаёт пул самой DOS через MEMORY/RAMDISK COMMIT. DLL, модульный handle и отдельный резидент не создаются; после RET область установщика доступна другим драйверам.

## Фиксированный пул

Штатный AUTOEXEC вызывает A:\DRIVERS\RAMDISK.COM -P 4. Четыре банка данных закрепляются через MEMORY/RAMLIMIT; банк DOS в эти четыре не входит. Вместе с DOS заняты пять банков из шестнадцати, одиннадцать свободны для FAR-памяти и BANK-программ. Нужны как минимум два банка: DOS и один банк данных. Режим для машины с единственным банком ДОЗУ пока не реализован.

Размер выбирается при первоначальной подготовке. Повторный запуск без -P запрашивает состояние пула через MEMORY/RAMDISK STATUS и сохраняет прежний размер; первый запуск без аргументов использует -P 4. Повторный запрос прежнего размера сохраняет данные. После COMMIT изменение размера запрещено до холодного старта. SHRINK/GROW, сжатие и динамическое перераспределение банков B: не реализуются. RAMLIMIT отказывает при чужих выделениях и при готовом томе другого размера; -P не форматирует такой том автоматически.

Физический обмен предоставляет общий транспорт MEM/CPM16. Установщик использует штатные секторные службы, а не устанавливает собственный переключатель страниц. Последний физический сектор каждого банка данных защищает хвост MEM и отмечается BAD в FAT. Банки B: исключены из DATA/EXEC-аллокатора.

## Подготовка и тёплый сброс

RAMDISK.COM монтирует B: перед передачей пула DOS. Проверка тома и буфер остаются во временной области установщика. Готовый том принимается без записи. При неподдержанной разметке boot-сектор проверяется консервативно: ошибка чтения, узнаваемый MX/FAT-заголовок, расширенная сигнатура 29h либо правдоподобный размер сектора исключают автоматическое форматирование. Это не полная проверка FAT и каталогов.

Для неразмеченной памяти вызывается A:\FORMAT.COM B: -R -Y через FILE_EXEC_NATIVE. FORMAT исполняется в main и возвращается в установщик. Режим KOI сохраняется; проверка тома восстанавливает исходный диск. FORMAT может оставить B: текущим, как при отдельном запуске.

При тёплом Reset DOS сохраняет владение фиксированным пулом и содержимое B:. Повторный AUTOEXEC заново запускает установщик: он принимает готовый том и повторно подтверждает передачу пула DOS. Поиск резидента и RESTORE/CLOSE для RAM-диска не используются. При холодной загрузке новой DOS готовый том прежнего размера принимается без переразметки. Сохранение питания и сохранность самой ДОЗУ остаются необходимыми условиями.

## Исторические варианты

Старый самостоятельный установщик main и его реализации CP/M buf16/R4 сохранены в legacy.inc, bank-install.inc, cpm.inc и r4.inc. Они относятся к системе до общего MEM; устанавливать их поверх штатного транспорта нельзя. Для исследовательской сборки задаются RAMDISK_LEGACY=1 и RAMD_USE_CPM=1 либо 0; адрес такой сборки — 0000h, флаг MAIN. В штатном образе RAMDISK_LEGACY=0, адрес C000h, флаг DRIVER. Автономные сравнимые алгоритмы доступны в COPYBEN.

## Сборка

build: ramdisk собирает RAMDISK.cpu (C000h, DRIVER); системный манифест упаковывает его в RAMDISK.COM. DLL для RAM-диска не требуется. build: OS включает установщик; после изменения содержимого образа пересоберите системный образ. Все инструкции совместимы с Intel 8080.
