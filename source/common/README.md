# Общие локальные примитивы BIOS и DOS

Эти исходники компилируются отдельно в BIOS и страницу DOS. Они не создают ещё один исполняемый модуль и не требуют межстраничного вызова для локальной памяти.

| Файлы | Назначение |
|---|---|
| cmp_hl_de.inc, math.inc | Сравнение; полный локальный комплект арифметики DOS из sdk/asm/lib/math.inc |
| memcpy_bc_hl.inc, memmove_bc_hl.inc, move8080.inc | Быстрый перенос локальной памяти |
| memset_de_20_b.inc | Заполнение памяти |
| strcmp.inc, argNext.inc | Строки и разбор аргументов |
| calcCS.inc | Контрольная сумма Монитора-2 |
| biosState.inc | Локальные данные совместимых примитивов и таблица драйверов |
| installDriver.inc | Установка обработчика в локальную таблицу |
| layoutMacros.inc | Макросы фиксированных адресов и размещения BIOS |

Программы обращаются к опубликованному ABI через [mxos.inc](../../sdk/asm/mxos.inc). Системные компоненты подключают [system.inc](system.inc) с текущим профилем и [картой памяти](system-layout.inc). Копии процедур из common/ в разных страницах имеют собственные адреса и состояние. Межстраничный memcpy_far находится в banked/.

Программы подключают sdk/asm/lib/math.inc в область кода, определив нужные MATH_SUB, MATH_DIV2, MATH_MUL и MATH_DIV. Имена можно изолировать MODULE. Реализации не используют BIOS/MXOS_CALL_REGS; BC сохраняется, остальные контракты описаны в заголовке библиотеки.
