# Общие локальные примитивы BIOS и DOS

Эти исходники компилируются отдельно в BIOS и страницу DOS. Они не создают ещё один исполняемый модуль и не требуют межстраничного вызова для локальной памяти.

| Файлы | Назначение |
|---|---|
| cmp_hl_de.inc, math.inc | Сравнение и арифметика 16-битных значений |
| memcpy_bc_hl.inc, memmove_bc_hl.inc, move8080.inc | Быстрый перенос локальной памяти |
| memset_de_20_b.inc | Заполнение памяти |
| strcmp.inc, argNext.inc | Строки и разбор аргументов |
| calcCS.inc | Контрольная сумма Монитора-2 |
| biosState.inc | Локальные данные совместимых примитивов и таблица драйверов |
| installDriver.inc | Установка обработчика в локальную таблицу |
| layoutMacros.inc | Макросы фиксированных адресов и размещения BIOS |

Программы обращаются к опубликованному ABI из source/include/mxos.inc. INCLUDE из common/ предназначен для сборки системных компонентов; копии в разных страницах имеют собственные адреса и состояние. Межстраничный memcpy_far находится в banked/ и отличается от этих NEAR-копировщиков.
