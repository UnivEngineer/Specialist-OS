# Начальный загрузчик MXOS

`SECTOR.asm` восстанавливает исторический 256-байтный `boot-system.bin` побайтно. JMP по адресу 0000h пропускает заголовок FAT12/16 с расширенным BPB: его длина 3Eh (62 байта). Это загрузочный сектор тома, а не первый сектор таблицы FAT. Оригинальный бинарный шаблон сохранён.

В линейных системных образах используется двухэтапная загрузка. Первый сектор переходит на BOOT.SYS; второй этап переносит себя в основную память по 8000h, устанавливает временный SP=8FDFh и локальным быстрым memcpy загружает DOS.SYS по C000h. Локальная memcpy находится в `memcpy.inc` и не вызывает BIOS: только прямой проход для неперекрывающихся диапазонов, с поддержкой пустого диапазона и нечётной длины. Исторический формат Mx2 64 КБ сохраняет старый загрузочный путь.

| Файл | Фиксированное смещение в ROM | Предельный конец области |
|---|---:|---:|
| BOOT.SYS | 2000h | 3000h |
| DOS.SYS, будущий BIOS | 3000h | 8000h |
| DOSMOD.COM, будущий DOS | 8000h | 10000h |

Сборщик добавляет BOOT.SYS в корневой каталог как системный файл только для линейных системных образов. Все три файла имеют обычные непрерывные FAT-цепочки; промежутки остаются свободными. Переполнение слота, конфликт с областью метаданных или недопустимый диапазон BIOS прекращает сборку. Фиксированное размещение гарантирует сборщик образа; обновление этих файлов файловыми командами не заменяет пересборку ROM.

Обычный образ пока загружает только BIOS/DOS в main. `powershell -NoProfile -File scripts/images/build-image.ps1 SystemEmuWritable -BootstrapProbe` создаёт отдельный `images/SystemRom_emu80_writable-bootprobe.bin`: дополнительно копирует DOSMOD.COM из ROM-страницы 1 в физическую RAMD0 по адресу 0000h локальным R4, по четыре байта через регистры. Копируется весь контейнер, включая 16-байтный заголовок и дополнение последнего сектора; исполнение из банка не начинается. Окно FFC0h и хвосты FF00h устанавливаются локально. Копия тестовая: дальнейшая инициализация RAM-диска может затереть её, RAMD0 не резервируется.

Проверка: `python scripts/emu80/check-bootstrap.py --report docs/banked/bootstrap-new`, для обычного образа добавить `--normal` после соответствующей сборки. Она проверяет BIOS и тестовую копию до старта DOS, затем загрузку до NC; собственный видимый эмулятор запускается без звука и закрывается после теста. Такты пересчитываются для 2 МГц. Старый `check-boot.py` предназначен для исторического одноступенчатого bootstrap.
