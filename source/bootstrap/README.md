# Начальный загрузчик MXOS

`SECTOR.asm` восстанавливает исторический 256-байтный `boot-system.bin` побайтно. JMP по адресу 0000h пропускает заголовок FAT12/16 с расширенным BPB: его длина 3Eh (62 байта). Это загрузочный сектор тома, а не первый сектор таблицы FAT. Оригинальный бинарный шаблон сохранён.

BOOTBANK.asm — штатный bootstrap банковой системы. Из линейного ROM он переносит себя по 8000h и локальным быстрым memcpy загружает BIOS.SYS в основную память по C000h, IO.SYS по F000h и весь FONTKOI.FNT подряд по FONT_ADDR=D660h. Штатный файл MXFN содержит 1328 байт: заголовок 32 байта с таблицей диапазонов, 1280 байт основных глифов и 16 байт ё/Ё в конце. Стек временно расположен под экраном, SP=8FDFh. Для этих действий файловые службы DOS не нужны.

| Файл | Фиксированный адрес в системном ROM |
|---|---:|
| BOOT.SYS | 2000h |
| BIOS.SYS | 3000h |
| FONTKOI.FNT | 5800h |
| IO.SYS | 6000h |
| MEM.SYS | 7000h |
| DOS.SYS | 8000h |

Далее bootstrap проверяет флаг готовности DOS в банке ДОЗУ 0. При холодном старте он прямо копирует DOS.SYS из ROM в этот банк по 0100h; при сохранённой готовности оставляет DOS, её кэш, драйверы и RAM-диск. Устанавливает транспорт и клиентские хвосты и передаёт управление BIOS. Каждое аппаратное Reset заново загружает BIOS, IO и шрифт. Программный возврат на C000h/C800h обрабатывается BIOS без повторного bootstrap. Старые BOOT.asm и legacy-unpacker.asm оставлены для исторических вариантов; BOOTBANK.asm задаёт текущий путь.

Размеры экспортирует scripts/build/build-bootstrap.py; физические слоты гарантирует scripts/images/build-image.ps1. Переполнение слота, конфликт с метаданными или недопустимый диапазон прекращает сборку. Обновление этих файлов обычными файловыми командами не заменяет пересборку ROM. Bootstrap включает точный установочный образ MEM.SYS и использует его сегменты; отдельный MEM.SYS также помещается в фиксированный слот системного диска.

Проверка: python scripts/emu80/check-bootstrap.py --report docs/banked/bootstrap-new. Она проверяет холодный старт, Reset с сохранением DOS и B:, восстановление шрифта и возвраты в NC/CLI. Эмулятор запускается видимым, без звука и закрывается после проверки. Старые измерения bootprobe относятся к этапу подготовки переноса и не описывают штатную загрузку.

## Межбанковый транспорт

Общий код вынесен в [source/mem](../mem/README.md), собираемый в MEM.SYS. Bootstrap устанавливает полный профиль в main и DOS и минимальный копировщик в банки данных. Протокол и кадры возврата описаны в [transport.md](../mem/transport.md). IO.SYS остаётся отдельным непрерывным образом основной памяти. Слоты физических драйверов заполняются их инициализаторами.
