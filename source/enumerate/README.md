# ENUM.DLL

Общий загружаемый перечислитель для DIR, COPY/MOVE с маской и прикладных программ. DOS лениво загружает `A:\ENUM.DLL` в нижнюю арену с `DOS_SERVICE_ADDR`; FILEOPS.DLL располагается отдельно с C000h. Активное перечисление и копирование могут сосуществовать: COPY получает очередной путь от ENUM, вызывает FILEOPS и продолжает тот же курсор. Непересекающиеся DLL не вытесняют друг друга. Приложение использует публичный ABI DOS и не знает адресов модуля.

В ядре остаются базовый FAT-обход каталога, точный поиск имени, парсер и диспетчер команд, потоковый BAT и файловые примитивы. Маски и состояние рекурсивного обхода находятся в ENUM, рекурсивное копирование — в FILEOPS. COMMAND.DLL не используется. CLI.COM остаётся интерфейсом ввода в MAIN; панели NC используют структурированный FILEOPS без командного парсера. Прежний API списка NC сохранён; подключение нового перечислителя к панелям — отдельная задача.

## Контракт

`MXOS_CALL MXOS_DOS_ENUMERATE` (022Ch): A=ENUM_OPEN/NEXT/CLOSE, HL=ENUM_REQUEST в банке вызывающего. CF=1/A=код DOS означает ошибку; пакет и выходной буфер — NEAR-адреса в том же банке. C SDK: `mxos_enumerate(operation, &request)`.

| Смещение | Поле | Размер |
|---:|---|---:|
| 0 | handle | 2 |
| 2 | path: указатель на ASCIIZ, читаемый буфер MAX_PATH=128 байт | 2 |
| 4 | buffer: массив ENUM_ENTRY в банке вызывающего | 2 |
| 6 | capacity: вместимость массива в записях, 1..255 | 2 |
| 8 | count: число выданных записей | 2 |
| 10 | flags | 1 |
| 11 | state: 0 продолжение, 1 конец | 1 |

OPEN=0 принимает path и flags, возвращает непрозрачный handle и обнуляет count/state. NEXT=1 заполняет до capacity записей; каждая запись занимает 160 байт: исходный 32-байтный FAT-дескриптор и полный ASCIIZ-путь в поле 128 байт. Путь завершается NUL; остаток 128-байтного поля не определён. При ошибке NEXT поле count сохраняет число уже выданных в этой пачке записей. После конца повторный NEXT возвращает count=0/state=1. CLOSE=2 обязателен после конца или ошибки, освобождает закрепление и обнуляет handle. Исходный текст пути можно менять после успешного OPEN.

Флаг ENUM_RECURSIVE=1 включает обход в глубину; ENUM_CHECK_CANCEL=2 разрешает Escape/Ctrl+C через штатный опрос клавиатуры. При отмене возвращается DOS_ERR_CANCELLED, после неё также требуется CLOSE. Один вызов внутреннего NEXT ограничивает поиск 64 шагами обхода; если совпадений пока нет, публичный NEXT может вернуть count=0/state=0. Это продолжение, а не конец: вызывающий получает возможность обработать ввод между вызовами. Пачка может завершиться раньше capacity. Это ограничение шагов, а не гарантия времени драйвера.

Текущая версия поддерживает один активный курсор, глубину до 32 каталогов и пути MAX_PATH. Между вызовами сохраняются все CWD вызывающего и независимый FAT-курсор; другие файловые обращения не сбивают обход. Владелец и поколение handle проверяются, завершение владельца или Reset закрывают старый курсор. Код остаётся кэшированным до реального пересечения с другой DLL; активный код не вытесняется. Сортировка и снимок неизменного дерева не создаются. Не изменяйте ещё не перечисленные части дерева во время обхода; COPY/MOVE могут обработать уже выданный элемент.

Маски `*` и `?` применяются к последнему компоненту имени без учёта регистра, `*.*` включает имена без расширения. `?` означает ровно один символ. Каталог без маски означает все его элементы; `B:` использует сохранённый CWD этого диска. Метки тома, LFN, удалённые записи, `.` и `..` не выдаются. В рекурсивном режиме во все подкаталоги входят независимо от совпадения имени каталога с маской; маска фильтрует выдачу. Маски в промежуточных компонентах пути пока не поддерживаются. Для дерева используйте ENUM_RECURSIVE, в DIR — `DIR B:\ROOT\*.TXT -S`.

## Команды и сборка

DIR печатает обычную таблицу для одного каталога, при `-S` — полные пути совпадений. COPY/MOVE с маской источника требуют существующий каталог назначения; маски переименования назначения пока не поддерживаются. DEL/ERASE принимают файл или пустой каталог; рекурсивное удаление не реализовано.

Сборка OS вызывает `scripts/build/build-overlays.py` после линковки DOS. `host.inc` и генерируемый `bin/enumerate-imports.inc` — проверяемый внутренний контракт совместной сборки, не публичные адреса. Сам модуль компилируется под Intel 8080, не содержит кода файловых драйверов и не меняет формат накопителей.

MKDIR/MD создаёт недостающих родителей: `MKDIR Games/Almaz-2/MXOS`. Уже существующие каталоги допускаются, файл в любом компоненте вызывает отказ. F7 NC использует тот же обработчик FILEOPS. При частичной ошибке уже созданные родители сохраняются.
