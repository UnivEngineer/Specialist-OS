# EXE.COM

Утилита для «Специалиста»: преобразует RKS, RAW и родные контейнеры в COM/EXE/DLL/FNT v2 либо RKS и меняет метаданные заголовка. Исходный файл всегда сохраняется; выходной путь должен отличаться. Совпадение файлов проверяется и для относительных/абсолютных псевдонимов. При существующем выходном файле запрашивается подтверждение; `-Y` отключает вопрос.

```
EXE H:\ALMAZ.RKS B:\ALMAZ.EXE -MODE:STD
EXE H:\GAME.RKS B:\GAME.EXE -F:MAIN -B:0400 -BEGIN:0000
EXE B:\GAME.EXE B:\GAME1.EXE -P:PRESERVE -END:7000
```

Все числа шестнадцатеричные. Разделитель значения — `:` или `=`. Ключи: `-F:MAIN|BANK|DOS|LEGACY`, `-B:BSS`, `-L:load`, `-E:entry`, `-BEGIN:start`, `-END:exclusiveEnd`, `-HEAP:minBytes`, `-STACK:bytes`, `-P:EXCLUSIVE|PRESERVE|MANAGED`, `-MODE:AUTO|MX|STD|MON|RF`, `-CACHE:0|1`, `-RAW`, `-Y`. `-RAW` явно запрещает распознавание исходного контейнера.

Размер BSS неизвестного классического образа равен FFFFh и требует EXCLUSIVE. Для подтверждённого MAIN/BANK/DOS задайте известный BSS, например `-B:0`. BSS и остальные рабочие диапазоны резервируются, но DOS их не обнуляет. Загрузка всегда остаётся по фиксированному адресу: изменение `-L` не переносит абсолютные адреса внутри машинного кода.

MODE задаёт среду RUN, если при запуске не указан явный ключ. Для COM/EXE с назначенным монитором EXE сохраняет имя и его контрольную сумму при преобразовании в COM/EXE. Явный `-MODE` с другим значением снимает назначение. В RKS отсутствует поле имени, загрузчики DLL/FNT отклоняют такой хвост. Для классической программы используйте `-F:LEGACY`. BAT позволяет закрепить ключ режима и аргументы, выбрать нестандартный монитор или выполнить несколько команд. Расширение DLL/FNT использует тот же 32-байтный контейнер. Назначение файла задаёт его загрузчик.

Исходный контейнер и сумма тела проверяются до открытия назначения на запись. Для изученных исторических файлов допускается импорт 16-байтного заголовка v1; штатные загрузчики ОС принимают только v2. RAW не имеет исходной контрольной суммы. Ошибка записи оставляет незавершённый выходной файл с явным сообщением; исходник не меняется. RKS не хранит новые метаданные и требует entry=load.

Штатный `A:\EXE.COM` собирается из `EXE.asm` в составе `scripts/build/build-project.ps1 OS`. Утилита работает в MAIN и использует FILEHANDLE DOS и контрольную сумму Monitor-2 из BIOS. Артефакты сборки — `bin/EXE.i80` и `bin/EXE.cpu`.

Для сравнения соберите `EXE.c` командой `python scripts/build/build-exe-c.py`. Сценарий z88dk создаёт отдельные `bin/EXE_C.i80` и `bin/EXE_C.cpu`.
