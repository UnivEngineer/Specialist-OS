# Основной системный диск A:.
# Метка тома (1–11 символов ASCII).
@label SYSTEM

# Формат строки: имя_на_диске источник [адрес_RAW [атрибуты]].
# Имя на диске — FAT 8.3; пути к источникам отсчитываются от assets/.
# ../bin/ — результаты сборки; {AUTOEXEC} — вариант AUTOEXEC для выбранного образа.
#
# Источники:
#   CPU + соседний I80: CPU содержит адреса загрузки и входа (два hex-числа ASCII), I80 — код.
#   CPU без I80: сырой код, загрузка и вход 0000h.
#   RKS: адреса и нагрузка из стандартного контейнера; сумма проверяется.
#   COM/EXE MXOS2: адреса и нагрузка из 16-байтного заголовка; суммы проверяются.
#   BIN/I80/старый сырой COM/EXE: код без заголовка; адрес загрузки и входа задаёт адрес_RAW (0 по умолчанию).
#
# Целевой формат задаёт расширение имени в первом столбце:
#   COM/EXE/DLL: общий контейнер MXOS2 — заголовок 16 байт (загрузка, вход, размер, суммы) + нагрузка.
#   COM/EXE с MAIN/DOS/BANK исполняет DOS; без флага среду выбирает RUN через CLI.EXT.
#   RKS: заголовок 4 байта + нагрузка + сумма 2 байта; через CLI.EXT запускается RUN, по умолчанию -MON.
#   При RKS -> COM/EXE заголовок и сумма RKS заменяются контейнером MXOS2; результат не является RAW.
#   При преобразовании в RKS адрес входа должен совпадать с адресом загрузки.
#   SYS/MON и остальные целевые расширения: побайтовая копия; SYS — DOS, MON — сырой образ сменного ядра.
#
# Адреса CPU/I80, RKS и COM/EXE берутся из источника, а не из адрес_RAW; в FAT адрес не записывается.
# Для DOS.SYS адрес_RAW используется загрузчиком. Для источника RKS столбцы адреса и атрибутов запрещены.
# Атрибуты: R — read-only, S — системный, RS — оба; без атрибутов — 0. Для пропуска адреса перед ними пишется 0.
# Порядок строк задаёт порядок файлов; в больших системных образах загрузочные записи идут первыми.
