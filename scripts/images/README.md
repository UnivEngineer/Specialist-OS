# Сборка образов

`build-image.ps1` собирает системный ROM и flash-образы.

Системный состав задаётся упорядоченным CSV-манифестом `manifests/system.csv`:

- `Source` — путь к физическому файлу относительно корня репозитория;
- `ImageName` — имя файла в FAT-каталоге образа;
- `LoadAddress` — адрес загрузки, десятичный либо с префиксом `0x`;
- `Format` — `raw` или `rks`.

Для `rks` адрес и длина полезной нагрузки читаются из заголовка файла.
Специальный источник `{AUTOEXEC}` заменяется на эмуляторный или аппаратный
AUTOEXEC в зависимости от цели сборки.

Flash-манифесты содержат имена файлов из `assets/games`. Порядок строк
определяет порядок каталогов и кластеров, поэтому изменять его без причины не
следует.
