# Инверсное выделение без снятия при вводе

Выделение остаётся битовой инверсией 10×10 байт экрана через существующий bios_uiInverseRect. Оно не зависит только от цветовых атрибутов и сохраняет видимость на чёрно-белом дисплее. ABI DOS не менялся.

Основной цикл классифицирует клавишу до снятия курсора. Ввод текста, Backspace, Escape, Ctrl+Enter и игнорируемые клавиши возвращаются сразу в ожидание ввода с прежним выделением. Перемещения и файловые действия используют обычный путь.

При Down за нижний край или Up за верхний край старое выделение остаётся на том же месте экрана. Строка с ним исключается из копируемого источника: вперёд сокращается последний перенос правой колонки; назад последний перенос левой колонки начинается со второй строки. Соседняя строка восстанавливается обычным текстом; новый выбранный файл печатается сразу инверсным поверх прежнего курсора. Печатаются два имени, копируется по 3400 байт чтения/записи экрана вместо 3500; обе полные инверсии старого и нового курсора исключены. Шаги больше одного файла используют прежний путь с ранним рисованием нового курсора.

CPU 8080: scripts/tests/check-nc-cursor.py, 11 сценариев для каждого из четырёх вариантов NC/NC-full/NC-text/NC-full-text. Ввод не вызывает инверсию и не меняет пиксели панели. Однострочный битмап-шаг вызывает ноль инверсий; итог совпадает с полной печатью и битовой инверсией. Текстовая опция сохраняет две инверсии при шаге и тот же результат. Все варианты собрались без ошибок и предупреждений.

Собственный видимый Emu80qt-mcp.exe, профиль Flash 512 КБ: штатные клавиши Down/Up на границе панели не достигают drawCursor и bios_fileList. RGB после обоих направлений совпадает с полной перерисовкой через меню. При вводе A/B, непустом Backspace и Escape drawCursor не вызывается, RGB панели не меняется. Результаты emulator.json, снимки down.png/up.png/typing-complete.png. Экземпляр закрыт после проверки. На физическом мониторе мерцание не измерялось.

Проверки кэша, UI ABI, размещения DOS и образа прошли; DOS 7092 байта, конец DBB4h, 83 объявления ABI, наложений нет; образ содержит 22 файла по манифесту. Другой агент параллельно добавил bios_argNext C8B7h; его код и JMP сохранены.

NC.i80 — 4332 байта, переменные 93 байта. Кэши 8162 байта: 1149h–2139h и 213Ah–312Ah. Выравнивание 213 байт, буфер копирования/ассоциаций 3200h–8EFFh — 23808 байт, 93 сектора. Всего резервируется 36608 байт (35,75 КиБ), как и до изменения курсора; дополнительные 203 байта бинарника и один байт переменных уменьшили буфер на один сектор из-за выравнивания. Общая строка DOS DC00h, 130 байт, в этот объём не входит.
