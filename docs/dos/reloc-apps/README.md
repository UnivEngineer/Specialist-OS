# Проверка релоцируемых прикладных DLL, 25 ноября 2026

В Emu80 на исходном MX с одним банком и ПЗУ 48 КиБ `NC_MN.COM` открыл `EDIT_MN.COM`. Редактор прочитал 73 байта `A:/AUTOEXEC.BAT`, принял символ `x` и вернулся в NC после отмены сохранения. В CLI выполнены `PWD` и `EXIT`. Из корня A запущен `RELTEST.COM`, который загрузил и вызвал две MAIN DLL и оставил сигнатуру `AA 55`. Запуск `A:/DOS/NC.COM` вернул `MEM_ERROR_NOMEM` с CF=1. [Протокол MX](mx-ui.json), [контрольная сигнатура](mx-reltest.png), [отказ при исчерпании банков](mx-bank-exhaustion.png).

В MMX штатный NC занял EXEC 6 и загрузил UI_GFX по адресу 767Fh. Банковый EDIT на EXEC 7 открыл 169 байт `C:/AUTOEXEC.BAT`, принял `x` и после отмены сохранения вернулся в NC на EXEC 6. Команды `PWD` и `C:/DOS/NC_MN.COM` вводились с клавиатуры. В MAIN `EDIT_MN.COM` прошёл тот же сценарий изменения и возврата. [Протокол MMX](mmx-ui.json).

После перевода обоих DOS-установщиков в v3 тот же сценарий MMX прошёл повторно. Дополнительно из MAIN с клавиатуры выполнена команда `C:/DOS/NC.COM`, затем из банкового NC — `C:/DOS/EDIT.COM C:/AUTOEXEC.BAT`. Перед каждым переходом DOS в установщик стенд прочитал его фактическую базу из HL и побайтно сравнил всю загруженную копию с применением таблицы WORD16 из штатного COM. Совпали 264 байта NC по C8D0h и 206 байт EDIT по C90Ah. NC дошёл до опроса клавиатуры на EXEC 6, EDIT — на EXEC 7. [Протокол загрузчиков](mmx-v3-launchers.json), [экран редактора](mmx-v3-launchers.png).

Команда `H:/BENCH/FONTBEN/FONTBEN.COM -K -N -Q` из NC прошла все 18 этапов и вернулась в NC. Для каждого из пяти текстовых API сравнивались 48 столбцов по 240 строк экрана с соответствующим MAIN-маршрутом. Во всех банковых маршрутах видимые байты экрана совпали. [Порядок этапов и замеры таймера ВИ53](font.json).

## Стоимость FontBank.dll

Тело занимает 528 байт, BSS — 1165 байт, таблица из 69 поправок HIGH8 — 138 байт, заголовок — 40 байт. Файл занимает 706 байт. Стенд прочитал таблицу модулей после загрузки, подтвердил EXEC 7, базу E700h, частный диапазон 1693 байта и 99 байт между концом диапазона и стеком EXEC. Такты 8080 считались от инструкции CALL системного шлюза до следующей инструкции FontBen. Интервал `MODULE_CALL` включает вывод 924 байт корпуса. После каждого маршрута DLL выгружалась.
