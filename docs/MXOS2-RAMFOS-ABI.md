# Карта вызовов: загрузчик, Monitor-2, MXOS, MXOS2, RAMFOS и адаптер

Актуально на 25.10.2026. Это текстовый аналог исторической
[`MXOS & RAMFOS.xlsx`](MXOS%20%26%20RAMFOS.xlsx), предназначенный для VS Code
и агентов. Историческая книга не изменяется.

В таблицах рядом приведены разные ABI, а не предполагаемое соответствие имён.
«Новый адаптер» означает текущий загружаемый `RAMFOS.SYS` с `MXOS_KERNEL=1`.
Это первый этап: он сохраняет ABI RAMFOS, но файловая система RAMFOS ещё не
заменена модулем MXOS2.

Статусы: **есть** — вызов работает; **заглушка** — определённая отмена или
ошибка; **будет** — целевой адаптер ещё не реализован. Все адреса — hex.

## 2. C800h: исходная MXOS, MXOS2 и BIOS RAMFOS

У исходной MXOS и MXOS2 по C800h обычно сохраняется роль точки. У RAMFOS C800h
находится другой BIOS: он служит целью переходов его F800h. Совпадение адреса
между MXOS и RAMFOS само по себе ничего не гарантирует.

## 3. F800h: Monitor-2, оригинальный RAMFOS и новый адаптер

Здесь находятся вызовы программ RAMFOS. В новом ядре адреса и контракты
оригинала сохранены. Файловые операции пока не переадресуются в MXOS2: они
возвращают определённый ответ, чтобы FAT не трактовалась как ФС RAMFOS.

|---:|---|---|---|---|

## 4. Прямые правила реализации адаптера

| Задача | Текущее состояние | Требуемый результат |
|---|---|---|
| Память RAMFOS | `RAM_TOP=8FFFh`, но таблицы страниц нет | Выделить 1–2 страницы, закрыть страницы MXOS и flash. |
| Файловая система RAMFOS | Все дисковые вызовы F800h запрещены | Драйвер тома MXOS2 реализует родной каталог/данные RAMFOS, не FAT-эмуляцию. |
| Диалоги RAMFOS | F824h/F827h отменяются | Сохранить интерфейс и использовать нативный том для списка, загрузки, сохранения. |
| Поток DOS | C88Dh передаёт FAT-кластеры | Добавить `open/read/write/close/abort` с 32-битной длиной; перевести F5. |
| FORMAT | Работает с нынешней FAT-подобной ФС напрямую | Определять тип тома и запретить форматирование RAMFOS из FORMAT. |
| Возврат в MXOS2 | Полная перезагрузка через FFC0h | Вновь загрузить и зарегистрировать внешние драйверы/модули. |
| Стандартная FAT16 | Не реализована | Отдельный режим с логическими секторами 512 байт, BPB, EOC, пустыми файлами, точной длиной. |
