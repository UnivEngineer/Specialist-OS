В текущем горячем Build all первая строка появилась на отметке 0,192–0,204 с от старта PowerShell. В одном из прогонов отметки этапов были такими: проверка Almaz и Almaz-2 завершилась к 0,558 с, Font engines — к 0,796 с, группа компонентов — примерно к 2,36 с. Дальше началась подготовка профилей: MMX в 2,359 с, MX в 3,360 с, RAMFOS в 4,387 с. Скрипт закончил работу примерно за 4,57 с. На всех горячих прогонах число вызовов SjASMPlus было нулевым.

Старый Build all заканчивается после игр и компонентов и использует одну проверку для ОС. Текущий выполняет проверки отдельных компонентов по INCLUDE/INCBIN и содержимому входов, часть из них параллельно. После компонентов Build all готовит девять целей образов для MMX, MX и RAMFOS, включая варианты системного ROM и дискет. Проверки игр, реестра вызовов и шрифтов идут до группы параллельных целей.

На G: отдельно выполнены три проверки записи кэша Font engines без запуска сборщиков и изменения файлов. Входы и 155 выходов совпали во всех прогонах. Проверка заняла 0,578 с с первой выборкой файлов и 0,115/0,109 с в повторах. В этот замер не входят загрузка PowerShell, остальные цели и ожидание блокировки.

С исходным H-ROM-64k-Games.txt прогретый Build all дошёл до ошибки за 5,319 с без вызовов ассемблера. Проверена последовательность `[up-to-date] image: MxRom48`, `[build] image: Games64k` и ошибка Games64k с именем манифеста и строкой 32. LodeRun.rks требовал 118 кластеров при 77 свободных, размер кластера 256 байт. При повторной отдельной попытке существующий ROM сохранился побайтно.
