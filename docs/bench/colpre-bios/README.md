# COLPRE в BIOS, 2026.11.11

Emu80 4.0.575, Intel 8080 2 МГц, локальный ВИ53 2 МГц. Штатный BIOS без подмены. Корпус 1152 байта: 24 блока по 46 печатных байтов README и CRLF. printChar рисует 1104 глифа и обрабатывает CRLF; Raw печатает все 1152 кодов. Сравниваются одинаковые API/корпуса. MAIN вызывает BIOS ABI, BANK использует штатный MXCALL; его накладные расходы и перенос текста входят в замер. Подготовка, файловая загрузка, выделение памяти и отчёт не измеряются.

## Изменение скалярного ядра

COLPRE заменил scalarPre для действующего пререндера 6×8. Данные и генератор остались прежними: пять плоскостей 10 КиБ и исходная несдвинутая фаза непосредственно в FONT_ADDR. Полные четвёрки используют прежние пакетные ядра; посимвольный вывод, короткие строки и невыровненные головы/хвосты используют COLPRE. При отключении/инвалидировании таблицы и при альтернативном линейном шрифте сохраняются вращения.

Прежний двухколоночный цикл чередовал столбцы на каждой строке и держал два указателя на части глифа. Для сохранения фона приходилось записывать временные значения в операнды OR и повторять цикл по парам строк. COLPRE выводит один столбец полностью: HL=битмап, DE=экран, B=маска сохранения фона. Семь повторений DUP и последняя строка без продвижения устраняют счётчик и условный переход. Следующая строка глифа — INC H, следующая строка экрана — INC DE. Перед вторым столбцом исходные HL/DE восстанавливаются со стека один раз, INC D переводит экранный указатель на 256 байт вправо. Промежуточного пиксельного буфера и SMC-слияний нет.

Обычное ядро строки: `LD A,(DE); AND B; OR (HL); LD (DE),A`. Инверсное — отдельный цикл с XOR маской записываемых пикселей; в обычном нет XOR/NOP. Выбор один раз на глиф. Для обычного курсора расчёт адреса и продвижение встроены, фаза и код остаются в регистрах. Редкий перенос перед рисованием при X/2>=190 сохраняет прежний helper. Проверки шрифта, наличия и эпохи пререндера остаются в BIOS: standalone COLPRE обходился без них, поэтому его 518.528 мс не стали временем полноценного BIOS.

## Проверки и повтор

Обычный прогон прошёл 36 этапов, инверсный — 18. Сверены пиксели и курсор, отчёт B:\FONTBEN.TXT прочитан обратно через DOS, проверены закрытие файла, отключение пререндера, освобождение блоков/модулей и возврат в NC. Экземпляры Emu80 были видимыми, без звука и закрыты после проверки. Это эмуляторные измерения, не физическое оборудование.

CPU-проверка: 13923 случая, cpu/results.json. Включены все 256 кодов, все четыре начальные фазы, KOI7/8, обычный и инверсный вывод (1 и FF), длины около границ порций, контроль терминатора/длины/регистров, устаревший пререндер, линейный fallback и граничный курсор, включая X/2=190,191,192,255. ABI SDK и 125 проверок диспетчера прошли. Полная сборка OS и SystemEmuWritable: без ошибок и предупреждений.

Размер BIOS — 8945 байт против прежних 8985 (−40), модуль scalarPre — 362 байта, шрифт E400h, свободно 271 байт до него. IO — 893 байта. Форматы, адреса API и размер пререндера не изменились.
