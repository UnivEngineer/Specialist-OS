# 8X8: единая сетка

Emu80 4.0.575, CPU и ВИ53 2 МГц, 1152 байта, время в мс. Свежий прогон после оптимизации циклов: пиксельный эталон, сохранение ABI, освобождение памяти, файл на B: и возврат в NC — PASS.

8×8 использует полный FONT.FNT, восемь страниц по 256 байт. Код глифа находится в младшем байте адреса, строка выбирается INC H. Цикл восьми строк развёрнут; текстовый указатель хранится в BC. Чтений экрана, масок и сдвигов нет; P=1 не включает ненужный пререндер.
