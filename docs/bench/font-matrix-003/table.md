BIOS char — неизменённый штатный printChar; Opt — экспериментальная замена только пиксельного бэкенда. Serial сохраняет регистры один раз на строку 48 байт. Win20 передаёт через общее окно 20+20+8 байт с чтением рендером прямо из окна, Far48 копирует строки по 48 байт через memcpy_far в main-буфер, Far1152 копирует весь корпус одним memcpy_far; их main-столбец повторно измеряет соответствующий пакетный вход на 48 байт. Время копирования включено, установка тестового шлюза исключена. У Quad без указания транспорта DOS передаёт по четыре кода регистрами. Во всех случаях один корпус и одна конечная сборка; это модель, не физическое оборудование.
