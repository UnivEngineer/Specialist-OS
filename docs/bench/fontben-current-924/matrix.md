# FontBen на корпусе 924 байта

Emu80 MX2, Intel 8080 и ВИ53 2 МГц. В обычной сетке 21 строка по 42 символа и CRLF. В `-X0…3` 22 явно позиционированные строки по 42 глифа. В фазовой сетке все пять API измеряются из MAIN. Обычная сетка включает 18 тестов на каждое сочетание движка, режима инверсии и пререндера. Приведено время в миллисекундах, шаг таймера 0,128 мс.

Для Char и CharRaw порядок значений MAIN / BANK CMD / BANK CMD+Z. Для строковых API порядок MAIN / BANK NEAR / BANK Far256 / BANK Own. Время BANK включает транспорт до рендера в MAIN. Установка шрифта и вывод отчёта идут вне таймера.

Всего 1904 результатов, из них 144 получены в предыдущих двух прогонах 4×8 на том же корпусе. [Исходные данные](results.json) · [Идентификаторы корпусов и образов](metadata.json)
