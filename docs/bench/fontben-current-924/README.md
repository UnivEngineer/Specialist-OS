# Базовая матрица FontBen перед оптимизацией 6×8 и 8×8

Серии на одном корпусе из `A:\README.TXT`. Обычная сетка использует 21 блок по 42 кода и CRLF, фазовая сетка 22 строки по 42 глифа. `-R` использует ту же фазовую сетку с двумя вертикальными разделителями и одной горизонтальной линией. CPU и ВИ53 работают на 2 МГц. Замеры выполнялись в четырёх отдельных видимых экземплярах Emu80 с выключенным звуком.

### 8×8 до изменения направления

`RawLim` из MAIN, 22 позиционированные строки, обычный вывод. Время в миллисекундах.

| Движок | X=0 | X=2 | X=4 | X=6 |
|---|---:|---:|---:|---:|
| `8x8/Rotate` (`Graph8x4`) | 127,872 | 318,336 | 348,032 | 318,464 |
| `8x8/Packed` (`GraphP8K`) | 128,000 | 290,048 | 289,920 | 289,920 |
| `8x8/Fast` (`Graph14K`) | 128,000 | 247,808 | 247,808 | 247,808 |

Таблица содержит все пять API, MAIN и маршруты BANK, обычный цвет и инверсию для актуальных сборок, `-X0…3` для графических 8×8, обычный цвет с `PRE=0/1` для LEGACY и `-R` для резидентов. Для современных движков проверены пиксели и курсор по независимому эталону. Для исторических контролей сравнивается полный кадр и курсор всех маршрутов одного API. Обычные 4×8 и FAST4 взяты из предыдущих двух прогонов на том же корпусе. [Матрица](matrix.md) · [Исходные отсчёты](results.json) · [SHA-256](metadata.json)

Для повторения используйте `check.py` с локальным checkout и параметрами `--group 0…3` и `--port 19781…19784`. В отдельном запуске добавить `--pseudo`. Обычный A: берётся из `SystemEmuWritable`. Тестовый H: собирается с `Games2M -ManifestFile` и содержит FontBen и три контрольных `.fnt`, включая компактный 6×8 и два выровненных 8×8.
