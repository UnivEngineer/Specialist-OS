# WIN8 и современные движки 8×8 — 2026-11-14

Локальный ВИ53 Emu80, CPU и ВИ53 2 МГц, квант 0,128 мс. 1152 байта одного корпуса A:\README.TXT: 24 × (46 символов + CRLF). Обычный цвет, KOI8, без пререндера. ROW8 использует флаг ON, который у этого движка не меняет алгоритм. Подготовка и очистка вне таймера, накладные расходы ABI/MXCALL внутри. Это эмуляторные измерения, не физический компьютер.

WIN8 — адаптированный оригинальный алгоритм оконного монитора, плоский шрифт code*8+row. Сохранены поиск блока по 32 кода, цикл восьми строк и CALL/JMP/RET на каждую строку. StringZ сохраняет исторический строковый цикл. Координаты и управляющие коды обслуживаются адаптером FontBen/BIOS; таблица блоков настроена на прямой KOI8. RawZ/RawLim — добавленные обёртки, не исторические API. Полный оконный монитор и его обработчик ESC здесь не измеряются.

ROW8 — прежний экспериментальный построчный рендерер (бывший 8X8), не оригинал монитора. FAST8 — современный код source/font, общий для MAIN DLL FontBen и резидентного Fast8.dll. У всех четырёх колонок одинаковые 256 исходных глифов оконного монитора. FAST8 транспонирует их в восемь страниц, разворачивает копирование строк и держит указатели в регистрах.

Все 72 этапа проверены по пикселям и координатам курсора. Проверены восстановление ABI и возврат в NC. CPU-тест дополнительно сравнил исторические машинные инструкции с ROM (кроме перемещённых адресов) и отрисовал все 256 кодов.

Воспроизведение: `FONTBEN_REPORT_DIR=docs/bench/window8-grid` (переменная окружения), затем `python source-apps/fontbench/check-resident.py Window8 Fast8 Standalone8 Shared8`. Исходные результаты, корпус и подтверждения — в подпапках; образ — tested-system.bin. Нормальные/инверсные современные ядра дополнительно проверены check-shared-font.py; исторический WIN8 с инверсией в эту матрицу не входит.

Во время этого прогона информационная строка после остановки таймера могла прокручивать экран с 8×8: её прежняя ширина была рассчитана на 6×8. Измеренный экран проверялся до информационной строки, поэтому это не включено во время. После прогона статус разнесён по двум строкам; финальная сборка также содержит исправления поиска FONT по короткому имени. tested-system.bin сохраняет именно измеренную сборку.

Финальная проверка через клавиатуру NC: короткие имена Packed6K/Fast8/Cpm4, явный путь, код 02 для отсутствующего имени; все 18 информационных строк FAST8 сохраняют тестовую область и курсор Y=255, прокрутки нет. Эмулятор закрыт. Лог и снимок находятся в final-check.
