# Проверки основного дерева

После исправления стендов прошли 47 наборов для текущей сборки. Проверены системная таблица вызовов, вложенные строки, регистровый вывод, CPM32, FILL, стековые границы, DOS, файловые операции, пакетные сектора, UI и обе сборки NC. Стенд RUN проверил девять вариантов переходника, размещения и возврата. Стенд Monitor-2 проверил точность и восстановление после намеренного повреждения тестового выхода. [Коды завершения](status.json)

Для SORTBEN дополнительно прошли 144 сценария сортировки на бинарнике приложения и 62 сценария ВИ53, задержки перезагрузки счётчика и форматирования времени. [Проверка сортировки](../../../../../source-apps/sortbench/check.py) · [Проверка таймера](../../../../../source-apps/sortbench/check-timing.py)

Отдельно запущенный исторический check-image-stream.py рассчитан на монолитную DOS до разделения MAIN/DOS и формат заголовка v1. Он не прошёл на современном дереве. В банковом RUN семь запусков v2 дошли до точки входа, подтвердили байты программы и вернулись в NC. Проверены COM, EXE и фрагментированный RKS, режимы MX, STD, Monitor-2 и RAMFOS, а также верхнее размещение EXE. Восьмой тест подтвердил отказ при повреждении RKS.
