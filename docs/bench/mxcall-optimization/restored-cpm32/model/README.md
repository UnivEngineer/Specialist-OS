# Проверка BIOS и MEM на модели 8080

`check.py` загружает фактический `MEM.sys` и `BIOS.sys` из каждого переданного каталога `bin`. Модель берёт физический вход, границы DATA и рабочие метки из символов этой сборки. Она сверяет фиксированные точки ABI F80Fh и C42Dh, устанавливает сегменты в MAIN, DOS, EXEC и DATA и включает резидентный путь BIOS штатным `biosMoveUseMem`, если такой переключатель есть. Для rev68 модель сверяет 62 байта шаблона и слово вектора из BOOT.bin и DOS.sys, помещает шаблон в FE4Ch только в DATA и выставляет вектор через операнд `moveForwardDispatch`. В результатах записаны SHA-256 обоих образов.

Такты отсчитываются с первой команды точки входа до возврата включительно. Межбанковый повтор API запускается в том же состоянии памяти и маппера с другим содержимым источника, пока активно окно COPY. Полный шаг CPM32 отдельно измеряется как разность отметок двух соседних входов в `bankCopyTail`. На rev65 и rev66 результаты C42Dh и внутреннего повтора совпали с ранее измеренными.

Стенд охватывает прямой C42Dh, публичные F80Fh и MOVE, физический вход CPM32, чтение ROM, локальные и удалённые переносы MAIN/EXEC, а также перенос внутри DATA. Проверки сравнивают память со снимком источника перед переносом, включая обе стороны перекрытия, противоположный порядок непересекающихся адресов и совпадающие адреса. Проверяются граничные байты, пакет, стек, регистры BC/DE/HL, возвращённые флаги статуса, выбранная страница, хвост DATA и содержимое окна. Исторический C42Dh проверяется по своему ABI, в котором значения BC/DE/HL после переноса определены отдельно. Для публичного нуля проверяется, что диапазоны и FAR-коды игнорируются и окно не меняется. Внутренний физический вход при нуле проходит подготовку с переключением страниц, при этом пользовательские байты не изменяются.

В rev65 MOVE внутри DATA должен вернуть E7h, а контракт F80Fh внутри DATA охватывает непересекающиеся диапазоны. Проверки отклонения выше начала хвоста DATA применяются начиная с rev66. Rev65 проверяет для всех страниц общий предел FF00h. Доступ к дисплею, периферии и загрузка системы в этой модели отсутствуют.

```powershell
python docs/bench/mxcall-optimization/restored-cpm32/model/check.py <rev65-bin> <rev66-bin> <rev68-bin>
```

Файл [result.json](result.json) содержит результаты по каждой ревизии.

## Результаты

Rev65 прошла 632 сценария, rev66 и rev68 — по 669. В каждой ячейке указаны такты rev65 / rev66 / rev68. Инициатор межбанкового запроса — MAIN. Источник и назначение находятся в разных банках DATA.

|    16 |       764 / 754 / 744 |    3703 / 3487 / 3673 |           3203 / 3017 / 3203 |
|    31 |    1171 / 1016 / 1006 |    4873 / 4011 / 4843 |           4373 / 3541 / 4373 |

Во всех 54 межбанковых физических сценариях rev68 совпадает с rev65 до такта. Все 45 случаев F80Fh быстрее rev65 на 30 тактов, все 45 межбанковых MOVE — на 33 такта. Повтор API с активным COPY тратит столько же тактов, сколько первый вызов. Горячий 32-байтовый шаг rev68 занимает 1022 такта, как в rev65. В rev66 он занимал 1647 тактов.

Для 256 байт со сдвигом назначения на один байт ниже источника прямой C42Dh занимает 5049 / 4986 / 4976 тактов. Со сдвигом на один байт выше источника — 5202 / 10139 / 10129 тактов. Ниже приведены такты MOVE с той же длиной и обоими направлениями перекрытия.

| Страница       |     Назначение ниже |       Назначение выше |
| -------------- | ------------------: | --------------------: |
| MAIN           |  6208 / 5983 / 5973 |  6390 / 11136 / 11126 |
| EXEC           |  8894 / 5983 / 5973 |  9058 / 11136 / 11126 |
| Удалённый MAIN |  8383 / 6212 / 6149 |  8565 / 11365 / 11302 |
| Удалённый EXEC | 11069 / 6203 / 6140 | 11233 / 11356 / 11293 |
| DATA           |   E7h / 6217 / 7147 |   E7h / 11370 / 11307 |

Локальные переносы rev66 и rev68 не обращаются к общему окну. Перенос в удалённой странице переключает её и страницу инициатора. 62-байтовый прямой ход DATA сократил перенос 256 байт со сдвигом вниз с 13660 тактов промежуточной rev67 до 7147 в rev68. В rev66 с полной развёрткой тот же перенос занимал 6217 тактов. Полный профиль rev68 сохраняет развёртку.

## Потребители SDK

`scripts/tests/check-sdk-abi.py` сверил 26 адресов BIOS, 12 кодов ошибок, восемь новых прямых входов и шесть C-переходников. Скомпилированный тест MEM проверил оба направления перекрытия F80Fh и MOVE в MAIN, неверный банк, нулевую длину и границу FE00h. Прошёл автономный тест NEAR-кучи. Девять программ и модулей из `source-apps/moduletest` собраны без предупреждений.

`check-sdk-runtime.py` запустил 7605-байтовый C-тест FILEHANDLE на готовом банковом образе. Стенд прошёл клавиатурой из NC EXEC через CLI в NC MAIN, затем проверил консоль, курсор, MEMTOP и файлы B:. Клавиатурные функции C проверены через временные заглушки BIOS, после теста оригинальные JMP восстановлены. Шрифт сверялся побайтно. Частная сборка Emu80 использовала MCP 19783, Qt offscreen и скорость 32× без full throttle. Результаты, контрольные суммы и параметры запуска записаны в [sdk-runtime-result.json](sdk-runtime-result.json).
