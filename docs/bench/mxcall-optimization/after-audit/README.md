# Записи в маппер и отдельный стек leaf

Emu80 4.0.575/qt-mcp, отдельный видимый экземпляр без звука, Intel 8080 2 МГц и фиксированные 32×. Проверена финальная сборка MEM ревизии 63, параметры и SHA-256 образа записаны в [system.json](system.json).

На время каждого вызова выставлены точки наблюдения `type=write` на FFFCh и FFFDh с `skipCount=1000000`. `bp_list` читается сразу после останова у клиента до переключений страниц самим стендом. `mapperWrites` — сумма обращений CPU к двум регистрам, `mapperWritesByAddress` — значения по адресам. В проверяемых маршрутах эти адреса используются для записи селекторов. Emu80 считает обращения до проверки типа точки наблюдения при ненулевом skipCount, поэтому этот способ применим к регистрам, к которым проверяемый сценарий только пишет.

У каждой страницы проверены нижние байты FEC5h–FEC6h, зарезервированные четыре байта стека FEC7h–FECAh и исходное слово возврата FECBh–FECCh. Глубина определяется по SP сразу после двух PUSH в BIOS и сверяется с контрольным заполнением. `leafStackBytes` хранит глубину по банкам, `leafStackMax` — максимальную глубину на вызов. `leafReturnPages` показывает банки, где листовой обработчик вошёл со SP=FECBh. Локальный DOS_GET_ERROR входит на стеке инициатора. Внешний вызов DOS_GET_ERROR читает отдельное слово возврата и расходует ноль байт под PUSH.

| EXEC, F806h, COMMAND | FFFCh | FFFDh | Максимум leaf, байты |
|---|---:|---:|---:|
| UPPERCASE, очередь выключена или активна | 1 | 1 | 4 |
| SUB_HL_DE | 1 | 1 | 4 |
| DOS_GET_ERROR | 0 | 2 | 0 |
| Вложенный EXEC→DOS→BIOS | 1 | 3 | 4 |

Целевые проверки расположены в [focused/profile.json](focused/profile.json). Расширенная матрица в [audit.json](audit.json) собрана с `--audit-only`, где сохраняются останов у клиента и контрольные точки для измерения leaf. Для скоростного запуска указать `MXOS_EMU80_SPEED=32`. Обычный режим без `--audit-only` по-прежнему записывает полный профиль контрольных точек и те же новые поля.

Проверены все 244 строки. Их такты совпадают с прежним `after/`, а число записей совпало с количеством переходов между страницами по полной трассе. В 80 строках записей нет, в 160 их две, в четырёх вложенных строках их четыре. Четыре байта отдельного стека MAIN используются в 36 строках. В четырёх внешних вызовах DOS_GET_ERROR используется отдельное слово возврата DOS с глубиной PUSH=0. В остальных 204 строках отдельное слово возврата не используется.
