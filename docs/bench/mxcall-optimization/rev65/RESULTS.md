# MEM 1.4 на Intel 8080, 2 МГц

Сравнение ревизий 64 и 65 выполнено в скрытом Emu80 MX2 с фиксированным ускорением 32×. Измерены такты гостевого процессора от CALL до возврата.

## Размер

| Величина, байты | rev64 | rev65 | Разница |
|---|---:|---:|---:|
| MEM.sys с заголовком и четырьмя сегментами | 3069 | 3070 | +1 |
| Мнемоники 8080 во всех установочных сегментах | 2628 | 2660 | +32 |
| Мнемоники в общем окне | 8 | 0 | −8 |
| Резидентный хвост DATA | 239 | 313 | +74 |
| Резерв RAM-диска на страницу | 512 | 512 | 0 |

Из сегментов файла вырос TRANSPORT, с 959 до 960 байт. LOCALBLOCK занимает 1600 байт, CLIENT — 448, начальное содержимое окна — 32, заголовок — 30. При подсчёте мнемоник каждый машинный байт учитывается один раз по адресу и сверяется с бинарником. DB, DW и выравнивание учитываются только в размере файла. Резидентный диапазон DATA теперь FE87h–FFBFh. [Подсчёт по листингам](instruction-size.py)

## BIOS

Замеры получены при пустой очереди. Прежний F806h использует CALL с DW и исходной раскладкой COMMAND. Прямой вызов из MAIN включает исторический JMP C8xx и сам BIOS. Печать символа проверена для Q в одинаковом положении курсора.

| Новый вход | Прямой BIOS в MAIN | F806h rev64 MAIN | F806h rev64 EXEC | Новый ABI MAIN | Новый ABI DOS/EXEC |
|---|---:|---:|---:|---:|---:|
| F81Bh mx_printChar | 1010 | 1540 | 3480 | 1184 | 1567 |
| F81Eh mx_getCursorPos | 53 | 573 | 539 | 149 | 175 |
| F821h mx_setCursorPos | 69 | 589 | 572 | 149 | 175 |
| F824h mx_printCharRaw | 934 | 1464 | 3404 | 1108 | 1491 |
| F827h mx_printHexByte | 2610 | 3130 | 5070 | 2784 | 3167 |
| F82Ah mx_printHexWord | 5092 | 5612 | 7552 | 5266 | 5649 |
| F830h mx_getMemTop | 53 | 573 | 2513 | 163 | 199 |
| F833h mx_setMemTop | 53 | 573 | 2513 | 173 | 209 |

У курсора и memTop SP остаётся в стеке инициатора. Печатные входы из банка устанавливают стек MAIN. C и A проходят напрямую, HL на время смены стека находится в DE. Служебный код запоминает адрес JMP к BIOS и числовой SP инициатора. Оба операнда использованы до входа в BIOS, а собственный адрес возврата каждого вызова лежит на стеке MAIN. ## CPM32 и локальный перенос

В таблице F80Fh вызван из MAIN, источник находится в MAIN, приёмник — в DATA с FAR-кодом 3, смещение в тестовом буфере равно 1. Первая передача начинается после COMMAND, второй вызов повторяет ту же передачу. Полные блоки переносятся по 32 байта. Для остатка 1–31 байт постоянно установленный код читает нужные байты в окно и вторым проходом записывает их в приёмник.

| Длина, байты | rev64 после COMMAND | rev64 повторно | rev65 после COMMAND | rev65 повторно |
|---:|---:|---:|---:|---:|
| 1 | 3183 | 2406 | 2536 | 2536 |
| 31 | 6003 | 5226 | 4876 | 4876 |
| 32 | 5349 | 4572 | 3470 | 3470 |
| 33 | 5896 | 5119 | 3889 | 3889 |
| 256 | 12180 | 11403 | 10264 | 10264 |
| 257 | 13028 | 12251 | 10984 | 10984 |
| 8192 | 265932 | 265155 | 264016 | 264016 |

Все 168 ненулевых передач FAR с длиной, кратной 32, ускорились. После COMMAND ускорились все 189 передач с остатком. При повторной передаче с остатком 161 из 189 вариантов ускорился, 28 заняли до 130 тактов дополнительно. Удалённый MOVE с перекрытием на один байт и длиной 257 байт внутри EXEC по запросу MAIN занял 15703 → 11274 такта, внутри MAIN по запросу EXEC — 15703 → 8611. Для ненулевого MOVE внутри DATA ожидается E7h. ## Образы и проверки

Итоговый образ имеет SHA-256 `CBCBECF413C63C7F25C6F8A6951E6C57B0D13B46B4AC1EEF03CCD76F86062302`. Он прошёл 99 сценариев BIOS и 18 сценариев вложенного COPY во время вывода строк и исполнения очереди. В 16 строковых случаях процессор прочитал терминатор один раз и сохранил байт за ним без чтения. NC и оба редактора открыты клавиатурой. Отдельно проверены ввод и возврат из EDIT_MN в NC_MN на исходном MX с одним банком ДОЗУ. Для этого изменён только AUTOEXEC в частной тестовой копии. [Вложенные вызовы](inline-nested/result.json) · [MAIN и EXEC](final2-user/result.json) · [Один банк](main-only/result.json)

Серии переноса, отказов и общего транспорта сняты на образе `864D1030…`. Между ним и итоговой сборкой в MEM.sys различаются только инструкции F561h–F582h, обслуживающие банковую печать символов и HEX. Код CPM32, локального MOVE, проверки прежних номеров и общий диспетчер побайтно совпадают. Все восемь входов BIOS измерены на итоговом образе.
