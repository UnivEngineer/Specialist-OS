# Вложенные TEXT, COMMAND и CPM32

Тест использует финальный системный образ с SHA-256 `CBCBECF413C63C7F25C6F8A6951E6C57B0D13B46B4AC1EEF03CCD76F86062302`. В MAIN тестовые векторы печати складывают символы в буфер и для каждого символа вызывают `mx_memcpyFar`. CPM32 переносит 32 байта из страницы DATA 2 в MAIN и перезаписывает общее окно. В сценарии короткой пачки первый обработчик также запускает внутреннюю пачку. Ожидаемый вывод двух внешних команд и одной внутренней — `A!B`.

Проверяются вызовы из DOS и EXEC. Сценарии ASCIIZ используют длины 0, 1, 19, 20, 21 и 43 байта, а публичные PRINT_STRING_Z и RAW_Z пересекают две границы фрагмента. Две контрольные точки чтения проверяют первое чтение NUL и отсутствие чтения следующего байта. Проверяются результирующие HL/SP, исходная страница, служебные стеки, данные COPY и оба защитных байта приёмника.

Прошли 18 сценариев, по девять из DOS и EXEC. Во всех 16 строковых сценариях NUL прочитан один раз, байт за ним не читался. В обоих сценариях короткой пачки получен вывод `A!B`. [Протокол](result.json) · [Отдельные сценарии](samples.jsonl)

Сценарий запускается в собственной скрытой копии runtime с EXE для 19781 и фиксированными 32×. Он проверяет SHA-256 EXE и Qt offscreen plugin, PID и путь слушателя, отсутствие главного окна, звук и скорость через MCP. Стенд останавливает свой процесс в `finally`.

```powershell
python -X utf8 docs/bench/mxcall-optimization/rev65/inline-nested/check-emu.py --bundle docs/bench/mxcall-optimization/rev65/final2-bin --runtime <private-runtime> --out docs/bench/mxcall-optimization/rev65/inline-nested
```

Автономный тест `python -X utf8 scripts/tests/check-mem-inline-nested.py` выполняет настоящие процедуры TEXT, CPM32 и BATCH под 8080 с плоской памятью. Для CPM32 в стенде адреса источника и назначения неперекрывающиеся, логическая страница MAIN задаётся явно.
