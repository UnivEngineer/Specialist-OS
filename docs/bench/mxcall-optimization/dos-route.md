# Таблица внешнего диспетчера DOS

Отдельная сборка rev62 и кандидат проверены в видимом Emu80 4.0.575/qt-mcp. Слот 19781, фиксированные 32× без полного ускорения, CPU/ВИ53 2 МГц, звук и мониторинг ленты выключены. Время включает CALL F800h и заканчивается на следующей инструкции. Каждый случай выполнен дважды.

| Операция F800h | Страница клиента | До, такты | После, такты |
|---|---|---:|---:|
| GET_ERROR | MAIN | 4352 | 3618 |
| GET_ERROR | DOS | 2231 | 2231 |
| GET_ERROR | EXEC | 4325 | 3591 |
| TIMER / QUERY | MAIN | 3956 | 3708 |
| TIMER / QUERY | DOS | 2331 | 2331 |
| TIMER / QUERY | EXEC | 3939 | 3691 |

В 26 сценариях совпали весь AF, результат MX_REGS, байт ошибки DOS и состояние контекста. Исполнение номеров 30h и FFh проверено из MAIN, DOS и EXEC, номера 12h (служба допустима локально) из EXEC. Все отказали с DOS_ERR_UNSUPPORTED, сохранили пакет и восстановили SP. У недопустимых внешних вызовов изменились неопределённые BC/DE/HL. Замеры проверяли защитную область стека, owner/home/depth/serviceSP и снятие kdBusy. [До](dos-route-before/result.json) [После](dos-route-after/result.json)

DOS.sys сократился с 29988 до 29975 байт, зазор до переменных вырос с 92 до 105 байт. Границы переменных и буфера данных сохранились. Внешняя таблица содержит 46 позиций, из них 15 адаптеров NEAR, 9 скалярных обработчиков и 22 отказа. Сопоставлены 48 записей штатной локальной таблицы по символам до и после перелинковки. Ранние специальные операции идут прежним порядком. [Сводка](dos-route-summary.json)
