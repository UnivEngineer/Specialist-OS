# Rev64: прямой опрос клавиатуры и контроль CPM32

Проверен объединённый образ SHA-256 `9d1b8508d793319edeb74a8c0cf7b7b80374ad20cc5b4ae398a3c004c979758b`. MEM.SYS SHA-256 `606cf80fb3ece5f656dfc5a9a8d312c57afa0157282d6b8577fe15340764fb45`. Каждый стенд запускался в собственном видимом Emu80 без звука. `sys_info` подтвердил CPU 8080 2 МГц, фиксированные 32× и выключенный full throttle.

## KEY_SCAN и GETCH

Файл результата побайтно совпал с rev63. KEY_CHECK и KEY_SCAN вернули FFh в простое и 1Ah при удержании Down, каждый результат повторился трижды. GETCH принял шесть событий за одно удержание для каждого пути. [Rev63](../../held-down/poll-after/result.json) · [Rev64](poll-after/result.json)

| Операция | Rev63 и rev64, тактов | Мс при 2 МГц |
|---|---:|---:|
| EXEC F806h KEY_SCAN и KEY_CHECK, свободно | 2 582 | 1,291 |
| EXEC F806h KEY_SCAN и KEY_CHECK, Down | 6 648 | 3,324 |

| EXEC io_bankKeyScan, свободно / Down | 140 / 5 711 | 0,070 / 2,8555 |
| EXEC F806h GETCH, первое событие от точки ожидания | 100 439 | 50,2195 |
| EXEC F806h GETCH, первый повтор | 986 579 | 493,2895 |
| EXEC F806h GETCH, устойчивый повтор | 45 031 | 22,5155 |

Использован [исходный стенд](../../held-down/remote.py) с перенаправлением только каталога вывода. Отсчёт первого GETCH начинается при останове BIOS в точке ожидания, остальные значения измерены между возвратами GETCH. При установившемся повторе все четыре отсчёта совпали.
