# Прямой CALL BIOS и F806h на rev64

Такты 8080 от CALL до первой следующей инструкции приложения. Для F806h остановка сразу за DW операции. Прямой BIOS CALL включает исторический вектор C8xxh. Оба пути измерены в MAIN с одинаковыми входными AF/BC/DE/HL, курсором 100Ah, активным COMMAND и шрифтом 6X8/ROTATE. Выходные AF/BC/DE/HL/SP и конечный курсор совпали. Видимый Emu80 19781 работал без звука и полного ускорения, с подтверждённой фиксированной скоростью 32×. Частота CPU 2 МГц. Образ SHA-256 9D1B8508D793319EDEB74A8C0CF7B7B80374AD20CC5B4AE398A3C004C979758B. [Регистрограммы и такты](result.json) [Стенд](measure.py)

| Служба | Прямой вход | Входные данные | CALL, такты | F806h, такты | Разница |
|---|---|---|---:|---:|---:|
| UPPERCASE | C875h | A=71h (q) | 73 | 593 | 520 |
| SUB_HL_DE | C87Eh | 1234h − 2345h, заём | 65 | 585 | 520 |
| SUB_HL_DE | C87Eh | 2345h − 1234h, без займа | 65 | 585 | 520 |
| GET_CURSOR_POS | C81Eh | курсор 100Ah | 53 | 573 | 520 |
| SET_CURSOR_POS | C821h | HL=100Ah | 69 | 589 | 520 |
| PRINT_CHAR | C809h | C=51h (Q) | 1010 | 1540 | 530 |
| PRINT_STRING_Z | C818h | X и завершающий NUL | 1766 | 2296 | 530 |

Для UPPERCASE CALL/F806h также проверены 39h и 41h (45/565 тактов), A3h и A4h (91/611), C0h (114/634), E0h (103/623).

## DOS отдельно

Локальный CALL dosGetError выполнен внутри банка DOS по адресу 16E3h и сравнен с F806h из того же банка при одинаковом входе. Для v_dosError=0 заняло 45/333 тактов, для A5h заняло 53/341 такт. Совпали AF/BC/DE/HL/SP. Время перехода в DOS из MAIN в эти строки не входит.

## Дополнительное сравнение SET_CURSOR_POS с rev63

Оба F806h измерены в COMMAND без очереди, AF=7193h, BC=3451h, DE=2345h, HL=1234h и исходный курсор 100Ah. Измерения повторены дважды. В обоих маршрутах курсор стал 1234h, AF/BC/DE/HL/SP, страница и контекст восстановились. Изолированный Emu80 использовал сохранённый образ rev63 C2C14339… и MEM.sys F1D1FB70… . [Измерения rev63](set-cursor-rev63.json) [Матрица rev64](../profile/profile.json)

Прямой исторический CALL C821h из MAIN для ранее проверенных входных регистров занимает 69 тактов. В его теле нет развилки по регистрам или значению курсора.
