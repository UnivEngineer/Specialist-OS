# NC и EDIT после оптимизации MXCALL

База собрана из `2791c88`. Кандидат rev63 взят из рабочего checkout. В обоих случаях видимый Emu80 работал без звука в собственном слоте 19783. `sys_info` подтвердил 8080, 2 МГц, фиксированное ускорение 32× и отключённый full throttle. В таблицах указаны такты гостевого процессора. Знак минус означает сокращение времени.


## NC

В обоих прогонах использован один образ H:. Стрелки измерены от декодированной клавиши до следующего опроса. В таблице медиана девяти вертикальных или трёх горизонтальных перемещений. В горизонтальной серии первый шаг меняет позицию без прокрутки, поэтому в JSON сохранены отдельные замеры. ## Счётчики системных вызовов

Счётчики сняты в отдельных прогонах с точками останова на слотах 19781 и 19783. Для стрелок трассировался первый шаг соответствующей серии. CALL/SCOPE — входы в обработчики ядра DOS. F818 — вызов внутри области MODULE_SCOPE. «Профили» — число изменений между допустимыми значениями BANK_PROFILE, промежуточные байты загрузки окна доступны в JSON. Селекторы — обращения к FFFCh/FFFDh, зафиксированные при выборе MAIN и банков. При запуске и возврате загрузчик может временно писать в этот адрес байты кода, что даёт лишние события в столбце «Профили». F80F — сумма длин запросов memcpyFar. Байты UI_GFX также входят в эту сумму. Одинаковые значения показаны один раз. В JSON сохранены счётчики для всех трассированных операций.
