# Стоимость селекторов CPM32

Измерения 8080 через z88dk-ticks на MEM rev63. Штатный стенд заново измерил участок до bankCopyTail. Для bankCopySector с 256 байтами и активным COPY результат 2556 тактов совпал с baseline. Вставки эксперимента сделаны в копии образа RAM. Модель исполняет инструкции выбора страниц и проверяет подготовленные параметры, окно и регистры. Физическое переключение банков и перенос данных этим экспериментом не измерялись. [Штатный стенд](current/result.json) [Стенд подмены](measure.py) [Сырые данные](result.json)

| Сценарий RAM 2 → 3 из MAIN | Такты |
|---|---:|
| Полная подготовка до bankCopyTail | 2556 |
| Внутренний путь copyPrepareBody → bankCopyTail | 2090 |
| Три CALL bankCopyPair с телами и RET | 190 |
| Три вызова вместе с чтением страницы и сохранением пары | 277 |
| Подстановка заранее рассчитанных пар | 2305 |
| Совпадение тройки источник/назначение/инициатор с проверкой каждого ключа | 2425 |
| Промах при смене источника с пересчётом | 2710 |

190 тактов составляют 9,09% внутреннего пути и 7,43% полной подготовки. С чтением страниц и сохранением результатов доли составляют 13,25% и 10,84% соответственно. Предельный выигрыш от готовых пар составляет 251 такт (9,82% подготовки, 125,5 мкс при 2 МГц). Для повторной пары с проверкой ключей выигрыш составляет 131 такт (5,13%, 65,5 мкс). Два дополнительных bankCopyPair в copyClone работают штатно во всех вариантах.

Промахи при смене источника, назначения, инициатора и RAM → ROM дали те же три пары селекторов, окно COMMAND/COPY, регистры и SP перед bankCopyTail, что штатная ветвь. Цена промаха составила 154–224 такта. В модели смешанного потока для выигрыша требуется примерно 54–63% попаданий, в зависимости от первого несовпавшего поля. Доля попаданий в реальных операциях не измерялась. Экспериментальный кэш в штатный код не внесён.
