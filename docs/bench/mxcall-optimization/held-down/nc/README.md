# NC: удержание Down без прокрутки

Сравнены исходный 2791c88 и финальная сборка с MEM rev63, образ C2C14339…. Оба прогона выполнены в видимом Emu80 без звука на 32× при эмулируемых 2 МГц. В каждом профиле одно нажатие и отпускание в `finally`. Правая панель содержала 103 позиции при 38 видимых строках. За удержание принято десять шагов: курсор последовательно прошёл позиции 1–10, верхняя строка оставалась 0.

От нажатия до завершения обработки первого шага прошло 65,2035 мс в MAIN при обеих сборках и 31,799 → 30,8865 мс в EXEC. Медиана интервала между завершениями обработки составляет 37,0415 мс в MAIN и 32,9985 → 32,79525 мс в EXEC. Во всех 40 участках ожидания и во всех 40 обработчиках счётчик входа F806h остался нулевым.

В EXEC медиана самой обработки уменьшилась на 986 тактов, или 0,493 мс. Темп принятия устойчивых повторов остался около 30,5 шага в секунду. Предыдущий девятишаговый замер на тех же образах дал первый повтор EXEC за 241,557 и 250,2865 мс, а устойчивые медианы за 32,6435 и 32,856 мс. Клавиша оставалась нажатой до проверки десятого шага 867,6375 мс эмулируемого времени в MAIN и 546,3915 → 558,0825 мс в EXEC. Настенные интервалы, записанные через монотонные часы, составили 1,804 → 1,938 с и 2,268 → 1,742 с соответственно. Они включают остановы CPU, ответы MCP и чтение состояния стендом. Интервалы пользовательских повторов берутся из счётчика эмулируемого CPU.

## Методика повторения

[held-down.py](held-down.py) использует запуск MAIN и EXEC из `benchmark-nc-repeat.py`. Перед нажатием Home ставит курсор в начало длинной правой панели. Нажатие регистрируется при остановленном CPU в первой точке ожидания. Точки декодирования — `loc_C311` BIOS для MAIN и `ncBankInputKey` для EXEC, возврат к ожиданию — `getch2` BIOS и `ncBankInputPoll` соответственно. На каждом отрезке F806h наблюдается через `bp_set type=exec skipCount=1000000`. Сценарий проверяет, что CPU не продвинулся от одного события press/release, а каждый шаг увеличил курсор на одну строку и сохранил верх панели.

Для каждого checkout собрать OS и SystemEmuWritable, а в исходный checkout перенести актуальные измерительные `scripts/emu80/benchmark-disks.py`, `benchmark-nc-repeat.py` и `benchmark-nc-profiles.py`. Запустить `python held-down.py before --checkout <baseline> --runtime <runtime-19782> --disk <общий образ H>`, затем аналогично с `after` и финальным checkout. Сценарий занимает свободный 19782 и сам закрывает свой экземпляр. Сырые данные включают каждый шаг, абсолютные отметки, счётчики и SHA-256 образов.
