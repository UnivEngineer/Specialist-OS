# Удержание ↓ в NC и EDIT

При удержании ↓ без прокрутки банковый NC в финальном образе перемещает курсор примерно на 30,5 строки в секунду, банковый EDIT — на 15,3. В обоих приложениях проверены фактические принятые события и положение курсора. Счётчики F806h в периодах ожидания равны нулю. [NC](nc/README.md) · [EDIT](edit/report.md)

В обоих сравниваемых образах уже работает локальный опрос KEYBANK. NC получил десять событий за одно удержание, EDIT — восемь. Верхняя строка оставалась на месте после каждого шага. Таймеры и CPU работали на эмулируемых 2 МГц, Emu80 — с фиксированным ускорением 32×. Интервалы ниже относятся ко времени гостевой машины. Первый повтор отсчитывается от первого декодированного нажатия. Для установившегося темпа использована медиана остальных интервалов.

## Сколько занимает один BIOS-опрос

В отдельном прогоне из EXEC выполнен настоящий F806h KEY_CHECK и KEY_SCAN. Обе операции вызывают j_keyScan. Отсчёт от CALL до следующей инструкции, очередь отключена, профиль COMMAND. Состояние клавиши устанавливается однократно через MCP. Каждый неблокирующий вызов повторён трижды с одинаковым результатом. Отдельная серия из шести GETCH использует одно непрерывное удержание и собственный механизм повтора BIOS. Здесь отсутствуют отрисовка приложения и его обработчик простоя. [Исходный прогон](poll-before/result.json) · [Итоговый прогон](poll-after/result.json) · [Измеритель](remote.py)

| Операция из EXEC                     | До, тактов | После, тактов | После, мс |
|--------------------------------------|-----------:|--------------:|----------:|
| KEY_SCAN, клавиатура свободна         |      3 148 |         2 582 |     1,291 |
| KEY_SCAN, удерживается ↓             |      7 214 |         6 648 |     3,324 |
| GETCH, установившийся повтор BIOS     |     45 597 |        45 031 |    22,516 |

На прямом входе MAIN тот же KEY_SCAN при удержании занял 4188 тактов. Следовательно, 2460 из 6648 тактов итогового F806h приходятся на остальной путь вызова. Для обычного ожидания без клавиши io_bankKeyScan из EXEC занимает 140 тактов. На одно текущее неблокирующее обращение к BIOS приходится около десятой доли установившегося интервала банкового NC. Проверка измеряет текущий транспорт и исходную ревизию 58. Архивного замера версии приложений до локализации ввода в этом сравнении нет.
