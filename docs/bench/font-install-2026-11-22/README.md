# Установка шрифтов с генерацией и чтением пререндера

22 ноября 2026. Emu80 MX2, CPU и ВИ53 2 МГц, системная flash C: на 512 КиБ. Команды `FONT <размер>/<движок>` и `FONT <размер>/<движок> -FILE` вводились с клавиатуры банкового NC. Для каждого сочетания выполнено по три установки, порядок способов чередовался. Между командами кэш файловой системы не сбрасывался. Тестовые образы и все замеры были локальными, экземпляры Emu80 работали с отключённым звуком.

В таблице приведены медианы в миллисекундах. Полная установка измерена от начала чтения `.fnt` до завершения инициализации резидентного движка. Подготовка включает построение плоскостей или прямое чтение `.pre` со сверкой размера. Загрузка самого FONT.COM, набор команды и перерисовка NC за пределами отсечек. Шаг ВИ53 — 0,128 мс. После каждого замера проверены статус `FONT`, граница `memTop` и все байты таблиц.

У прежнего 6×8 Packed генератор переключался между выходными плоскостями для каждого байта. Новый Init6 строит две 256-байтные таблицы преобразования в верхней части временной рабочей области. Затем каждая фаза пишется отдельным проходом по страницам с разворотом на восемь байтов. Генерация стала быстрее в 3,20 раза. Размер тела Init6 вырос с 347 до 388 байт и остался в прежних двух секторах образа. Таблицы побайтно совпадают с результатом хостового сборщика. Для импорта проверен также синтетический шрифт через `scripts/tests/check-font-prepared.py`.

Генерация выигрывает у всех пяти штатных движков. Из манифеста системного тома убраны пять `.pre` общим объёмом 34 КиБ. Собраны SystemEmuWritable, SystemRamfos и SystemHardware 512. Проверены каталоги FAT и установка всех пяти движков с обычным FONT.COM из SystemEmuWritable без `.pre`. Ключ `-FILE` доступен для пользовательских комплектов.

Для повторения соберите FONT с `-DFONT_BENCH=1` и на время замера включите его и пять сырых таблиц в отдельный образ. Точки отсечки `benchStamps` содержат убывающие 16-битные счётчики. Разности соседних значений по модулю 65536 дают интервалы в тиках. Фаза подготовки находится между смещениями 8 и 10, прямой вызов чтения — между 16 и 18. Считывайте их на входе `committed`.
