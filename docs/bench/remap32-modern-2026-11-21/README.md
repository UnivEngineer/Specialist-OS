# REMAP32 на современных 6×8

Сравниваются штатные Rotate, Packed и Fast с экспериментальными резидентами на тех же ядрах. Вариант REMAP32 использует старшие три бита кода как индекс в восьмибайтной таблице, затем объединяет результат с младшими пятью битами. Вторая проба заранее разворачивает ту же карту в 256 готовых индексов. Обе версии подставляют индекс после штатной проверки четвёрки и при входе в скалярное ядро. Пиксельные циклы, форматы шрифтов и пререндеров те же. Исходные управляющие коды и ограничители строк обрабатываются до перекодировки.

Обе таблицы размещены в выравнивании перед шрифтом E400h. У Rotate и Packed таблица начинается с E300h, у Fast с E200h. Размер всех пробных резидентов 5189 байт. Нижняя память нужна только для штатного пререндера Packed и Fast. В эксперименте таблица задаёт индексы глифов. Штатное переключение KOI в резидентах использует прежнюю физическую перестановку.

## Проверка и время

В модели 8080 проверено 1500 сочетаний. Перестановка семи блоков прошла на всех кодах через RawLim, на 01h–FFh через RawZ, с управляющими кодами в StringZ и на выборке одиночных вызовов. Сверялись экран, курсор и регистры. Проверены четыре фазы X, правый край, инверсия и сохранность исходных плоскостей. [Такты в модели 8080](cpu-timing.json)

| Дополнительная работа | Карта 8 байт | Таблица 256 байт |
|---|---:|---:|
| Одиночный CharRaw | 100 тактов | 60 тактов |
| Одна выровненная четвёрка RawLim | 319 тактов | 159 тактов |

Эти числа включают чтение и перезапись кодов в буфере четвёрки. Определение индекса занимает 52 такта для карты блоков и 12 тактов для готовой таблицы. Расчёт для 231 четвёрки при 2 МГц даёт прибавку 36,845 и 18,365 мс соответственно. В Emu80 измерялся весь вызов API с исходной тождественной картой, чтобы сравнить одинаковые кадры. Использовался корпус 924 байта, CPU и ВИ53 на 2 МГц, обычный и инверсный режимы, MAIN и банковские маршруты. Пиксели и курсор совпали с независимым эталоном на всех 324 этапах трёх экземпляров Emu80. ## Воспроизведение

Подготовьте отдельный локальный checkout с актуальными исходниками. `prepare.py <checkout> --runtime-source <source>` добавляет шесть пробных резидентов. Каталог source содержит отдельные runtime `font4-runtime-19781`…`font4-runtime-19783`. Соберите OS и SystemEmuWritable в checkout. Скопируйте [тестовый манифест](H-Remap32-test.txt) в локальный checkout и соберите `Games2M -ManifestFile H-Remap32-test.txt`, затем запустите `seed-flash.ps1`.

`check.py --root <checkout> --port <port> --group <0|1|2>` запускает один из трёх наборов. `check-cpu.py <checkout>` проверяет перестановки и считает такты. `report.py <checkout>` собирает результаты.
