# Сборка и запуск Emu80 на D:, N: и G:

Коммит `0d5041d9`. N: и D: обновлены через `git pull --ff-only`. На G: этот коммит уже был. Для Git на N: понадобился адресный `safe.directory` на время команды.

Замер от старта `scripts/build/build-all.ps1` до появления видимого окна MXOS в Emu80 4.0.575. Вторая часть использует `scripts/emu80/run-built-profile.ps1 Flash2M` с одним отдельным локальным runtime и отключённым звуком. На каждом томе использована чистая копия того же коммита под `tmp/`. Холодный прогон начинался с пустых результатов сборки. Системный файловый кэш и кэш NAS работали в обычном режиме. Горячие прогоны использовали те же каталоги. Копирование исходников и закрытие окна не входят во время.
