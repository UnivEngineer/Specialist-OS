# FontBen Far1024 и строковые входы MAIN

Сравнение выполнено на Specialist-MX2 в скрытом Emu80 с фиксированным ускорением 32×. В таблице указаны такты CPU 8080, включая CALL и возврат. Все три маршрута печатают тот же корпус FontBen из 924 байт с нулевой стартовой позиции в штатном шрифте Rotate. Для Z копируется 925 байт вместе с NUL. Стенд вызывает собранную подпрограмму `gridBankFar` из FONTGRID и сверяет растровое изображение, курсор, состояние ESC, инверсию и границы записи с прямым MAIN. Предварительное выделение буфера и подготовка корпуса выполняются до замера.

| Строковый API | MAIN напрямую | EXEC через окно 32 | EXEC Far1024 | Far1024 к MAIN | Экономия времени к окну |
| :------------ | ------------: | -----------------: | -----------: | -------------: | ----------------------: |
| StringZ       |       573 043 |            668 228 |      609 059 |         +6,29% |                   8,85% |
| RawZ          |       525 973 |            572 520 |      562 004 |         +6,85% |                   1,84% |
| RawLim        |       498 146 |            548 354 |      534 133 |         +7,22% |                   2,59% |

Far1024 использует один `mx_memcpyFar` и один `PRINT_STRING_*_MAIN` на весь корпус. Оба действия входят в замер. Порции через 32-байтное окно вызывают рендерер на каждом заполнении. Скорость зависит от шрифта, позиции курсора и текста. В отдельном запуске FontBen из NC проверены экран, освобождение буфера и возврат в оболочку. [Сырые такты и параметры эмулятора](emu/result.json) · [Штатный запуск из NC](../fontben-far1024-smoke/results.json)

В тесте ABI 84 проверки сопоставляют экран прямого BIOS с регистровым и пакетным вызовами для MAIN, DOS и EXEC, включая длины 0, 33 и 1024, встроенный NUL и разные данные по одинаковому адресу в двух банках. Ещё девять проверок составляют три строки таблицы. [Стенд](../../../scripts/emu80/benchmark-mem-bank.py) · [Реализация](../../../source-apps/fontbench/grid-bank.inc)

После удаления диспетчера BIOS.SYS уменьшился с 6142 до 5857 байт, IO.SYS с 818 до 766. MEM.SYS занимает 3070 байт, DOS.SYS — 31471. FONTGRID.i80 вырос с 666 до 708 байт вместе с таблицей релокаций. Постоянная область IO_VARIABLES сократилась с 72 до 60 байт.
