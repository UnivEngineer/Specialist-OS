# 32-байтное окно печати и файловых вызовов DOS

Итоговая сборка содержит BIOS 6.1, DOS 3.1 и транспорт MEM rev69. Сравнение выполнено в отдельной рабочей копии без параллельной разработки загрузчика DLL. [Доставка путей и дескрипторов DOS](dos/README.md) · [Проверенный системный образ MMX](after/images/C-Flash-512k-MMX-System-Emu80.bin)

Использованы загруженные системные образы ревизий 68 и 69. Emu80 работал в собственном скрытом экземпляре с фиксированной скоростью 32×, без звука. В EXEC использован шестой банк с резидентными сегментами MEM. Такты измерены между началом CALL и возвратом в вызывающий код. Для каждой длины и режима сравнивались курсор и все 12 КиБ видеопамяти с прямым вектором MAIN. Проверены исходная строка, AF/BC/DE, конечный HL, SP и контекст банка.

В каждой ячейке приведены такты до и после изменения. Одно число означает совпадение.

## Устройство транспорта

В rev68 строка занимала поле пакета COMMAND по адресу FFC8h. Теперь TEXT использует все адреса FFC0h–FFDFh. Выборка из страницы клиента прекращается на первом NUL или на 32-м байте. После переключения в MAIN обработчик получает частную копию фрагмента на служебном стеке и дополнительный NUL после полной порции. Это позволяет обработчику вызвать DOS или COPY с тем же окном. При 32 печатных байтах и следующем за ними NUL передаются две порции. В RAW_LIM те же 32 байта передаются за один раз.

DOS собирает ASCIIZ в своём буфере KD_PATH до разбора пути. Файловая операция может занять окно повторно при обращении к драйверу. Значение MAX_PATH равно 128 байтам вместе с NUL. Двоичные объекты передаются с явной длиной. Для двух и более полных блоков используется CPM32.

## Сборка и размеры

Полная сборка прошла для MMX Flash + floppy, исходного MX и RAMFOS. Номера BIOS/DOS в загруженном файле и образе подтверждены по адресам biosVersion, biosDosVersion и kernelVersion. Monitor2.mon побайтно совпал с эталоном. Проверки 8080 прошли для 314 сценариев CPM32 и 16 файловых операций. Реальные файловые вызовы из MAIN и EXEC проверены в скрытом Emu80 при 32×.
