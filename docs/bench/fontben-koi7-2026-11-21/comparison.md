## Байты движка в MXOS

Резидентный образ включает код, верхнюю таблицу, выравнивание и служебные данные. MAIN — постоянная нижняя резервация. Таблицы указаны суммарно в обоих адресных диапазонах.

| Профиль | Таблицы KOI-8 → K7 | Резидент KOI-8 → K7 | MAIN KOI-8 → K7 |
|---|---:|---:|---:|
| Rotate → K7Rotate | 2048 → 1024 | 5189 → 4096 | 0 → 0 |
| Packed → K7Packed | 6144 → 3072 | 5189 → 5230 | 4096 → 0 |
| Fast → K7Hybrid | 12288 → 3072 | 5189 → 5120 | 10240 → 0 |

## Смена кодировки или загрузка с A:

Переключение измерено в модели 8080 по входу setEncoding. Загрузка измерена в Emu80 от входа FONT до установленного модуля. Приведён диапазон трёх загрузок на профиль, время в миллисекундах.

| Профиль | Переключить KOI-8 → KOI-7R | Установить K7 |
|---|---:|---:|
| Rotate → K7Rotate | 9,184 | 495,336–543,744 |
| Packed → K7Packed | 27,377 | 565,768–615,547 |
| Fast → K7Hybrid | 54,629 | 561,970–611,926 |
