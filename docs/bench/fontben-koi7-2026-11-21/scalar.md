# K7Fast под экраном и посимвольный вывод

21 ноября 2026. Модель 8080, номинальные 2 МГц. Из результатов вычтены такты тестовой обёртки. `K7Rotate` выбран основным профилем KOI-7R.

## Пакетный вывод K7Fast

Все три пары фаз разделены и занимают 6144 байта. У обеих встраиваемых проб код и таблицы целиком лежат за экраном 9000h–BFFFh и не занимают прикладной MAIN. В действующем MXOS слот D800h–EC7Fh вмещает 5248 байт, поэтому контрольный полный вариант MXOS запускался из низкой памяти.

| Движок и размещение | Таблицы | Секция целиком | Тактов на дополнительную четвёрку | RawLim, 924 байта | Время при 2 МГц |
|---|---|---:|---:|---:|---:|
| MXOS Fast12K в режиме KOI-7R | Верхняя таблица и MAIN | — | 1140 | 276 511 | 138,256 мс |
| MXOS K7Fast, стенд в MAIN | 4000h–47FFh и 5000h–5FFFh | — | 1162 | 281 453 | 140,727 мс |
| Монитор‑2 K7Fast, D000h–F0FFh | D900h–F0FFh | 8448 байт | 1522 | 367 595 | 183,798 мс |
| RAMFOS-MXOS K7Fast, D300h–F3FFh | DC00h–F3FFh | 8448 байт | 1162 | 286 045 | 143,023 мс |

Стоимость четвёрки вычислена по разнице замеров на 4 и 16 байтах. На всех четырёх длинах (4, 16, 64, 924 байта) сверены экран, конечный курсор и указатель буфера. Проба RAMFOS-MXOS добавляет 328 тактов на каждый из 14 переходов через край строки по сравнению с K7Fast в MXOS. У пробы Монитора‑2 чтение экранного байта и XOR при записи добавляют 360 тактов на четвёрку.

## Посимвольные входы MXOS

Такты на глиф при вызове из MAIN. Каждый код 21h–7Eh измерен на всех четырёх фазах X без перехода строки. Фазы соответствуют 0, 2, 4 и 6 пикселям внутри экранного байта. У KOI-8 движков для этих кодов получилось одинаковое время в штатном KOI-8 и после переключения в KOI-7R. У контрольного полного K7Fast измерен прямой вход временного модуля.

| Движок | `printChar`, фазы 0 / 2 / 4 / 6 | Среднее `printChar` | Среднее `printCharRaw` |
|---|---:|---:|---:|
| KOI-8 Rotate | 993 / 889 / 1307 / 1386 | 1143,75 | 1067,75 |
| KOI-8 Packed6K | 865 / 894 / 1347 / 1337 | 1110,75 | 1034,75 |
| KOI-8 Fast12K | 780 / 774 / 1199 / 1199 | 988,00 | 912,00 |
| K7Rotate | 1066 / 962 / 1385 / 1464 | 1219,25 | 1127,25 |
| K7Packed | 993 / 953 / 1418 / 1433 | 1199,25 | 1107,25 |
| K7Hybrid | 1066 / 962 / 1385 / 1464 | 1219,25 | 1127,25 |
| K7Fast в MAIN | 866 / 843 / 1147 / 1179 | 1008,75 | 916,75 |

У K7Rotate и K7Hybrid общий скалярный путь. K7Packed и K7Fast берут из таблиц один готовый байт или два фрагмента в зависимости от фазы X. Глиф, пересекающий границу байтов, рисуется слева вниз и справа вверх. Packed маскирует вторую фазу, которая хранится в том же байте. Это даёт 76 тактов выигрыша на глиф у прежнего K7Packed в среднем. На фазе X=4 пикселя K7Hybrid рисует на 33 такта быстрее K7Packed. К прямому вызову K7Fast следует добавить 10 тактов перехода BIOS для сравнения с резидентными модулями. Получается 1018,75 такта на `printChar`. Готовые фазы сэкономили K7Fast в среднем 144 такта из 1152,75 на прямом входе. [Разбор пакетных циклов](cpu.md)

## Посимвольные входы Монитора‑2 и RAMFOS

Штатный C037h Монитора‑2 рисует печатный глиф через XOR с текущим содержимым экрана. У C809h и C818h к этому добавляется стирание знакоместа через DEL и возврат курсора на один знак. Встраиваемые пробы Монитора‑2 делают прямой XOR. RAMFOS маскирует старые пиксели внутри знакоместа и записывает глиф с фоном. Его XOR с подготовленными данными вставляет новые биты в очищенное поле. RAMFOS рисует девять строк, встраиваемые пробы пишут восемь. Исторический RAMFOS и RAMFOS-MXOS дали одинаковые времена на C809h.

| Движок / вход | Фазы 0 / 2 / 4 / 6, тактов | Среднее, тактов |
|---|---:|---:|
| Монитор‑2 C809h | 9118 / 8558 / 7998 / 7438 | 8278,00 |
| Монитор‑2 C037h | 3917 / 3637 / 3357 / 3077 | 3497,00 |
| Монитор‑2 K7Rotate и K7Hybrid | 952 / 848 / 1423 / 1502 | 1181,25 |
| Монитор‑2 K7Packed | 951 / 911 / 1392 / 1407 | 1165,25 |
| Монитор‑2 K7Fast | 762 / 739 / 987 / 1019 | 876,75 |
| RAMFOS и RAMFOS-MXOS C809h | 1629,117 / 1604,117 / 2369,117 / 2499,117 | 2025,37 |
| RAMFOS-MXOS K7Rotate и K7Hybrid | 1008 / 904 / 1327 / 1406 | 1161,25 |
| RAMFOS-MXOS K7Packed | 935 / 895 / 1360 / 1375 | 1141,25 |
| RAMFOS-MXOS K7Fast | 818 / 795 / 1099 / 1131 | 960,75 |

K7Rotate обрабатывает печатный глиф в 2,96 раза быстрее XOR-входа C037h. Проба с K7Rotate в RAMFOS-MXOS даёт 1,74-кратное ускорение. Пробы используют прежний путь для DEL и управляющих кодов. Пробел и DEL измерены отдельно и доступны в исходных данных.
