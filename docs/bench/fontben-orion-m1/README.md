# Монитор М1 «Ориона-128» против 6×8 Rotate в FontBen

Исходный ROM найден в `G:\Projects\RetroPC\Orion\soft\M1_rk.bin`. SHA-256 совпадает с ROM `m1rk.bin` из Emu80 и равен `CEAE3793B4D24E80CC76F43DC0BF70DA1AC080A72284FCFC17F578FAF7237D67`.

В `OrionM1.dll` перенесён пиксельный цикл FCFAh–FD25h. Для каждой из восьми строк он загружает шесть битов глифа в L, обнуляет H, сдвигает HL парами `ADD HL,HL` и объединяет обе половины с экранными байтами по маске. Шрифт KOI8 и шаг строки общие с Rotate. В правом столбце доступен только первый экранный байт. Обработка управляющих кодов, переносы и строковый ABI взяты из FontBen. Дополнительные строки межстрочного интервала исходного монитора исключены, чтобы сравнивать одинаковый растр 6×8.

## MAIN

Emu80 MX2, CPU и ВИ53 2 МГц. По одному полному прогону для каждого движка. Одинаковый корпус содержит 924 байта из системного C:. Для `StringZ` это 882 печатных глифа и 42 управляющих кода CR/LF. Обе RAW-функции рисуют все 924 байта. Отсечки ВИ53 учитывают вызов BIOS и рисование, без очистки экрана, установки движка и подготовки корпуса.

## Посимвольное сравнение

В MAIN `printChar` и `printCharRaw` вызываются отдельно для каждого байта корпуса. Это один и тот же корпус из 924 байт во всех четырёх прогонах, проверенный по SHA-256. В обычном режиме 42 байта CR/LF обрабатываются как управляющие коды. В RAW рисуются все 924 глифа. Результаты ВИ53 в миллисекундах.

| Движок | `printChar` | `printCharRaw` |
|---|---:|---:|
| 6×8 Rotate | 526,848 | 508,160 |
| 6×8 Packed | 511,104 | 492,800 |
| 6×8 Fast | 457,216 | 436,096 |
| Orion M1 | 1423,232 | 1453,824 |

Отдельный замер модели 8080 фиксировал фазу перед каждым вызовом и прогонял 94 печатных кода 21h–7Eh. Измерялся публичный вход BIOS без переноса строки. Такты подготовки курсора и вызова вычтены. Для каждой фазы проверены курсор и итоговый растр на фоне A5h.

| Движок | `printCharRaw` X=0 | X=2 | X=4 | X=6 |
|---|---:|---:|---:|---:|
| 6×8 Rotate | 917 | 813 | 1231 | 1310 |
| 6×8 Packed | 789 | 818 | 1271 | 1261 |
| 6×8 Fast | 704 | 698 | 1123 | 1123 |
| Orion M1 | 3535 | 3255 | 2975 | 2695 |

Даже на своей самой быстрой фазе X=6 М1 расходует в 2,06 раза больше тактов, чем Rotate на той же фазе. За четыре фазы в среднем М1 проигрывает Rotate в 2,92 раза. На этой разнице сказываются и сдвиги, и остальные операции скалярного ядра, включая работу со стеком, маскирование и запись экрана.

## Разница в ядрах

Одна итерация сдвига М1 стоит 35 тактов 8080, включая два удвоения, инкремент и условный переход. Для четырёх фаз X выполняются от двух до пяти итераций, то есть 70–175 тактов на пиксельную строку только на этот цикл. Rotate использует восьмибитные вращения и сложения по 4 такта и собирает четыре глифа в три экранных байта. Внутри выровненной по байту четвёрки он пишет готовые байты без чтения экрана. Поэтому сравнение показывает разницу между целыми путями вывода, включая скалярный обход у M1 и пакетную обработку у Rotate.

## Воспроизведение

```text
FONT 6x8/Rotate
H:/Bench/FontBen/FontBen.com -E BIOS -P OFF -Q -N
H:/Bench/FontBen/FontBen.com -E ORIONM1 -P OFF -Q -N
```

В обоих прогонах проверены все 18 этапов. Экран и курсор сверены с независимой моделью, три публичных перехода BIOS проверены во время замера и после восстановления. Программы вернулись в NC. Модель 8080 дополнительно проверила регистры ABI, все коды RAW и сохранение соседних пикселей на ненулевом фоне.
