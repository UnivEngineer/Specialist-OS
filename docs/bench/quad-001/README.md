# Четверки FONTBEN, 08.11.2026

Реализован экспериментальный путь четверок в автономном FONTBEN; BIOS-рендер не менялся. Вывод непосредственно в VRAM, 24 записи и ноль чтений на четверку. Три указателя на фазы 0/6/4 и один на исходный глиф; промежуточного пиксельного буфера нет. Экранный указатель BC, смена столбца INC B. Пиксельное ядро 370 байт, весь quad.inc 685 байт (2200h–24ACh), основной код заканчивается на 1D2Ch, скалярный рендер 2000h–2108h, исходный шрифт 2800h–2FFFh, полная таблица 3000h–5FFFh. Пересечений областей нет.

Защита выбранного слота на два следующих получения указателя задана двумя последними номерами: жертва FIFO пропускает эти номера. Слот первого глифа нельзя вытеснить при подготовке двух следующих; затем подготовка завершена и выполняется запись. Четвертый глиф сырой и ничего не выделяет. Минимум три слота. После четверок восстановлена обычная политика скалярного пути. Нулевая длина допустима, хвосты/невыровненный X/выход за экран отвергаются до записи. Режим normal KOI-8, нет интерпретации управляющих кодов, инверсии и прокрутки.

Тест использует 1200 отфильтрованных байт A:\README.TXT, 89 разных кодов, сетку 48×25, 168 слотов. Измерение ВИ53, CLK1=2 МГц, квант 0,128 мс. Main и DOS передают по четыре кода на вызов; из DOS коды передаются регистрами BC/DE, затем сохраняются в четыре байта main. Подготовка указателей, поиск/промахи/защита, цикл, таймер и межстраничная передача входят в результат. Загрузка файла и очистка экрана вне измерения. Один интеграционный прогон, измерения моделей Emu80, не физического оборудования.

Число промахов cold/warm 193/185 во всех вариантах кеша; независимые FIFO-модели подтвердили оба прохода, включая защиту указателей. В main выигрыш пиксельных операций компенсируют подготовка/защита: прогретые четверки медленнее на 1,60%. Из DOS прогретые четверки быстрее на 11,59% за счет меньшего числа межстраничных вызовов. По сравнению с BIOS вывод четверками с warm-кешем быстрее на 21,32% в main и на 27,93% из DOS. Разделение пиксельного ядра и передачи необходимо для интерпретации результатов.

Сборка OS завершилась без ошибок/предупреждений SjASMPlus, системный образ собран, проверено совпадение 27 файлов с манифестом. Независимый z88dk-ticks -m8080: 1046 скалярных и 556 пакетных случаев. Пакетная проверка охватывает все 256 кодов, крайние координаты и фон, сохранность регистров, CF на отказе, нулевую длину/хвосты/неправильные координаты/малый кеш и трехслотовые конфликты жертвы с защищенным указателем. Анализ машинных инструкций ядра разрешает чтения только через HL и записи только STAX B, запрещает чтение VRAM, маски, стек и CALL.

Emu80 запущен собственным видимым экземпляром без звука. FONTBEN.COM введен клавиатурой в обычную строку NC, снимок command.png. Все 9216 байт результата каждого прохода сравниваются с BIOS, Bitmap PASS; results.png содержит сводку. Подтверждены восстановление 2048 байт резерва DOS и 32 байт общего окна, возврат в NC после клавиши (returned.png). Экземпляр закрыт. JSON содержит такты, миллисекунды, промахи и SHA-256 использованных образов.
