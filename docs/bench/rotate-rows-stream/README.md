# Rotate 6×8 по строкам и непрерывный Rotate 8×8

FontBen в Emu80, CPU и ВИ53 2 МГц, обычный вывод. Для 6×8 использована обычная сетка MAIN/BANK и 1152 байта (24 × (46 символов + CRLF)). Для 8×8 использован режим MAIN -X0…3, 24 независимо позиционированные строки по 46 глифов, всего 1104 глифа. Сопоставлять стоит пары с одинаковой шириной и фазой. Время в миллисекундах.

6RotateQuads пишет три колонки блока 24×8 по вертикали. 6RotateRows берёт те же четыре кода и выводит по три байта горизонтально на каждой из восьми пиксельных строк. Два средних байта шрифта поворачиваются по одному разу, их битовые части используются в двух соседних экранных байтах. Ускорение затрагивает полные четвёрки, в посимвольных вызовах цикл общий.

8RotateQuads и 8RotateStream работают по горизонтальным пиксельным строкам. В обоих случаях прежний фронтенд определяет участок до правого края, кода управления, NUL или лимита в зависимости от API. Внутри участка перенос битов сохраняется между всеми соседними байтами. 8RotateQuads разворачивает запись на четыре байта, читая коды парами через POP. 8RotateStream читает один код и пишет один байт за итерацию. Конечная колонка подставляется в инструкцию сравнения один раз на участок. При X=0 оба работают одним выровненным ядром.

[check.py](check.py) запускает видимый Emu80, набирает команды через NC и сверяет пиксели, курсор и время каждого этапа. [results.json](results.json) содержит полные замеры. Маршруты 0…5 означают MAIN, BANK CMD, BANK CMD после пустого StringZ, BANK NEAR, BANK Far256 и BANK USER. NEAR вызывает PRINT_STRING_* с указателем в банке, MEM режет строку порциями до 20 байт внутри COMMAND. [check-pixels.py](check-pixels.py) отдельно проверяет две формы Raw, четыре фазы, инверсию и края на ненулевом фоне в модели 8080.
