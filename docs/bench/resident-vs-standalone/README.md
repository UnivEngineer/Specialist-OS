# FontBen: резидентные и MAIN-сборки, 2026-11-13

[Актуальная матрица Emu80 на корпусе 924 байта](../fontben-current-924/matrix.md)

Один образ, один корпус 1152 байтов (24 × 46 символов + CRLF), CPU и ВИ53 Emu80 2 МГц. Время — локальный ВИ53, квант 0,128 мс; накладные расходы MXCALL включены. Загрузка, подготовка, очистка экрана и отчёт исключены. Это эмулятор, не физическое оборудование. В каждой клетке **резидент через BIOS / тот же публичный код в MAIN**, миллисекунды. BIOS-прогон не подменяется. FONT*-прогон использует полные фронтенды из source/font, без старой обвязки standalone. При разных ширинах одинаковое число символов занимает разную площадь.

Проверены все пиксели, курсор, восстановление публичных ABI, сохранность резидентных таблиц и возврат в NC. KOI7/8, повторный Attach и совпадение MAIN/резидента с инверсией дополнительно проверены CPU-тестами.

## Старые standalone-ядра и текущий резидент, MAIN

Старые ядра измерены заново на том же корпусе и образе; это не подстановка исторических 153/198 мс. Для FAST8 и старого ROW8 используются одинаковые битмапы оконного монитора. Для Fast12K скаляр сравнивается с COL6PRE, пакетные строки — с ROW6 ON.

У Compact нет тождественного исторического компактного модуля для парного сравнения. Старые контрольные ядра не изменялись ради поддержки инверсии; в FontBen это отдельная коллекция LEGACY. Все шесть актуальных FONT*-движков имеют обычные и инверсные ядра.

Всего 540 этапов. SHA-256 сохранённого tested-system.bin: `1c9df061f4945d2943ee34037dcb8ead1a8cdad3000d84ada27c5ecdb9896742`.
