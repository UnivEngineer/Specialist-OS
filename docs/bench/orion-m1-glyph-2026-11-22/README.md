# Вывод глифов в Мониторе М1 «Ориона-128»

22 ноября 2026 г. [Образ М1 из Emu80](https://github.com/vpyk/emu80v4/blob/master/dist/orion/rom/m1rk.bin) загружен по F800h в z88dk-ticks -m8080. Шрифт распакован через F82Dh. Экран C000h, шрифт F000h, обычное начертание. Перед каждым вызовом F80Fh для кодов 21h–7Eh позиция курсора F3D4h установлена на строку 5. Вычтено 50 тактов обвязки на знак и 20 на прогон. Проверены конечный курсор и наличие пикселей в экранной области.

| Значение X в курсоре | 0 | 4 | 8 | 12 | Среднее |
|---|---:|---:|---:|---:|---:|
| Такты F80Fh | 4714 | 3559 | 3966 | 4373 | 4153 |
| Мкс при 2,5 МГц | 1885,6 | 1423,6 | 1586,4 | 1749,2 | 1661,2 |

В цикле FCFAh–FD25h каждая из восьми строк сдвигается удвоениями HL и объединяется с двумя исходными байтами экрана по маске. [Сопоставимые посимвольные замеры MXOS, Монитора-2 и RAMFOS](../fontben-koi7-2026-11-21/scalar.md). [Замеры пакетного вывода MXOS](../fontben-koi7-2026-11-21/cpu.md).
