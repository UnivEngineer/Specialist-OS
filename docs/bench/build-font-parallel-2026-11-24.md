# Параллельный запуск сборки шрифтов, 2026-11-24

В изолированном локальном checkout сравнили два прогона build-project.ps1 OS -Force с теми же исходниками. Последовательный прогон занял 13,069 с, параллельный — 12,795 с. Это одиночные замеры на локальном диске.

| Цель             | Начало пересборки | Конец   |
| ---------------- | ----------------: | ------: |
| UI_GFX           |           1,062 с | 1,652 с |
| COPYBEN variants |           1,188 с | 1,751 с |
| Font engines     |           1,198 с | 4,141 с |
| DOS              |           4,226 с | 7,690 с |

Отсчёт ведётся от запуска PowerShell. DOS начал проверку в 4,142 с после завершения ранних задач. Бинарники и описатели шрифтов, COPYBEN и UI_GFX, а также BIOS.SYS, DOS.SYS, IO.SYS и MEM.SYS совпали по SHA-256 с результатом последовательной сборки. Обычный Build all включает в раннюю группу Almaz и Almaz-2. Полный горячий Build all прошёл за 4,241 с без SjASMPlus. Отдельные Almaz и Almaz-2 нашли те же записи кэша, проект MX собрался.

В отдельном прогоне намеренная ошибка ассемблера UI_GFX дала код возврата 1 и завершила пакет до проверки DOS. После восстановления исходника прошла штатная сборка. Прогоны на сетевом диске для этой правки не выполнялись.
