# FontBench на MXOS2 rev68

25 ноября 2026 года. Сохранились 72 измерения на четырёх движках. Во всех строках время дано в миллисекундах гостевой машины на вывод 924 байт. Для каждого банкового маршрута приведён прямой вызов BIOS из MAIN на том же движке.

## Что изменилось в банковом выводе

На MXOS1 один и тот же посимвольный вывод через банк занимал 2123,136 мс в архивной серии и 967,424 мс в rev68. Прямой вывод из MAIN в обеих сериях занял 705,280 мс. На всех четырёх движках разница между BANK CMD и MAIN в rev68 составляет 565–568 тактов на байт. Она вычислена по полному циклу вывода при 2 МГц. Отдельный вызов печати символа имеет свой замер. [Такты одного вызова BIOS](mxcall-optimization/restored-cpm32/fast-abi/README.md)

У архивных строк совпадают движок, состояние пререндера, отсутствие инверсии и длина корпуса. В архиве они помечены A:. Старые замеры сделаны на более ранней сборке. Разность времён включает изменения рендера и транспорта между сборками. Архив содержит также отдельные серии для KOI-7R, позиций X и псевдографики, всего 2318 отсчётов Emu80. ## Посимвольный вывод

Char выводит один байт с обработкой управляющих кодов. CharRaw рисует один глиф по его коду. MAIN вызывает публичный BIOS-вектор напрямую. В банке обе колонки используют фиксированные F81Bh для Char и F824h для CharRaw. Перед замером CMD читает курсор, CMDZ вызывает пустой StringZ. Подготовка не входит во время.

## Строковый вывод

StringZ обрабатывает CR и LF. StringRawZ рисует их как глифы и заканчивается на NUL. StringRawLim получает явную длину. В банке NEAR передаёт исходную строку порциями до 20 байт. F256 использует общий 256-байтный буфер BIOS, USER использует выделенный приложением буфер в MAIN. [Код банковых маршрутов](../../source-apps/fontbench/grid-bank.inc)

## Условия и проверка

Emu80 MX2, 8080 и ВИ53 по 2 МГц, скрытый режим 32×. Корпус содержит 21 строку по 42 символа с CR и LF. Шаг таймера 0,128 мс, в таблицах использованы исходные отсчёты JSON. Гостевой FONTBEN.TXT выводит миллисекунды с целой частью. PRE=0 означает выключенный пререндер, PRE=1 — включённый. В измерениях учтены обращения к API и пересылка текста. Загрузка DLL, подготовка шрифта, очистка экрана и запись отчёта выполняются вне измеряемого интервала. [Корпус](../../source-apps/fontbench/grid-corpus.inc) · [Прямой маршрут MAIN](../../source-apps/fontbench/grid-main.inc)

В 18 этапах MXOS1, 18 этапах PACKED и 36 этапах совместного прогона SCALAR12 и 4DUP проверены пиксели и координаты курсора. Для двух последовательных движков проверено дописывание обеих таблиц в FONTBEN.TXT. Отдельные проверки подтвердили восстановление точек BIOS и ресурсов после ошибки загрузки и 2062 проверки растров, регистров и таблиц на 24 вариантах рендера.
