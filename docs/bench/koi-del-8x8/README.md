# 8×8 после исправления DEL в KOI-7R

Сравнение со сборкой до исправления DEL на [том же наборе FontBen](../fontben-current-924/README.md). Для обычной сетки использован корпус 924 байта и все маршруты MAIN и BANK. Фазовая сетка начиналась при X=4 пикселя. В обоих случаях проверены обычный вывод и инверсия. В таблице обычный вывод, время в миллисекундах.

| 8×8 Packed | X=4 | CharRaw | MAIN | 683,520 | 650,752 |
| 8×8 Rotate | X=4 | RawLim | MAIN | 348,032 | 348,032 |
| 8×8 Packed | X=4 | RawLim | MAIN | 289,920 | 289,920 |
| 8×8 Rotate | Обычная | CharRaw | BANK CMD | 1701,760 | 1699,328 |
| 8×8 Packed | Обычная | CharRaw | BANK CMD | 1701,632 | 1699,328 |
| 8×8 Rotate | Обычная | RawLim | BANK NEAR | 188,160 | 188,160 |
| 8×8 Packed | Обычная | RawLim | BANK NEAR | 188,160 | 188,160 |

Для всех 92 этапов FontBen экран и курсор совпали с независимым эталоном. Модель 8080 даёт экономию 49 тактов у Rotate и 71 у Packed на одиночный невыровненный глиф вдали от правого края. Результат одинаков для нормального и инверсного вывода.

Исходные результаты фазовой сетки сохранены для [Rotate](worker-2/results.json) и [Packed](worker-3/results.json). Результаты обычной сетки сохранены для [Rotate](ordinary/worker-2/results.json) и [Packed](ordinary/worker-3/results.json).
