# Физический CPM32 и читатель TEXT в итоговой rev71

Старый бинарник — сборка из рабочего каталога `4e2ad367a6504ef2abac8014ed53875c` с прежним чтением TEXT через стековую развёртку near. Новый — общий итоговый образ C-flash с SHA-256 `b87ba3033b0dbc6cdd4fce4d0ecb9317c0e1d12f986190ec64f70c550c25dcee`. Оба бинарника имеют внутреннюю ревизию MEM 71. В JSON записаны контрольные суммы MEM, BIOS, bootstrap и DOS для сравниваемых сборок.

`check.py` выполняет код собранных MEM.sys и BIOS.sys на модели 8080 и банков MX2. Измерение полного переноса начинается непосредственно с первой инструкции физического входа и включает RET. Внешний CALL стоит ещё 17 тактов. Горячий шаг — разность отметок двух соседних входов `bankCopyTail` внутри одного запроса. У обоих бинарников прошли по 669 сценариев. В таблице для полных вызовов MAIN инициирует перенос между разными банками DATA.

| Вызов                                  | Старые такты | Новые такты |
| -------------------------------------- | -----------: | ----------: |
| Физический вход, 32 байта               |         2927 |        2902 |
| Физический вход, 256 байт               |         9721 |        9683 |
| Физический вход, 1024 байта             |        34550 |       34464 |
| Горячий внутренний шаг, 32 байта        |         1022 |        1020 |
| `bankTextCopy32`, от входа до RET      |          693 |         519 |
| Тот же читатель с внешним CALL         |          710 |         536 |

`text-copy.py` загружает тот же образ MEM и отдельно вызывает `bankTextCopy32` из MAIN, DOS и EXEC при чётном и нечётном указателе источника. Во всех шести сочетаниях такты совпали. Сверены байты источника и окна, SP, отсутствие переключений страницы. Между промежуточной интеграцией и финалом удалён один JMP, поэтому измерение читателя изменилось с 529 до 519 тактов.

На итоговом образе прошли холодный, тёплый и несовместимый с MEM аппаратные сбросы. Во всех трёх случаях сверены CLIENT в MAIN и DOS и весь хвост DATA, NC EXEC дошёл до опроса клавиатуры в банке 6. В тёплом сценарии сохранены DOS и B:, при несовместимой ревизии DOS перезагрузилась с сохранением B:. Отдельный свежий runtime использовал MCP 19781, Qt offscreen, фиксированные 32× и отключённый звук. После проверки свой процесс закрыт.
