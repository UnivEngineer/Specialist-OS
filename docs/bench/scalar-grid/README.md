# Скалярные ядра 6×8

Живой прогон в Emu80 4.0.575, CPU 2 МГц, измерение локальным ВИ53. Команда FontBen: `-E:<движок> -P:<ON|OFF|BOTH> -S`. Все варианты используют одинаковые публичные входы и вызывающий код; standalone-модуль временно подменяет входы BIOS. Подготовка шрифта, пререндера и отчёта в замер не входит, прямой ABI и банковый MXCALL входят. Standalone-серия и строки «BIOS до удаления KOI» сняты до удаления проверок KOI; затем отдельно повторён BIOS после их удаления. Исходные BIOS-результаты сохранены в bios-before-koi/.

Корпус: 1152 байта = 24 строки по 46 печатных символов README и CRLF. `printChar` обрабатывает CRLF и рисует 1104 глифа, `printCharRaw` рисует все 1152 глифов, включая CR и LF. Сравнивать следует одинаковые столбцы. BANK CMD/TEXT — посимвольные протоколы, без объединения в строковые пакеты.

MON2 и RAMFOS — адаптированные исторические пиксельные алгоритмы с общим FontBen-фронтендом и FONT.FNT; это не измерение неизменённой ОС/ПЗУ. SP580 использует тот же стековый механизм, что Monitor-2; отдельный дубликат не добавлен. Оконный монитор с полнобайтовым 8×8 не является скалярным 6×8.

ROTLINE — развёрнутый скаляр с линейным шрифтом; PAGED — соответствующий скаляр с транспонированным шрифтом. FULL — прежний скаляр с таблицей 12 КиБ; FULLFAST — то же ядро без повторного сохранения регистров внутри уже сохраняющего их публичного входа. COLPRE — скаляр с таблицей 10 КиБ, раздельным выводом столбцов и развёрнутыми восемью строками.

Самый быстрый Raw — COLPRE, 518.528 мс; FULLFAST — 523.392 мс. У FULLFAST устранение четырёх лишних пар PUSH/POP даёт 48.384 мс против FULL. Без пререндера лидирует PAGED. Текущий BIOS с пререндером медленнее собственного пути без пререндера: новое двухколоночное ядро следует заменить или переработать.

Самый быстрый найденный прежний посимвольный результат полного пререндера — 484.352 мс: [font-matrix-003](../font-matrix-003/table.md). Старый корпус содержал 1152 печатных символа без нынешних CRLF, вызывающий путь также отличался. Это исторический ориентир, не непосредственно сопоставимый прогон; значения не пересчитывались.

Первичные результаты каждого движка: `<имя>/results.json`, `raw.json`, `FONTBEN.TXT` и снимки в этой папке. Проверки пиксельного результата завершились PASS во всех десяти сериях; CPU-проверка всей standalone-коллекции — 1898 случаев.

После удаления KOI MAIN Char OFF ускорился с 788.480 до 728.064 мс, Raw OFF — с 762.624 до 717.824 мс; Char ON — с 965.504 до 905.216 мс, Raw ON — с 948.736 до 903.808 мс. Подтверждены все 12 этапов, включая BANK CMD/TEXT. Разница scalar↔COLPRE остаётся существенной и не объясняется одной проверкой KOI.

Итоговая сборка: BIOS 8985 байт, IO 893 байта; шрифт по-прежнему E400h. После изменения внутренних номеров MXCALL ревизия связки MEM повышена до 20, чтобы bootstrap не использовал оставшуюся в памяти DOS со старым ABI. Арифметическая библиотека занимает 90 байт полным комплектом и позволяет включать отдельные операции. Холодный запуск и геометрия A:/B: проверены отдельно после окончательной пересборки; boot/cold-ram.png.
