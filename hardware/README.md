# Аппаратная часть «Специалиста-MX2»

[Аппаратный журнал](ISSUES.md) — единый список ошибок, исправлений и доработок по платам и ревизиям. Новую пометку из `.dch` заносите в журнал до исправления. После правки допишите в ту же запись, что изменилось в схеме, разводке или на изготовленной плате и чем это проверено. Закрытые записи сохраняйте. В схеме рядом с узлом можно оставить номер записи.

В `boards/<плата>/` лежит по одному текущему проекту схемы (`.dch`), платы (`.dip`), экспорту схемы в DipTrace XML (`.dchxml`) и PDF. Имена файлов стабильны: история изменений хранится в Git. Экспорты обновляются вместе со схемой. PDF и XML здесь являются версионируемой документацией, а не временными результатами сборки. Экспортов самих печатных плат в PDF/XML в исходном наборе нет; `.dchxml` описывает именно схему.

| Каталог | Назначение | Исходная ревизия |
|---|---|---|
| `specialist-m` | Заводская материнская плата с авторскими доработками | Без номера |
| `crossboard` | Разъёмы, питание, ВИ53, ВВ55 программатора/flash-диска | 1 |
| `mapper` | Переключение памяти, стандартный режим и системная ROM/flash | 0 |
| `ram-slots` | Слоты памяти и контроллер цвета MX/стандартного режима | 1 |
| `ram-module` | Универсальный модуль DRAM | 0 |
| `flash-disk` | 1–4 микросхемы AT29C010–AT29C040 | 0 |

### Запрос захвата шины на кросс-плате rev1

Запрос /HOLD может выдавать только одна плата расширения. У DD3.3 (К155ЛЕ1) два входа /HOLD с подтяжками к +5 В. Он выдаёт высокий HOLD процессору, только когда оба входа имеют низкий уровень.

Для работы одной платы с /HOLD без переделки кросс-платы установите заглушку между контактом 43 и GND в другом слоте. Используйте для заглушки свободный слот. При пустом втором слоте без заглушки подтяжка удерживает его вход в 1 и блокирует запрос первой платы. [Схема кросс-платы](boards/crossboard/crossboard.pdf)

В маппере «Специалиста-MMX» регистр номера страницы ДОЗУ также выбирает банк системной ROM/flash. Перемычки маппера позволяют подать четыре выхода регистра на A15–A18 микросхемы. В режиме MX банк виден в окне 0000h–7FFFh. При подключении всех четырёх разрядов это 16 банков по 32 КиБ, всего 512 КиБ для системного диска A:. Для A15 предусмотрена также разводка в режиме совместимости с MX2. В профиле Emu80 выходы регистра подключены к обоим селекторам, а младшие биты адреса записи отдельно выбирают карту памяти. [Схема маппера](boards/mapper/mapper.pdf), [профиль Emu80](../scripts/emu80/specialist-mx2.conf).

В `panels/` сохранены два проекта производственных панелей DipTrace.

Ревизии имеют физический смысл: rev0 изготовлены и исправлены дорожками и перемычками; rev1 содержат исправления в проекте и не изготовлены. Выбор rev1 для crossboard и ram-slots не означает, что изготовлены именно эти платы. Исторические промежуточные проекты остаются в исходном внешнем архиве; импорт не удаляет и не перезаписывает их. Отдельный `Final-flash-disk-rev1.dip` не подменяет пару rev0 при импорте.

`import-notes.md` — исходные пояснения автора, сохранённые без редактирования. `import-manifest.json` связывает новые пути с исходными именами и SHA-256. Исходные бинарные проекты и экспорты скопированы побайтно; соответствие редакций схемы, платы и экспорта требует проверки в DipTrace.

Для чтения электрических соединений используйте `.dchxml`: файл содержит компоненты, определения выводов и цепи. Для визуальной сверки используйте PDF. Не изменяйте XML/PDF вместо исходного проекта DipTrace.
