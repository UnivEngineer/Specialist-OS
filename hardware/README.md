# Аппаратная часть «Специалиста-MX2»

В `boards/<плата>/` лежит по одному текущему проекту схемы (`.dch`), платы
(`.dip`), экспорту схемы в DipTrace XML (`.dchxml`) и PDF. Имена файлов
стабильны: история изменений хранится в Git. Экспорты обновляются вместе со
схемой. PDF и XML здесь являются версионируемой документацией, а не временными
результатами сборки. Экспортов самих печатных плат в PDF/XML в исходном наборе
нет; `.dchxml` описывает именно схему.

| Каталог | Назначение | Исходная ревизия |
|---|---|---|
| `specialist-m` | Заводская материнская плата с авторскими доработками | Без номера |
| `crossboard` | Разъёмы, питание, ВИ53, ВВ55 программатора/flash-диска | 1 |
| `mapper` | Переключение памяти, стандартный режим и системная ROM/flash | 0 |
| `ram-slots` | Слоты памяти и контроллер цвета MX/стандартного режима | 1 |
| `ram-module` | Универсальный модуль DRAM | 0 |
| `flash-disk` | 1–4 микросхемы AT29C010–AT29C040 | 0 |

В `panels/` сохранены два проекта производственных панелей DipTrace.

Ревизии имеют физический смысл: rev0 изготовлены и исправлены дорожками и
перемычками; rev1 содержат исправления в проекте и не изготовлены. Выбор rev1
для crossboard и ram-slots не означает, что изготовлены именно эти платы.
Исторические промежуточные проекты остаются в исходном внешнем архиве;
импорт не удаляет и не перезаписывает их. Отдельный `Final-flash-disk-rev1.dip`
не подменяет пару rev0 при импорте.

`import-notes.md` — исходные пояснения автора, сохранённые без редактирования.
`import-manifest.json` связывает новые пути с исходными именами и SHA-256.
Исходные бинарные проекты и экспорты скопированы побайтно; соответствие
редакций схемы, платы и экспорта требует проверки в DipTrace.

Для чтения электрических соединений используйте `.dchxml`: файл содержит
компоненты, определения выводов и цепи. Для визуальной сверки используйте PDF.
Не изменяйте XML/PDF вместо исходного проекта DipTrace.
