# Системная дискета DD для Специалиста-MX/MX2, 720 КиБ (80 дорожек, две стороны, по девять секторов 512 байт).
# ПЗУ загружает систему с привода 0. Загрузочные сектора до первой FAT сборщик берёт из ../bin/mx/reserved.bin.
# Они содержат вторую ступень, BIOS, IO, MEM, начальный шрифт, DOS и службу ВГ93. Ниже перечислены файлы тома FAT12.
# Привод 0 остаётся диском A: после загрузки. Строка SYSROM C: в AUTOEXEC.BAT подключает системное ПЗУ.
@label MX PROGRAMS

# Для каждой записи укажите имя на диске и путь от assets/. Третий и четвёртый столбцы необязательны.
# Для сырого исполняемого файла третий столбец задаёт адрес загрузки и входа (по умолчанию 0).
# У пары CPU/I80 адреса берутся из CPU, код из I80. У источника RKS адрес и сумма находятся в заголовке.
# Цели COM, EXE, DLL и FNT получают контейнер MXOS2. Для игровых EXE режим запуска задан в games/catalog.csv.
# TXT, BAT, CFG, EXT, HLP, PF и DAT копируются побайтно. Атрибуты R, S и RS означают «только чтение», «системный» и оба.
# Чтобы задать атрибуты без адреса, поставьте 0 в третьем столбце. У источника RKS дополнительных столбцов нет.

# Имя на диске                 Источник относительно assets/                          Адрес RAW Атрибуты
