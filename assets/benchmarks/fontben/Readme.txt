Бенчмарки FontBen и TextBen==========================FontBen.com - MAIN/BANK сетка пяти текстовых API.FontBank.dll - самостоятельный банковый участник.DLL движков самостоятельно не запускаются.Char и CharRaw: MAIN, BANK CMD, BANK CMD после StringZ.StringZ, StringRawZ, StringRawLim: MAIN, BANK NEAR,Far1024 через собственный MAIN-буфер. MXCALL входит в замер.NEAR передаёт до 32 байт за раз. Far1024 переносит до 1024байтов и NUL для Z одним memcpy_far перед выводом из MAIN.Параметры (регистр не важен):-E=BIOS        установленный движок, по умолчанию-K             то же, что -E=BIOS-E=STANDALONE  коллекция standalone-движков-E=ALL         BIOS и коллекция standalone-движков-E=LEGACY      прежние контрольные реализации-E=имя,имя     отдельные движки-I             инверсия для BIOS и актуальные standalone-P=OFF|ON|BOTH  состояния пререндера только для LEGACY-S             только посимвольные API-N             не сохранять отчёт-Q             без ожидания Enter-?             справкаВместо = можно использовать пробел.Актуальные standalone-движки:6RotateQuads - Rotate 6x8 по столбцам6RotateRows  - Rotate 6x8 по строкам внутри четвёрки6RotateCol4  - штатный Rotate 6x8 по столбцам6PackedQuads - Packed6K 6x8, упакованные фазы6FullQuads   - Fast12K 6x8, раздельные фазыCOMPACT6  - Compact 6x8, 162 глифа FONTKOIFAST8    - Fast8 8x8, байты без масокCPM4    - Cpm4 4x8, пары повторенных полубайтовFAST4   - Fast 4x8, отдельные таблицы полубайтов8RotateQuads  - невыровненный 8x8, по 4 байта8RotateStream - невыровненный 8x8, по 1 байту6RotateStream, 6PackedStream, 6FastStream - построчный 6x84PackedStream, 4FastStream, 4CompactStream - построчный 4x84Compact - обычный Compact 4x8 для сравненияДля 8x8 -X0..3 задаёт сдвиг 0, 2, 4, 6 пикселей.Прежние имена: ROTATE6, PACK6K, FAST12K.актуальные standalone и устанавливаемые FONT DLL собираются изодних исходников. Все имеют отдельные обычные иинверсные ядра. Исправление движка меняет обе сборки.FontBen временно подменяет BIOS/MXCALL-входы на DLLв MAIN и восстанавливает перед отчётом и выходом.BIOS измеряет установленный модуль без подмены.BIOS/актуальные standalone всегда испытывают одно состояние модуля:Packed6K/Fast12K с таблицей, остальные без неё.Для standalone нужна свободная MAIN: предварительноустановите FONT 6x8/Rotate. Сам FontBen не отключаети не освобождает резидентный пререндер.Примеры:FONT 4x8/PackedFontBen.com -E=BIOS -IFONT 6x8/RotateFontBen.com -E=CPM4,FAST8 -QFontBen.com -E=FAST4 -QFontBen.com -E=STANDALONE -I -QИсторические имена доступны явно, например:WIN8 ROW6 COL6PRE SCALAR12 TRIPACK ROW8 4DUP MON2.ORIONM1 - ядро 6x8 Монитора М1 "Ориона-128".WIN8 - оригинальное ядро оконного монитора.FAST8 - ускоренный движок, FONT 8x8/Fast8.ROW8 - прежнее экспериментальное ядро 8x8.ROW6 (бывший PAGED) - построчные страницы 6x8.COL6PRE (COLPRE) - посимвольная запись столбцов.SCALAR12 (FULL) - посимвольная таблица 12 КиБ.Коллекция LEGACY сохранена для сравнения прежнегокода и поддерживает только обычный вывод.FontLab/FontMap/FontBlk заменены общей сеткой и DLL.Встроенный текст: 21 блок по 42 байта и CRLF,всего 924 байта. Char/StringZ обрабатывают CRLF.Raw рисует их глифы и переносится по краю экрана.-X0..3: 22 строки по 42 глифа, те же 924 байта.CharRaw рисует даже код 00h. RawZ завершается нулём,RawLim печатает заданное количество байтов.15 этапов на модуль. Время измеряет локальный ВИ53в MAIN и BANK. Подготовка, загрузка DLL, очистка ипечать отчёта исключены из измеряемого интервала.Результат: B:\FONTBEN.TXT. Этап, название и времяостаются на экране. После серии - таблица и Enter.TextBen.com проверяет штатную печать MAIN/BANK ифайловые функции DOS. После завершения - Enter.Каталог A:\BENCH содержит CopyBen, SortBen, DiskBen,FontBen и TextBen со всеми модулями. Весь BENCH можноперенести в корень H: без пересборки программ.Модули загружаются с диска запуска бенчмарка.
