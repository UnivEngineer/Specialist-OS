Бенчмарки шрифтов FontBen и TextBen================================FontBen.com - общая сетка вызовов BIOS.MAIN: прямой ABI. BANK: штатный MXCALL.Движки *.dll отдельно не запускаются.FontBank.com - банковая часть стенда.Пять API: Char, CharRaw, StringZ,StringRawZ, StringRawLim. Для каждогодвижка проверяются MAIN, COMMAND/TEXT,Win20, Far256 и собственный MAIN-буфер.Неприменимые сочетания пропускаются.Standalone временно подменяет входыBIOS и таблицу MXCALL своим движком.Исходные адреса восстанавливаются доотчёта, при ошибке и перед выгрузкой.BIOS испытывается без всякой подмены.Параметры (регистр не важен):-E=BIOS        BIOS, по умолчанию-K             то же, что -E=BIOS-E=STANDALONE  все локальные движки-E=ALL         BIOS и локальные движки-E=имя,имя     выбранные движки-P=OFF|ON|BOTH  пререндер; обычно BOTH-N             не сохранять файл-Q             без таблиц и Enter-?             справкаВместо = можно поставить пробел.Повторный -E добавляет движки к выбору.Имена standalone-движков:MXOS1 OPT FULL CACHE QUAD COLD WARMROTATE HALF PACKED PAGED REMAP32 BLOCK328X8 4RAW 4PACK 4DUPMXOS1 - копия старого пиксельного ядра.OPT - пакетный посимвольный вывод.FULL - посимвольный пререндер 12 КиБ.CACHE - кэш отдельных сдвинутых глифов.QUAD - четвёрки с полным пререндером.COLD/WARM - холодный/прогретый кэш.ROTATE - четвёрки с вращением на месте.HALF - сохранённый сдвиг на 4 пикселя.PACKED - упакованный FONTKOI.PAGED - полный построчный шрифт 6x8.REMAP32 - полная таблица + remap блоков.BLOCK32 - компактные блоки по 32 глифа.8X8 - выровненное копирование глифа.4RAW/4PACK/4DUP - три формата CP/M 4x8.OFF отключает ускоряющие таблицы.MXOS1/OPT/ROTATE, 8x8 и форматы 4x8не меняют алгоритм при этом флаге.Для отсутствующих компактных глифовиспользуется локальный полный шрифт.Примеры:FontBen.com -E=PAGED -P=ONFontBen.com -E=FULL,QUAD,BIOSFontBen.com -E 4DUP -P ON -QFontBen.com -E=ALL -N -QТекст: A:\README.TXT, CRLF после 46 букв.Всего 1152 байта. Raw печатает CRLF какглифы, обычный вывод переводит курсор.RawChar рисует код 00h, RawZ завершаетстроку нулём, RawLim использует длину.18 замеров на движок и состояние таблиц.36 замеров при -P=BOTH. Время по ВИ53.В MAIN и BANK таймер читается локально.Передача и MXCALL входят в измерение.Подготовка, загрузка DLL и очистка экранавыполняются вне измеряемого интервала.Отчёт: B:\FONTBEN.TXT. Все выбранныедвижки записываются в один файл.После каждой таблицы ожидается Enter.-Q выполняет выбранную серию подряд.FontLab.com сохраняет старую методикуи прежние фильтры для сравнения.FontBlk.com/FontMap.com - старые тестыкомпактной адресации.TextBen.com измеряет штатный выводиз MAIN и BANK, с расходами вызовов DOS.Его результаты нельзя напрямую сравниватьс чистым пиксельным ядром FontLab.После итоговой таблицы нажмите Enter.-S: только printChar/printCharRaw, MAIN и BANK CMD/TEXT.Новые движки: MON2 RAMFOS ROTLINE FULLFAST COLPRE.Пример: FontBen.com -S -E=COLPRE -P=ONEngineS.dll нужен рядом с FontBen.com.
