Бенчмарки FontBen и TextBen==========================FontBen.com - MAIN/BANK сетка пяти текстовых API.FontBank.com - самостоятельный банковый участник.DLL движков самостоятельно не запускаются.Char и CharRaw: MAIN, BANK COMMAND, BANK TEXT.StringZ, StringRawZ, StringRawLim: MAIN, BANK Win20,Far256 и собственный MAIN-буфер. MXCALL входит в замер.Строковые банковые вызовы автоматически режут текст.Параметры (регистр не важен):-E=BIOS        установленный движок, по умолчанию-K             то же, что -E=BIOS-E=STANDALONE  шесть актуальных актуальные standalone-движков-E=ALL         BIOS и шесть актуальные standalone-движков-E=LEGACY      прежние контрольные реализации-E=имя,имя     отдельные движки-I             инверсия для BIOS и актуальные standalone-P=OFF|ON|BOTH  состояния пререндера только для LEGACY-S             только посимвольные API-N             не сохранять отчёт-Q             без ожидания Enter-?             справкаВместо = можно использовать пробел.Актуальные standalone-движки:ROTATE6  - Rotate 6x8, вращение, четвёркиPACK6K - Packed6K 6x8, упакованные фазыFAST12K - Fast12K 6x8, полные фазыCOMPACT6  - Compact 6x8, 162 глифа FONTKOIFAST8    - Fast8 8x8, байты без масокCPM4    - Cpm4 4x8, пары повторенных полубайтовактуальные standalone и устанавливаемые FONT DLL собираются изодних исходников. Все имеют отдельные обычные иинверсные ядра. Исправление движка меняет обе сборки.FontBen временно подменяет BIOS/MXCALL-входы на DLLв MAIN и восстанавливает перед отчётом и выходом.BIOS измеряет установленный модуль без подмены.BIOS/актуальные standalone всегда испытывают одно состояние модуля:Packed6K/Fast12K с таблицей, остальные без неё.Для standalone нужна свободная MAIN: предварительноустановите FONT 6x8/Rotate. Сам FontBen не отключаети не освобождает резидентный пререндер.Примеры:FONT 4x8/Cpm4FontBen.com -E=BIOS -IFONT 6x8/RotateFontBen.com -E=CPM4,FAST8 -QFontBen.com -E=STANDALONE -I -QИсторические имена доступны явно, например:WIN8 ROW6 COL6PRE SCALAR12 TRIPACK ROW8 4DUP MON2.WIN8 - оригинальное ядро оконного монитора.FAST8 - ускоренный движок, FONT 8x8/Fast8.ROW8 - прежнее экспериментальное ядро 8x8.ROW6 (бывший PAGED) - построчные страницы 6x8.COL6PRE (COLPRE) - посимвольная запись столбцов.SCALAR12 (FULL) - посимвольная таблица 12 КиБ.Коллекция LEGACY сохранена для сравнения прежнегокода и поддерживает только обычный вывод.FontLab/FontMap/FontBlk заменены общей сеткой и DLL.Текст: A:\README.TXT, 24 блока по 46 байтов и CRLF,всего 1152 байта. Char/StringZ обрабатывают CRLF.Raw рисует их глифы и переносится по краю экрана.CharRaw рисует даже код 00h. RawZ завершается нулём,RawLim печатает заданное количество байтов.18 этапов на модуль. Время измеряет локальный ВИ53в MAIN и BANK. Подготовка, загрузка DLL, очистка ипечать отчёта исключены из измеряемого интервала.Результат: B:\FONTBEN.TXT. Этап, название и времяостаются на экране. После серии - таблица и Enter.TextBen.com проверяет штатную печать MAIN/BANK ифайловые функции DOS. После завершения - Enter.
