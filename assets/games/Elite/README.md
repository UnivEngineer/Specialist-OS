# Elite для «Специалиста»

Порт CityAceE кассетной Elite для BBC Micro на журнальный «Специалист» с Intel 8080, выполненный на основе порта Бориса Лихачёва для «Вектора-06Ц». Тема автора и опубликованный архив: https://zx-pk.ru/threads/36828-elite-dlya-pk-spetsialist.html (вложение 85280). Исходный проект для «Вектора»: https://github.com/reqw41/elite-v06c.

`Elite-jcuken.rks` — неизменённая версия с раскладкой ЙЦУКЕН; загрузка и вход 268Ch, конец загружаемого образа 7EFFh. Это адреса упакованного загрузочного файла, а не доказательство границ памяти после распаковки. Требования автора: классический «Специалист», 48 КБ, 2 МГц, программный звук. Нативная совместимость с MXOS не подтверждена. Полное авторское описание и управление сохранены без изменения байтов в [Readme-original.txt](Readme-original.txt).

19.11.2026 файлы из локального архива сверены с единственным опубликованным в доступной теме вложением: обе RKS-версии и readme совпадают побайтно. SHA-256 ЙЦУКЕН: `97d710869aeb93242e20bf55a3aaa9f34d7285261a3f55b4898d0db4dcae88ba`, размер 22650 байт. Исходники именно адаптации CityAceE в этом вложении отсутствуют; исходники «Вектора» нельзя считать точным исходником этой сборки.

Манифест Games2M помещает игру на H: как `Elite/Elite.exe`: стандартный 32-байтный контейнер MXOS2 создаётся из RKS с сохранением адресов и нагрузки. Нейтральный EXE не объявлен нативным MAIN-приложением; среду запуска выбирает RUN. Требуется среда классического «Специалиста»; игровая и аппаратная проверка этой установки пока не выполнена.

Существующий `assets/games/Elite.txt` помещается в `Elite/Elite.txt` на H: вместо корня диска. Байты и кодировка KOI-8R этого текста сохранены; это ранее имевшийся файл, не авторское readme нового порта.
