# BUDI и BUDI2

Платформенная игра с лестницами, собираемыми предметами и охранниками.
Игрок может выкапывать временные ямы слева и справа под собой.

Исходные исторические версии сохранены побайтно в `legacy/`. В корне —
копии с нормализованными именами и **отдельный патч BUDI2 для цвета MX**.
Все четыре варианта включены в GAMES (Games2M) для пользовательской проверки.
Адрес загрузки всех вариантов — `0000h`.

## Варианты

| Файл | Происхождение и особенности | Статус |
|---|---|---|
| [Budi-std.rks](Budi-std.rks) | Копия прежнего `assets/games/BUDI.rks`. Цвет через `FF02h`; собственный опрос клавиатуры использует процедуры `C254h/C25Ah` и таблицу `C50Ch` Загрузчика. | Автор подтвердил работу в MON; в MX/STD клавиши не работали. |
| [Budi2-color-f000.rks](Budi2-color-f000.rks) | Исходная BUDI2: кандидат на незавершённую RAMFOS-адаптацию по уточнению автора. Пишет цвет в `F000h`, назначение этого адреса в целевой среде не установлено. Клавиатура через `C81Bh`. | По наблюдению автора в MON работает без цвета. Отдельный нестандартный контроллер не подтверждён. |
| [Budi2-mx.rks](Budi2-mx.rks) | Отдельный патч предыдущей версии: пять `STA F000h` заменены на `STA FFF8h`; коды цвета сохранены, сумма RKS пересчитана. | Статическая проверка пройдена; игровой прогон и соответствие палитры оригиналу не подтверждены. Запускать в MX. |
| [Budi-mx.exe](Budi-mx.exe) | Копия прежнего `assets/games/Budi-MX.exe`, историческое имя `Budi.0.EXE`. Самостоятельная историческая MX-версия, не результат нашего патча BUDI2. | Совместимость с нынешней MXOS в этом исследовании не проверена. |

RKS сохраняет заголовок адресов и сумму, EXE — исторический сырой образ.
Гипотеза о незавершённом переносе BUDI2 не доказывает её происхождение
от RAMFOS. Записи `F000h` не считаются достаточным доказательством
существования отдельного цветового контроллера; патч MX проверяет только
перенос пяти адресов и не завершает автоматически всю адаптацию игры.
Патч BUDI2 сохранён как RKS; переименование в EXE без извлечения нагрузки
не применяется. Сборщик образа штатно извлекает нагрузку из RKS.

| [legacy/BUDI2.rks](legacy/BUDI2.rks) | 28678 | `449588e8175e752819e24a37d1f9184bbb412e3f359b57d14378d7e6685425fc` |
| [legacy/Budi-MX.exe](legacy/Budi-MX.exe) | 28501 | `569192f641e7e9bf612d8accd8cd4998c3554ba352a9947f23af0c64ba8348ff` |

`legacy/BUDI2.rks` восстановлен из неизменяемого
[оригинала до патча](../originals/budi2/BUDI2.rks.bin); обе копии совпадают.
Прежний пропатченный файл из корня `assets/games` перенесён в `Budi2-mx.rks`.
Патчи не записываются поверх `legacy`. В образ включаются только рабочие
копии, явно перечисленные в манифесте.

## Имена в образе GAMES и запуск

| Имя на диске | Рабочая копия | Запуск |
|---|---|---|
| `BUDI.RKS` | `Budi-std.rks` | `LAUNCH -MON BUDI.RKS` |
| `BUDI-MX.RKS` | `Budi2-mx.rks` | `LAUNCH -MX BUDI-MX.RKS` |
| `BUDI2-F0.RKS` | `Budi2-color-f000.rks` | Исследовательская копия; MON не поддерживает её исходный контроллер цвета. |
| `BUDI-MX.EXE` | `Budi-mx.exe` | Прямой запуск MX; требует проверки. |

MX-патч в образе называется `BUDI-MX.RKS` (прежнее имя — `BUDI2.RKS`).
Ассоциация RKS с `LAUNCH -MON` не подходит для этого патча: режим MX
нужно выбрать явно. Имена задаёт
[FlashDisk.txt](../../../scripts/images/manifests/FlashDisk.txt).

## Управление и различия версий

В BUDI2: Пробел начинает игру; стрелки управляют движением; Пробел во время
игры копает слева внизу, ВК/Enter — справа внизу. В исходной BUDI действия
копания используют коды `71h` и `7Eh` вместо `20h` и `0Dh`.

Первые семь карт BUDI/BUDI2 побайтно одинаковы; восьмая отличается в 76 байтах.
Музыкальные данные различаются. Проигрыватель речи и запись 1280 байт
совпадают. Падение игрока выполняется отдельным циклом, который продолжает
музыку, но до приземления не вызывает обработчики охранников.

## Воспроизведение

Из корня репозитория:

```powershell
python -X utf8 scripts/games/package-budi.py
python -X utf8 scripts/games/package-budi.py --check
python -X utf8 scripts/games/patch-budi2.py --check
powershell.exe -NoProfile -File scripts/images/build-image.ps1 Games2M
```

Упаковщик проверяет SHA-256 всех трёх исторических файлов, создаёт три
побайтные нормализованные копии и воспроизводит отдельный патч через
`patch-budi2.py`. Патч проверяет исходный хеш, ожидаемые пять инструкций
и сумму, используя общую хостовую функцию контрольной суммы.

Реестр исправлений: [../README.md](../README.md).
Подробный локальный разбор: `docs/compat/budi-001/RESULTS.md`.
Статическая проверка и успешная сборка образа не заменяют игровой прогон.
