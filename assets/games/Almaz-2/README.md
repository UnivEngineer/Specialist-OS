# Варианты «Алмаза-2»

В каталоге собраны исходные и производные бинарники игры, загружаемые с
адреса `0000h`.

| Бинарники | Платформа / BIOS | Графика | Звук и отсчёт времени | Оптимизации и назначение |
|---|---|---|---|---|
| `Almaz2.exe`, `Almaz2.rks` | Классический «Специалист» | Ч/б | Программный звук, исходный игровой отсчёт | Без оптимизаций; сборка побайтно совпадает с оригиналом. |
| `Almaz2-optimized.exe`, `Almaz2-optimized.rks` | Классический «Специалист» | Ч/б | Программный звук, исходный игровой отсчёт | Все программные оптимизации: быстрый диспетчер, адресный ввод, буфер стрелок, квота анимации и сдвиги фаз. |
| `Almaz2-mx.exe`, `Almaz2-mx.rks` | «Специалист-MX» / MXOS | Цвет | Программный звук, исходный игровой отсчёт | Программные оптимизации, без аппаратных часов. |
| `Almaz2-mx-optimized.exe`, `Almaz2-mx-optimized.rks` | «Специалист-MX» / MXOS | Цвет | Эффекты ВИ53, музыка BIOS, секунды уровня | Все оптимизации, включая ограничитель темпа на ВИ53. |
| `Almaz2-ramfos.exe`, `Almaz2-ramfos.rks` | «Специалист-RAMFOS» / Ramfos | Цвет | Программный звук, исходный игровой отсчёт | Программные оптимизации, без аппаратных часов. |
| `Almaz2-ramfos-optimized.exe`, `Almaz2-ramfos-optimized.rks` | «Специалист-RAMFOS» / Ramfos | Цвет | Эффекты ВИ53, музыка BIOS, секунды уровня | Все оптимизации, включая ограничитель темпа на ВИ53. |
| `Almaz2-original-ramfos.exe`, `Almaz2-original-ramfos.rks` | Ramfos | Цвет | Исходный программный звук и игровой отсчёт | Историческая версия с восстановленными картами и надписями; хранится готовой, сборщик её не меняет. |

Имена внутри образов задаются манифестами. Например, `Almaz2MX.exe` на
flash-диске берётся из `Almaz2-mx-optimized.exe`, а `ALM2OPT.RKS` в системном
ROM — из `Almaz2-optimized.rks`. Отдельные копии с короткими именами не создаются.

Для каждого EXE в этом каталоге есть одноимённый RKS с адресом загрузки
и запуска `0000h` и контрольной суммой Монитора. Сборка и публикация:

```powershell
powershell.exe -NoProfile -File scripts/build/build-almaz2.ps1 All -PublishMxTimer
```

Суффикс `-optimized` означает все оптимизации, доступные платформе: для
MX и RAMFOS это также ВИ53. Шесть вариантов собираются из `source-apps/almaz2`.
Ключ `-NoOptimizations` отключает программные оптимизации; имена выходных файлов
при этом не меняются. Таблица описывает стандартную сборку без этого ключа.

Подкаталог `legacy` хранит оригинальный чёрно-белый `Almaz2-original.*` и
повреждённый исторический `Almaz2-original-ramfos-broken.*`. Они служат
эталонами и не публикуются в образы. Сборщик не создаёт резервных копий,
не упаковывает исторические файлы и не записывает данные в `legacy`.
