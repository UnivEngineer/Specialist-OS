# Варианты «Алмаза-2»

В каталоге собраны исходные и производные бинарники игры, загружаемые с
адреса `0000h`.

| Файл | Назначение |
|---|---|
| `Almaz2-original.exe` | Оригинальная чёрно-белая версия. |
| `Almaz2-original-ramfos-broken.exe` | Исторический цветной оригинал для RAMFOS с повреждёнными картами и надписями. |
| `Almaz2-original-ramfos.exe` | Исправленная цветная версия для RAMFOS с исходным программным звуком. |
| `Almaz2-optimized-ramfos.exe` | Ускоренная цветная версия для RAMFOS с эффектами ВИ53. |
| `Almaz2-optimized-mx.exe` | Ускоренная цветная версия для MXOS с эффектами ВИ53. |

В корне `assets/games` ускоренная MX-версия публикуется под коротким именем
`Almaz2MX.exe`. Именно эта копия включается в образы flash- и ROM-дисков.

Подкаталог `legacy` хранит промежуточные варианты восстановления и настройки
палитры. Они не публикуются в образы и не считаются текущими версиями игры.
