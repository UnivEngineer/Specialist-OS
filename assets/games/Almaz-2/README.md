# Варианты «Алмаза-2»

В каталоге собраны исходные и новые бинарники игры, загружаемые с адреса `0000h`. В двух вариантх: `rks` и `cpu` (сырой образ с загрузкой и входом 0000h). Оптимизации включают: быстрый диспетчер, адресный ввод, буфер стрелок, квота анимации и сдвиги фаз. На платформах, где есть ВИ53 — неблокирующий звуковой движок эффектов (но не музыки) и отсчёт реального времени в игре.

| Бинарники | Платформа / BIOS | Графика | ВИ53 | Звук и отсчёт времени | Оптимизации |
|---|---|---|---|---|---|
| `Almaz2`                  | Классический «Специалист»                   | Монохром  | Нет  | Программный звук, оригинальная скорость игры | Нет  |
| `Almaz2-optimized`        | Классический «Специалист»                   | Монохром  | Нет  | Программный звук, оригинальная скорость игры | Есть |
| `Almaz2-8color`           | «Специалист» с 8-цветным контроллером «М-К» | 8 цветов  | Нет  | Программный звук, оригинальная скорость игры | Нет  |
| `Almaz2-8color-optimized` | «Специалист» с 8-цветным контроллером «М-К» | 8 цветов  | Нет  | Программный звук, оригинальная скорость игры | Есть |
| `Almaz2-mx`               | «Специалист-MX» / MXOS                      | 16 цветов | Нет  | Программный звук, оригинальная скорость игры | Нет  |
| `Almaz2-mx-optimized`     | «Специалист-MX» / MXOS                      | 16 цветов | Есть | Звук ВИ53, реальные секунды                  | Есть |
| `Almaz2-ramfos`           | «Специалист-RAMFOS» / Ramfos                | 16 цветов | Нет  | Программный звук, оригинальная скорость игры | Нет  |
| `Almaz2-ramfos-optimized` | «Специалист-RAMFOS» / Ramfos                | 16 цветов | Есть | Звук ВИ53, реальные секунды                  | Есть |

Имена внутри образов задаются манифестами. Например, `Almaz2MX.exe` на flash-диске берётся из `Almaz2-mx-optimized.cpu`. Сборка и публикация:

```powershell
powershell.exe -NoProfile -File scripts/build/build-almaz2.ps1 All -PublishMxTimer
```

Суффикс `-optimized` означает все оптимизации, доступные платформе: для MX и RAMFOS это также ВИ53. Восемь вариантов собираются из `source-apps/almaz2`. Ключ `-NoOptimizations` отключает программные оптимизации; имена выходных файлов при этом не меняются. Таблица описывает стандартную сборку без этого ключа.

Подкаталог `legacy` хранит оригинальный классический `Almaz2-original.*`, повреждённый исторический `Almaz2-ramfos-original-broken.*` и пропатченный `Almaz2-ramfos-original-fixed.*`. Исторические MXOS-варианты `Almaz2X-mxos-legacy.bin` и `Almaz2D.cpu` с пользовательской палитрой воспроизводит `scripts/games/repair-almaz2x.py`; известные хеши проверяются до записи. Все эти варианты служат эталонами и не публикуются в образы. Сборщик не создаёт резервных копий, не упаковывает исторические файлы и не записывает данные в `legacy`.

В образе EXE получает 16-байтный контейнер MXOS2. Исходные CPU и RKS не переименовываются в готовый EXE: преобразование выполняет сборщик. EXE передаётся RUN.COM через NC.EXT, без ключа показывается меню среды.

DOS загружается bootstrap и остаётся резидентной в своём банке; приложению не нужны запросы загрузки/освобождения DOS. Устаревшие входы C8D8h/C8DBh удалены. При возврате программа передаёт управление C800h; при аппаратном Reset bootstrap восстанавливает BIOS и шрифт.

Для исправленного MXOptimized проверен запуск из строки NC через RUN -MX и возврат в NC по СТР в Emu80; эта проверка относится к запуску/выходу, а не к прохождению всех уровней.
