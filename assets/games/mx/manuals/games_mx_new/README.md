# Сопроводительные тексты Soft/games_mx_new

Четыре файла сохранены побайтно в Windows-1251. В них указаны авторы адаптаций и управление. Версии для «Специалиста-MX» подготовил Иван Городецкий, рекомпиляцию с Z80 на КР580 выполнил Александр Тимошенко.

| Игра | Описание из архива | Файл в библиотеке |
|---|---|---|
| Cannon Ball | [canball.txt](canball.txt) | [canball.cpu](../../canball.cpu) |
| Color Ball | [clrball.txt](clrball.txt) | [ColorBall.cpu](../../ColorBall.cpu) |
| Driller Tanks | [driller.txt](driller.txt) | [driller.cpu](../../driller.cpu) |
| Fire Rescue | [fire.txt](fire.txt) | [FireRescue.cpu](../../FireRescue.cpu) |

У всех четырёх архивных пар CPU/I80 в описателе указан `m2_d400.mon`.
