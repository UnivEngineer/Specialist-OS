# BUDI до добавления GAME OVER

Побайтные рабочие копии до графического патча 02.11.2026. Файлы неизменяемы; суффикс `.bin` исключает их из автоматического поиска игр. Budi2-mx.rks.bin уже содержит прежние пять замен цветового регистра, остальные соответствуют историческим нагрузкам. Хеши проверяет `scripts/games/patch-budi-game-over.py --check`.

Запись RF-006 в реестре кандидатов RAMFOS ссылается на Budi-ramfos.cpu.bin: пользовательский результат относится к исходному варианту без надписи. Текущая рабочая копия с GAME OVER находится в `../../BUDI/`; сборщик образа упаковывает её в новый EXE с заголовком. Это сохранение исторического результата, а не откат формата EXE.
