# Оригиналы игр до исправлений

Здесь хранятся побайтные входные файлы патчей. Не исправлять их на месте
и не включать в образы как рабочие игры. Суффикс `.bin` после исходного
расширения предотвращает автоматическое включение в коллекцию RKS/EXE.

- `adskok/Adskok.rks.bin` — исходный ADSKOK, SHA-256
  `cdabd464f516f97581f9f32dd35599911eed3cef6eb88c91e15bcbc6ed5b062d`.
- `budi2/BUDI2.rks.bin` — BUDI2 до переноса регистра цвета F000h → FFF8h,
  SHA-256 `449588e8175e752819e24a37d1f9184bbb412e3f359b57d14378d7e6685425fc`.
  Исторические версии семейства теперь также собраны в
  [BUDI/legacy](../BUDI/legacy/), а отдельный патч — в
  [BUDI/Budi2-mx.rks](../BUDI/Budi2-mx.rks).
- [rks-checksums/](rks-checksums/README.md) — Lines, Jet-set, KOM13_1, StarW2
  до исправления хвостов контрольной суммы.
- `almaz2/` — копии исходного монохромного «Алмаза-2» и повреждённого
  исторического RAMFOS-варианта, EXE и RKS. Скопированы побайтно из
  `assets/games/Almaz-2/legacy/`; прежние файлы оставлены для существующих
  ссылок и сценариев. Исправленные и заново собранные варианты оригиналами
  не являются и в этот каталог не добавляются.

Общий реестр изменений: [../README.md](../README.md).
