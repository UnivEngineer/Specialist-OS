# Исходные RKS с неверными хвостами контрольной суммы

Побайтные оригиналы до исправления от 31.10.2026. Расширение `.bin` предотвращает случайное включение этих копий в проверяемую библиотеку RKS.

В `Jet-set.rks`, `KOM13_1.rks` и перенесённом [StarWars2-mx.rks](../../StarWars/legacy/StarWars2-mx.rks) заменены только два байта суммы. В `Lines.rks` один байт хвоста заменён правильной двухбайтной суммой; заголовок и все 18429 байт объявленной нагрузки сохранены.

Сумма рассчитана для имеющейся нагрузки. Исправление контейнера не доказывает целостность исторического кода игры и не восстанавливает неизвестный оригинал. В найденных внешних архивных копиях присутствуют те же несоответствия.

Указанный автором оригинал Lines: `D:/Projects/RetroPC/Specialist/Soft/lines/lines.rks`. Он побайтно совпадает с `Lines.rks.bin`: 18434 байта, SHA-256 `06892a22e898f319cc9dafed1ea7e3f2fe4ec8810955c8c7e2fa1d8114d39bd8`. Других файлов или исходников в этой папке нет. Исправленный контейнер имеет 18435 байт; все 18429 байт объявленной нагрузки и четыре байта заголовка сохранены, единственный хвостовой `FF` заменён на `35 BD`.

Повторяемая правка и проверка всей коллекции:

```powershell
python -X utf8 scripts/games/repair-rks-checksums.py
```

Сценарий проверяет известные SHA-256 оригиналов, сохраняет заголовки и данные, проверяет все RKS вторым вариантом расчёта. Полные хеши и размеры записываются в локальный `docs/games/rks-repair-001.json`; резервные бинарники сохраняются здесь.
