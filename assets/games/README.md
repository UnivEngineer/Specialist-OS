# Игры

В этом каталоге хранится по одной канонической копии каждого игрового
бинарника.

Состав образов `Games2M` и `Games64k` задаётся манифестами в
`scripts/images/manifests/`. Файл, отсутствующий в манифесте, в образ не
попадает.

Исторические варианты для MX и стандартного «Специалиста», перечисленные в
`catalog.csv`, пока не проверены. Остальные файлы происходят из исторической
двухмегабайтной flash-коллекции; их статус пока не ведётся индивидуально.
