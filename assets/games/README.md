# Исправления игр для MXOS

В каталоге хранятся канонические рабочие копии игровых бинарников; архивные оригиналы до исправлений отделены в `originals/`. Состав образов `Games2M` и `Games64k` задаётся манифестами в `scripts/images/manifests/`: файл вне манифеста в образ не попадает.

Исторические варианты для MX и стандартного «Специалиста» перечислены в `catalog.csv`. Наличие файла в каталоге или образе не означает проверенную совместимость. Для остальных игр из исторической двухмегабайтной flash-коллекции индивидуальная функциональная приёмка ещё не выполнена.

Краткий общий реестр изменений игровых бинарников. Исправление контейнера, совместимость с MXOS и проверка игрового процесса — разные результаты. Оригиналы до правок хранятся в [originals/](originals/); суффикс `.bin` исключает архивные копии из автоматического поиска исполняемых игр.

## Реестр RAMFOS-кандидатов

02.11.2026: в [реестр игровых RAMFOS-кандидатов](ramfos-candidates.md) внесены все 62 различные игровые нагрузки с отобранными ABI-признаками. [Машинно читаемый реестр](ramfos-candidates.json) хранит SHA-256, происхождение, копии и смещения вызовов. Сильные/неоднозначные кандидаты отделены от уже известных адаптаций и пользовательских сообщений об ошибках. Наличие в реестре не означает подтверждённую совместимость и не включает файл в образы.

Полные локальные отчёты находятся в `docs/games/` и `docs/compat/`. Для ADSKOK: `docs/compat/adskok-001/RESULTS.md` и `patch-check.json`. Эти отчёты могут отсутствовать в Git; данный реестр, оригиналы и сценарии должны оставаться достаточными для определения внесённого изменения.

Новые исправления добавляются сюда вместе с сохранением исходного файла, точным описанием изменения, способом воспроизведения и фактическим статусом проверки. Неизменённые игры в реестре перечислять не требуется.
