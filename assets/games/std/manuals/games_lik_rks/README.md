# Архив Soft/games_lik_rks

[LIST.TXT](LIST.TXT) сохранён побайтно в CP866. В нём описаны игры, а звёздочка у имени означает, что составитель использовал свою версию «Монитора '88» (`mon-bai2.rks` или snapshot `LIK3.RSS`).

Файлы с расширением RKS в этой подборке состоят из служебного префикса LIK длиной 279 байт, четырёхбайтного диапазона загрузки и игровой нагрузки. После нагрузки двухбайтной суммы Monitor-2 нет.

У шести файлов диапазоны и нагрузки совпали с обычными RKS из коллекции. После добавления штатной суммы эти контейнеры совпадают побайтно.

| Имя в архиве | Файл в коллекции |
|---|---|
| `CHESS.RKS` | [Chess2.rks](../../Chess2.rks) |
| `KLAD.RKS` | [Klad.rks](../../Klad.rks) |
| `KWADRATY.RKS` | [Square.rks](../../Square.rks) |
| `OCHKO.RKS` | [Ochko.rks](../../Ochko.rks) |
| `ROBOT.RKS` | [Robot.rks](../../Robot.rks) |
| `TETRIS-M.RKS` | [Tetris-m.rks](../../Tetris-m.rks) |

Для [ZOO](../../../families/zoo/README.md) сохранены отдельная LIK-редакция, редактор и уровни.

Ещё одиннадцать образов с отдельными нагрузками сохранены в [архивных контейнерах LIK](../../../unknown/games_lik_rks/). Имена файлов и требования к монитору перечислены в общем реестре.
