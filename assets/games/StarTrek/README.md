# StarTrek: удаление символа в MXOS

`StarTrek-mx.exe` — нативное MAIN-приложение MXOS (флаг IMAGE_FLAG_MAIN=04h). В конец тела добавлена точка входа 6B80h: она устанавливает стек 7FFFh, включает KOI7 через bios_setFontEncoding и переходит к оригинальному входу 0000h. Игра запускается по Enter в NC или командой `H:\MXOS\StarTrek.exe`, без выбора среды RUN. Исходное тело отличается от сохранённого `assets/games/Startrek.rks` одним байтом кода: по адресу 1993h операнд `LD C,7Fh` заменён на `20h`. Суммы тела и 16-байтного заголовка MXOS пересчитаны. Манифест Games2M устанавливает исправленный вариант как `H:\MXOS\StarTrek.exe`.

Игра читает клавишу через C337h. Для стрелки влево (08h) адаптер 198Dh–1997h выводит через C037h сначала 08h (курсор влево), затем 7Fh. В MXOS 7Fh — печатный глиф: DEL в KOI8 или Ъ после переключения KOI7. Исправленный вариант выводит пробел. Возвращённый код клавиши остаётся 08h; строковый редактор игры обрабатывает его в 0476h и повторно выводит через RST 18h, возвращая курсор на стёртую позицию. Дополнительный Backspace в адаптер добавлять нельзя.

Патч не меняет BIOS, шрифты, раскладку клавиатуры и остальные программы. Воспроизведение: `python scripts/games/patch-startrek.py`, проверка: `python scripts/games/patch-startrek.py --check`. Игра сохраняет исторические входы Монитора-2 C037h/C337h; стартовый адаптер дополнительно использует bios_setFontEncoding.
