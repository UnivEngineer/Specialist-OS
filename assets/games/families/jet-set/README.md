# Jet Set

Архивный `JET-SET.RKS` из `Soft/games1_rks` побайтно сохранён как [Jet-set.rks.bin](originals/Jet-set.rks.bin). Суффикс `.bin` исключает эту копию из проверки обычных RKS.

31.10.2026 в [Jet-set.rks](repaired/Jet-set.rks) изменены только два байта контрольной суммы, `B6 86` → `69 78`. Заголовок и нагрузка сохранены. Сумма рассчитана по архивной нагрузке. Целостность игрового кода отдельно не проверялась.

Команда `python -X utf8 scripts/games/repair-rks-checksums.py` сверяет SHA-256 исходных файлов, воспроизводит исправление хвостов и независимо проверяет суммы всех обычных RKS. Хеши и размеры записываются в `docs/games/rks-repair-001.json`.
