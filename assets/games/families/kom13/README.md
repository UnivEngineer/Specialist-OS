# «Команда 13»

Игру загружают в порядке `KOM13_1`, затем `KOM13_2`, как указано в архивном `DESCRIPT.ION`.

- [Komanda13-part1.rks](repaired/Komanda13-part1.rks) загружается с `3C00h`. 31.10.2026 в нём изменены только два байта контрольной суммы, `F6 17` → `0A A4`. Заголовок и нагрузка сохранены. [Исходный файл](originals/Komanda13-part1.rks.bin) побайтно совпадает с `Soft/games1_rks/KOM13_1.RKS`. Суффикс `.bin` исключает его из проверки обычных RKS.
- [Komanda13-part2.rks](originals/Komanda13-part2.rks) побайтно совпадает с архивным `KOM13_2.RKS`. Диапазон `0000h–8EFFh` захватывает служебную область RUN, поэтому штатный RUN такой файл целиком не загрузит.

Сумма первой части рассчитана по имеющейся архивной нагрузке. Команда `python -X utf8 scripts/games/repair-rks-checksums.py` сверяет SHA-256 исходных файлов, воспроизводит исправление хвостов и независимо проверяет суммы всех обычных RKS. Хеши и размеры записываются в `docs/games/rks-repair-001.json`.
