# ADSKOK

[Adskok.rks.bin](originals/Adskok.rks.bin) хранит архивный `ADSKOK.RKS` из `Soft/games1_rks`. [Adskok.rks](repaired/Adskok.rks) ограничивает очистку нижним ОЗУ `0000h–2FFFh` и сохраняет байт `D6h`, который игра проверяет после заставки. Прежняя версия с дополнительным вызовом очистки экрана меняла этот байт на `A9h` и останавливалась при входе в игру.

Из NC выполните `RUN H:ADSKOK.RKS -MON`. На заставке нажмите пробел, на первом поле нажмите стрелку вправо. На поле видны игрок, противники и счётчик попыток. В левом верхнем углу может остаться приглашение `PROGRAM ?`. Проверен возврат через Reset с последующим чтением контрольного файла.

Исправленный RKS воспроизводит `python scripts/games/patch-adskok.py`. Ключ `--check` сверяет готовый файл. Для проверки через штатный RUN на тестовом образе Games2M используйте `python scripts/games/trace-adskok.py --installed`. [Реестр изменений](../../README.md#исправления-бинарников).
