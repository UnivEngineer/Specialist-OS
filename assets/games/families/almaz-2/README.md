# Варианты «Алмаза-2»

Варианты игры загружаются с адреса `0000h`. Классические и 8-цветные сборки публикуются как RKS, сборки MXOS и RAMFOS — как EXE v2. Оптимизации включают быстрый диспетчер, адресный ввод, буфер стрелок, квоту анимации и сдвиги фаз. На платформах с ВИ53 используются неблокирующий звуковой движок эффектов и отсчёт реального времени.

| Бинарники | Платформа / BIOS | Графика | ВИ53 | Звук и отсчёт времени | Оптимизации |
|---|---|---|---|---|---|
| `Almaz2`                  | Классический «Специалист»                   | Монохром  | Нет  | Программный звук, оригинальная скорость игры | Нет  |
| `Almaz2-optimized`        | Классический «Специалист»                   | Монохром  | Нет  | Программный звук, оригинальная скорость игры | Есть |
| `Almaz2-8color`           | «Специалист» с 8-цветным контроллером «М-К» | 8 цветов  | Нет  | Программный звук, оригинальная скорость игры | Нет  |
| `Almaz2-8color-optimized` | «Специалист» с 8-цветным контроллером «М-К» | 8 цветов  | Нет  | Программный звук, оригинальная скорость игры | Есть |
| `Almaz2-mx`               | «Специалист-MX» / MXOS                      | 16 цветов | Нет  | Программный звук, оригинальная скорость игры | Нет  |
| `Almaz2-mx-optimized`     | «Специалист-MX» / MXOS                      | 16 цветов | Есть | Звук ВИ53, реальные секунды                  | Есть |
| `Almaz2-ramfos`           | «Специалист-RAMFOS» / Ramfos                | 16 цветов | Нет  | Программный звук, оригинальная скорость игры | Нет  |
| `Almaz2-ramfos-optimized` | «Специалист-RAMFOS» / Ramfos                | 16 цветов | Есть | Звук ВИ53, реальные секунды                  | Есть |

Имена внутри образов задаются манифестами. MXOS запускает `Almaz2MX.exe` напрямую по флагу MAIN. Для `Almaz2RF.exe` используйте `RUN` с `-RF`, для неоптимизированного `Almaz2-mx.exe` с `-MX`.

Сборка и публикация:

```powershell
powershell.exe -NoProfile -File scripts/build/build-almaz2.ps1 All -PublishMxTimer
```

Суффикс `-optimized` означает все оптимизации, доступные платформе: для MX и RAMFOS это также ВИ53. Восемь вариантов собираются из `source-apps/almaz2`. Ключ `-NoOptimizations` отключает программные оптимизации; имена выходных файлов при этом не меняются. Таблица описывает стандартную сборку без этого ключа.

- [`originals/`](originals/) хранит монохромный оригинал `Almaz2-original.cpu` и `Almaz2-original.rks` из нагрузки архивного `ALMAZ-2.RKS` (известной также как `Almaz-2.exe)). Повреждённый RAMFOS-образ `Almaz2-ramfos-original-broken.cpu` побайтно совпадает с `Soft/Lafan/bst_mx0/Games/Gam0/Almaz_2..EXE`. Две ранние сборки из реестра RAMFOS хранятся в [`builds/archive/`](builds/archive/).
- [`repaired/`](repaired/) восстанавливает 27 клеток карт и две надписи SCREEN по монохромному образцу. [Almaz2-ramfos-fixed.cpu](repaired/Almaz2-ramfos-fixed.cpu) хранит исправленный сырой образ для RAMFOS и используется в реестре RF-061. [Almaz2-mxos-repaired.bin](repaired/Almaz2-mxos-repaired.bin), прежний `Almaz2X-mxos-legacy.bin`, также меняет системные адреса для MXOS.
- [`patched/`](patched/) хранит [Almaz2-mxos-custom-palette.cpu](patched/Almaz2-mxos-custom-palette.cpu), прежде `Almaz2D.cpu`. Этот вариант сделан поверх исправленного MXOS-образа. Он добавляет пользовательскую палитру с чёрным фоном, меняет цвет текста HUD и положение TIME/SCREEN. Изменены 32 байта и добавлены 30 байт обработчиков вывода.
- Восемь сборок в таблице выше создаются из ассемблерных исходников и публикуются в [`builds/`](builds/).

Сценарий `python scripts/games/repair-almaz2x.py --check` воспроизводит правки карт, адресов и пользовательской палитры и сверяет эталонные хеши. Эти исторические варианты не входят в штатный состав H:.

Сборщик компонентов упаковывает CPU/I80 из `bin/` в готовые образы. Ключ `-PublishMxTimer` публикует выбранные варианты в `builds/`. Сборщик H: использует эти образы и [общий реестр](../../catalog.csv).

DOS загружается bootstrap и остаётся резидентной в своём банке; приложению не нужны запросы загрузки/освобождения DOS. Устаревшие входы C8D8h/C8DBh удалены. При возврате программа передаёт управление C800h; при аппаратном Reset bootstrap восстанавливает BIOS и шрифт.

Для исправленного MXOptimized проверен запуск из строки NC через RUN -MX и возврат в NC по СТР в Emu80; эта проверка относится к запуску/выходу, а не к прохождению всех уровней.
