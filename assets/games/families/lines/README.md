# Lines

Указанный автором `Soft/lines/lines.rks` побайтно сохранён как [Lines.rks.bin](originals/Lines.rks.bin). Это единственный файл в архивной папке. Размер 18 434 байта, SHA-256 `06892a22e898f319cc9dafed1ea7e3f2fe4ec8810955c8c7e2fa1d8114d39bd8`.

31.10.2026 в [Lines.rks](repaired/Lines.rks) единственный хвостовой байт `FF` заменён двумя байтами `35 BD`. Четырёхбайтный заголовок и все 18 429 байт объявленной нагрузки сохранены. Размер исправленного контейнера — 18 435 байт.

Суффикс `.bin` исключает архивную копию из проверки обычных RKS. Сумма рассчитана по имеющейся нагрузке. Целостность игрового кода отдельно не проверялась.

Команда `python -X utf8 scripts/games/repair-rks-checksums.py` сверяет SHA-256 исходных файлов, воспроизводит исправление хвостов и независимо проверяет суммы всех обычных RKS. Хеши и размеры записываются в `docs/games/rks-repair-001.json`.
