# StarTrek в MXOS

На H: `H:StarTrek.exe` собирается из [StarTrek-std.rks](originals/StarTrek-std.rks), архивного `STARTREK.RKS` из `Soft/games1_rks`. Команда `RUN H:StarTrek.exe -STD` включает STD и KOI-7R с BIOS MXOS. Адрес загрузки и входа `0000h`, игровая нагрузка сохранена побайтно.

Игра читает клавиши через C337h. При стрелке влево обработчик 198Dh–1997h выводит через C037h коды 08h и 7Fh. Первый сдвигает курсор влево, второй стирает знакоместо в KOI-7R. Обработчик возвращает 08h, и строковый редактор игры повторно сдвигает курсор через RST 18h на стёртую позицию.

В прежнем MAIN EXE к исходной нагрузке дописывался 11-байтный адаптер, который выставлял стек и включал KOI-7R. Теперь режим вывода задаёт RUN. В Emu80 запуск из NC дошёл до заставки и вопроса «Вам нужны пояснения?». Сценарий `scripts/tests/check-font-koi7-del.py` проверяет исходный обработчик стирания через BIOS, соседние пиксели и положение курсора.
