MXOS2 для оригинального Специалиста-MXA: - загрузочный носитель. После Reset MX проверяетвнешнюю flash через ВВ55, затем дискету в приводе 0.BIOS, рабочий шрифт и DOS загружаются с одного носителя.При загрузке с flash A: доступен только для чтения.NC_MN и EDIT_MN работают в основной памяти. F4 в NCоткрывает выделенный файл, F10 закрывает редактор.Вручную запустите EDIT_MN для варианта MAIN.Для банкового варианта служат NC и EDIT из DOS.Выбор оболочки: A:\DOS\NC.COM для банкового NCв конце AUTOEXEC.BAT. По умолчанию стартует NC_MN.При 128 КБ ДОЗУ DOS занимает один банк. БанковыйNC удерживает второй. Для F4/F10 используйте MAIN.GUIDE1.TXT - GUIDE3.TXT содержат общее руководствоMXOS2. В нём описаны также программы и оборудованиерасширенной конфигурации MX2. Для этой дискеты см.DRIVERS\README.TXT и FONTS\README.TXT.PATH включает A:\DOS и A:\DRIVERS. ROM64KX.COMподключает внешнюю плату ROM-диска через ВВ55.C: - системное ПЗУ MX на 32 или 48 КиБ.SYSROM C: подключает встроенный драйвер BIOS.Команда есть в A:\AUTOEXEC.BAT. Уберите её иперезагрузитесь, чтобы скрыть C:. Для подключениявведите SYSROM C: в NC или CLI. На C: могут хранитьсяпользовательские файлы. ПЗУ 2 КиБ содержит загрузчик.Игры находятся в A:\GAMES. Руководство Elite:ELITE.TXT, ELITE2.TXT, ELITE3.TXT и ELITE4.TXT.Читайте их по порядку, каждую часть открывайте F4.
