SPECIALIST-OS / MXOSКраткое руководство по системе1. Начало работыПосле загрузки запускается NC. A: - системный диск,B: - RAM, H: - внешний ROM/flash. C:-G: требуют драйверов.Формат MXOS: секторы 256 байт, имена 8.3, без подкаталогов;это не стандартная FAT16.README.TXT (KOI8-R): F4 в NC или A:E.COM A:README.TXT.Выход из E - СТР; соответствие клавише PC задаёт эмулятор.2. Командная строка и DOSФорма запуска:  [диск:]имя.расширение [аргументы]Примеры:  A:DEBUG.COM  A:E.COM H:NOTES.TXT  A:FORMAT.COM B:  A:\DRIVERS\AT2MX.COMБез префикса используется текущий диск. В NC командаA: или H: без имени меняет диск активной панели.Указывайте расширение явно: автоматического поискаимени по списку COM/EXE/BAT нет. Для удобства используйтелатинские буквы в именах и командах.DOS предоставляет загрузку и запуск файлов, файловыеоперации и аппаратные функции через BIOS. ОтдельногоCOMMAND.COM с командами DIR, COPY, DEL, CD, TYPE нет.Просмотр каталога, копирование, удаление и переименованиевыполняются через NC; работа с памятью - через DEBUG.COM.Строка запуска DOS ограничена 128 символами, поле NCкороче. Аргументы разбирает сама запущенная программа.3. NC - файловая оболочкаСтрелки перемещают выбор. Tab меняет активную панель.Home/End переходят к началу/концу списка панели.  F1 - выбрать диск левой панели.  F2 - выбрать диск правой панели.  F3 - сведения о диске на противоположной панели.
       Внизу показаны имя и описание его драйвера.  F4 - открыть выбранный файл в A:E.COM.  F5 - копировать выбранный файл.  F6 - переименовать на том же диске; это не перенос.  F7 - резерв для каталогов, сейчас ничего не делает.  F8 - удалить выбранный файл после подтверждения.  Enter - запустить выбранный файл или введённую строку.  Ctrl+Enter - вставить имя выбранного файла в строку.  Esc - очистить командную строку.  Backspace - стереть последний введённый символ.Функциональные клавиши здесь отличаются от PC NortonCommander: F3 не является просмотром файла.Для копирования выберите источник, нажмите F5 и проверьтеимя назначения. Можно явно указать другую букву диска,например H:FILE.TXT. Enter подтверждает, Esc отменяетдиалог. Копирование идёт порциями через нижнее ОЗУ.Если имя занято, выводится File already exists;файл назначения остаётся без изменений.Для переименования F6 задавайте только новое имя.NC предупреждает при удалении System или Read-only;DOS отклоняет удаление таких файлов на любом диске.Read-only запрещает изменение; System можно изменять.AUTOEXEC.BAT имеет System, README.TXT - обычный файл.Ассоциации Enter задаются файлом A:NC.EXT:  TXT A:E.COM  RKS A:RUN.COM  EXE A:RUN.COMВ каждой строке - три символа расширения, пробел,команда. Имя выбранного файла добавляется как аргумент.Ассоциации действуют при Enter на файле, но не заменяютразбор явно введённой команды. При отсутствии ассоциацииNC пытается обычный запуск через DOS.4. COM, EXE И RKSCOM - родной контейнер MXOS2: заголовок 16 байт, адресазагрузки и запуска, длина и контрольные суммы. DOSисполняет COM. EXE имеет тот же контейнер, но запускаетсячерез RUN.COM. Это не форматы MS DOS или Windows.Адреса больше не записываются в каталог FAT.RKS хранит стандартные адреса начала/конца и суммув конце. NC.EXT передаёт RKS и EXE в A:RUN.COM.  A:RUN.COM -MX H:GAME.COM  A:RUN.COM -STD H:GAME.EXE  A:RUN.COM -RF H:GAME.RKS  A:RUN.COM -MON H:GAME.RKS  A:RUN.COM -MON:Monitor2 H:GAME.EXEБез ключа COM выбирает MX, RKS - MON, EXE спрашиваетрежим: 1 MX, 2 STD, 3 RF, 4 MON, 5 своё ядро MON.В пункте 5 вводится имя файла монитора.MX оставляет аппаратуру и ядро MXOS2. STD включает STD,белый цвет, KOI-7 и останавливает ВИ53. MON дополнительнозаменяет ядро на MONITOR2.MON; RF - на RAMFOS.MON.RET из MX/STD возвращает в MXOS2, из MON/RF загружаетMXOS2 заново. Файловый сервис RAMFOS ещё не подключёнк FAT. SYS оставлено за DOS, MON - сырой образ ядра.Несовместимая игра может запускаться через BAT с явнымключом RUN. Совместимый EXE можно переименовать в COM.Команда без диска и расширения ищется на A: как COM.Например, с H: можно набрать run BUDI-RF.exe.RUN загрузится с A:, а игра - с текущего диска H:.Это правило работает и в BAT.CPU/I80 - формат исходников для сборщика образов,а не готовая программа для запуска в DOS.5. Загрузка и AUTOEXEC.BATПосле холодной загрузки DOS проверяет RAM-диск B:.При отсутствии служебной метки выполняется A:FORMAT.BAT.Штатный FORMAT.BAT содержит A:FORMAT.COM B: -R -Y:он форматирует B: без запроса. Затем однократновыполняется A:AUTOEXEC.BAT, после него - A:NC.COM.Если AUTOEXEC отсутствует или команда не запускается,DOS прерывает BAT и запускает A:\DRIVERS\ROM2M.COM, затем NC.Зависания запущенной программы DOS не обнаруживает.Служебная метка не заменяет резервную копию RAM-диска.AUTOEXEC пропускается при активном сигнале клавиши,проверяемом загрузчиком через клавиатурный ВВ55.При обычном возврате из программы NC загружается снова,а AUTOEXEC повторно не выполняется. Повторная загрузкаDOS из ПЗУ снова включает начальную последовательность.BAT - простой список строк запуска файлов. Каждая строкапередаётся тому же исполнителю, что и командная строка.Допускаются CR, LF и CRLF; размер BAT - до 32 КБ.Не используйте синтаксис Windows: REM, ECHO, IF, GOTO,переменные, конвейеры, перенаправления и вложенные BATтекущим исполнителем не поддерживаются.Драйверы надо установить до команд, использующих их диск.Пример AUTOEXEC для платы внешнего flash-диска:  A:\DRIVERS\AT2MX.COMДля конвейерного варианта замените строку на:  A:\DRIVERS\AT2MXF.COMЭто альтернативы, выполнять обе строки подряд незачем.Обычный профиль эмулятора с 64-КБ ROM-диском использует:  A:\DRIVERS\ROM2M.COMПри ручном подключении системной flash можно выполнить:  A:\DRIVERS\AT512KS.COM  A:\DRIVERS\AT2MX.COMBAT временно загружается в 0000h-7FFFh; после каждойкоманды DOS загружает его снова. Программы могут свободноиспользовать эту область. Адрес из каталога не меняется.Запись A: подключается явной командойA:\DRIVERS\AT512KS.COM в AUTOEXEC.BAT.До выполнения сценария доступно только чтение ROM-Sys.6. Диски и подключаемые драйверыВстроенный драйвер читает системный A: до 512 КБи обслуживает RAM-диск B:. Для чтения A: выше 64 КБустановка FLASHSYS не нужна; она добавляет запись.Файловые функции DOS управляют FAT и каталогом,физический драйвер только передаёт секторы.AT2MX.COM - внешний H: на 1-4 AT29C040A по 512 КиБ.Два чипа дают 1 МиБ, четыре - 2 МиБ. Software IDопределяет число чипов; пустые гнёзда пропускаются.Незнакомый непустой ID отклоняется. AT29C040 без Aне поддерживается: у него физическая страница 512 байт.Запись B=1 ждёт готовности по DQ7; ошибка даёт CF=1.B=5 записывает сектор и сравнивает все 256 байт чтением.AT2MXF.COM использует ту же нумерацию и формат H:,но B=1 оставляет программирование чипа незавершённым.Перед обращением к занятому чипу драйвер ожидает его.DOS распределяет новые кластеры по чипам по очереди.FAT и каталог остаются на первом логическом чипе.B=4 ожидает все отложенные записи; DOS вызывает егопри завершении файловой записи. B=5 - синхронная проверка.AT512KS.COM - запись системного A: через маппер.По ID определяются AT29C010A/C020/C040A (128/256/512 КиБ).Размер страницы записи берётся из ID, а не BPB тома:128 байт у C010A, 256 у C020/C040A. На 128-КиБ чипесектор пишется двумя половинами с ожиданием каждой.Три flash-COM загружаются с 0000h, определяют чипыи копируют резидент: FLASH/FLASHFST в DE00h-DFFFh,FLASHSYS в DC00h-DDFFh. Установщик затем освобождается.При ошибке ID прежний драйвер не перезаписывается.Для /WE, отключённого перемычкой, software ID недоступен;у системного A: в этом случае остаётся встроенное чтение.ROM2M.COM - H: только для чтения, протокол 64-КБ ROM черезВВ55. Это другой аппаратный режим, не замена FLASHна настоящей плате AT29. Он загружается в DE00h.ROM, FLASH и FLASHFST заменяют друг друга. FLASHSYSможет работать одновременно с любым из них.Смена драйвера на работающей системе:  A:\DRIVERS\AT2MX.COMили:  A:\DRIVERS\AT2MXF.COMДрайвер действует до замены или перезагрузки DOS.Возврат в NC сам по себе его не переустанавливает.Смена драйвера и детект не форматируют носитель.Для двух чипов нужен том на 1 МиБ: обрезать готовый2-МиБ образ недостаточно. FORMAT получает размер по B=3,но форматирование уничтожает прежнее содержимое диска.Read-only (01h) и System (04h) запрещают удаление в DOS.System без Read-only допускает изменение содержимого.Read-only запрещает перезапись; эти атрибуты не защищаютот FORMAT или прямых секторных обращений.7. DEBUG.COM - монитор памятиЗапуск: A:DEBUG.COM. Все числовые параметры - HEX,без h и 0x. Буква команды и цифры A-F - заглавные.Параметры отделяются запятыми, без пробелов:  D1000,10FFВо всех примерах начальный адрес не больше конечного.Ниже НАЧ,КОН,АДР - адреса, БАЙТ - значение 00-FF.  DНАЧ,КОН          - дамп памяти в HEX.  LНАЧ,КОН[,МАСКА]  - текстовый ASCII-дамп.  MАДР              - побайтовое редактирование.  FНАЧ,КОН,БАЙТ     - заполнение диапазона.  TНАЧ,КОН,АДР      - копирование вперёд.  CНАЧ,КОН,АДР      - сравнение двух блоков.  SНАЧ,КОН,Б1[,Б2[,Б3[,Б4]]] - поиск 1-4 байтов.  NНАЧ,КОН,БАЙТ     - вывести отличающиеся байты.  KНАЧ,КОН          - контрольная сумма BIOS.  HЧИСЛО1,ЧИСЛО2    - сумма и разность, 16 бит.  GАДР[,СТОП]       - запуск, необязательный останов.  X                 - снимок регистров после останова.  ?                 - каталог текущего диска.  A: ... H:         - выбрать диск.  U                 - загрузить файл по адресу каталога.  VАДР              - загрузить файл в заданный адрес.  BНАЧ,КОН          - сохранить блок в файл.  AАДР              - установить адрес загрузки файла.  Q                 - показать атрибуты файла.  YБАЙТ             - установить атрибуты файла.  J                 - выйти в NC.  WНАЧ,КОН          - историческая запись на ленту.  R[СМЕЩЕНИЕ]       - историческое чтение с ленты.Для дисковых U,V,B,A,Q,Y имя запрашивается отдельно.Для длинных имён удобнее сначала выбрать диск: запросимени в MON2 ограничен 13 символами вместе с префиксом.В M две HEX-цифры записывают байт и двигают адрес вперёд;стрелка вниз пропускает байт, влево возвращает назад.СТР завершает редактирование. Длинный вывод можноприостановить СТР; повторное СТР прекращает команду,другая клавиша продолжает вывод.Диапазоны обычно включают последний адрес. T копируетвперёд, поэтому перекрытие с назначением выше источникаопасно. S не предназначена для строк и имеет ограниченияна перекрывающиеся совпадения и конец диапазона.L фильтрует текст до ASCII: кириллица может стать точками.Список ? может быть неполным для большого каталога.G со вторым параметром меняет байт останова на RST 7и использует вектор 0038h. После останова нельзя простопродолжить программу с восстановленными регистрами.X не показывает регистры на момент ввода команды X.Загрузка U/V, запись B и редактирование памяти не защищаютэкран, стек и сам монитор. Не затрагивайте C000h-FFFFhбез понимания карты памяти. W/R требуют работоспособныхмагнитофонных обработчиков; штатно используйте TAPE.COM.MON2.MON - другой файл! Он нужен LAUNCH для RKS иработает вместо DOS. Не запускайте его как DEBUG.COM.8. E.COM - текстовый редакторЗапуск: A:E.COM [диск:]файл.TXT, либо F4 в NC.Файл редактируется в ОЗУ, а не непосредственно на диске.Предел буфера текущей сборки - примерно 27 КБ.  F1 - вставка/замена; начальный режим - замена.  F2/F3 - страница вверх/вниз.  F4 - открыть файл вместо текста.  F5 - сохранить текст; имя надо проверить самому.  F6 - добавить файл в конец текста.  F7 - поиск с учётом регистра.  F8 - отменить ещё не завершённую правку строки.  Home/End - начало/конец строки.  Tab/Shift+Tab - перемещение по позициям табуляции.  Del - удалить символ в позиции курсора.  СТР - выйти БЕЗ сохранения и без подтверждения.Esc отпускается перед второй клавишей:  Esc,Home / Esc,End - начало / последняя страница.  Esc,L - выделение строк; Esc,U - снять выделение.  Esc,C / Esc,M / Esc,D - копировать/перенести/удалить блок.  Esc,S - разделить строку; Esc,J - соединить две строки.  Esc,N - очистить документ, подтверждение латинской Y.После запуска с именем F5 не гарантирует подстановкуимени аргумента: введите нужное имя, например H:NOTES.TXT.Повторное открытие через F4/F6 в этой версии имеетизвестные ошибки; надёжнее выйти и запустить E с именем.9. Форматирование и прочие программыDISKBEN.COM: File access через DOS, Raw access через драйвер.Введите диск, режим, проходы 0-9 и размер 1-24 КиБ (Enter=8).0=write; 1=проверка всего файла после записи; 2=B=5 по секторам.Проверка и flush входят в WRITE. FLUSH виден при поддержке.На A: READ и Raw WRITE - LOW/HIGH напрямую. Время в мс, кБ/с.TMP создаётся, читается и удаляется; существующий не заменяется.0 проходов: Raw READ без TMP. Q при выборе диска: выход.Flash имеет ограниченный ресурс записи.FORMAT.COM создаёт текущий формат MXOS и уничтожаетпрежнее содержимое выбранного диска.  A:FORMAT.COM B:       - форматировать с запросом.  A:FORMAT.COM B: -R -Y    - RAM-диск B: без запроса.-R устанавливает метку RAM DISK; -Y убирает подтверждение.Диск должен иметь установленный драйвер нужного типа.Для H: с AT29 сначала установите FLASH или FLASHFST.Не форматируйте A:, если не намерены уничтожить систему.TAPE.COM - самостоятельный обмен с магнитофоном:  A:TAPE.COM  L - принять с ленты и сохранить на выбранный диск.  S - передать дисковый файл на ленту.  Esc - выход в NC.Программа использует свой низкоуровневый драйвер и буфердо 36 КБ; старые команды ленты в других утилитах незаменяют её установкой по умолчанию.FONT.FNT - системный шрифт, NC.EXT - ассоциации оболочки.DOS.SYS и NC.COM нужны для загрузки и работы системы.DL-RED.COM и Test-*.COM - отдельные внешние программыи аппаратные тесты; они не добавляют команд в DOS.Часть тестов предназначена для конкретной схемы машины.RAMFOS.MON загружается общим RUN.COM с ключом -RF.Отдельный RAMRUN.COM больше не используется.10. Сохранность данныхRAM-диск теряет данные при отключении питания.Не меняйте драйвер и не сбрасывайте машину во время записи.Перед FORMAT и опытами с MON2 сделайте резервную копию.Код эмулятора не заменяет проверку таймингов на железе.В Emu80 flash оба образа A: и H: и их файлы .sdpхранятся в runtime. Копируйте их при закрытом эмуляторе.Запуск с пересборкой заменяет оба образа новыми.Старые файлы сохраняются в flash-backups. Для продолженияработы без сброса используйте запуск без пересборки.
Драйверы накопителей находятся в A:\DRIVERS.Их описание и ограничения: A:\DRIVERS\README.TXT.При аппаратном Reset AUTOEXEC выполняется зановодля установки драйверов; готовый B: не форматируется.RAMDISK.COM выделяет банки, готовит том B: и передаётих DOS. DLL и отдельный резидент больше не нужны.-P 4: четыре банка данных плюс банк DOS; из 16свободны 11. Reset сохраняет владение DOS и данные.Размер пула фиксирован до холодного старта.
