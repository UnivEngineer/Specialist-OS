SPECIALIST-OS / MXOSКраткое руководство по системе1. Начало работыПосле загрузки DOS запускается файловая оболочка NC.Обычно A: - системный диск, B: - RAM-диск, H: - внешнийROM- или flash-диск. Буквы C:-G: доступны при наличиисоответствующих драйверов; сама буква не создаёт диск.Текущая файловая система - исторический формат MXOSс 256-байтными секторами, а не стандартная FAT16.Подкаталоги пока не поддерживаются. Имена имеют вид 8.3.Эту инструкцию можно открыть клавишей F4 в NC либо так:  A:E.COM A:README.TXTТекст записан в KOI8-R. Для выхода из E нажмите СТР.СТР - клавиша машины; её соответствие клавише PC задаётпрофиль эмулятора. Это не обязательно Ctrl или Esc.2. Командная строка и DOSФорма запуска:  [диск:]имя.расширение [аргументы]Примеры:  A:MON2.COM  A:E.COM H:NOTES.TXT  A:FORMAT.COM B:  A:FLASHCHK.COMБез префикса используется текущий диск. В NC командаA: или H: без имени меняет диск активной панели.Указывайте расширение явно: автоматического поискаимени по списку COM/EXE/BAT нет. Для удобства используйтелатинские буквы в именах и командах.DOS предоставляет загрузку и запуск файлов, файловыеоперации и аппаратные функции через BIOS. ОтдельногоCOMMAND.COM с командами DIR, COPY, DEL, CD, TYPE нет.Просмотр каталога, копирование, удаление и переименованиевыполняются через NC; работа с памятью - через MON2.COM.Строка запуска DOS ограничена 128 символами, поле NCкороче. Аргументы разбирает сама запущенная программа.3. NC - файловая оболочкаСтрелки перемещают выбор. Tab меняет активную панель.Home/End переходят к началу/концу списка панели.  F1 - выбрать диск левой панели.  F2 - выбрать диск правой панели.  F3 - сведения о диске на противоположной панели.  F4 - открыть выбранный файл в A:E.COM.  F5 - копировать выбранный файл.  F6 - переименовать на том же диске; это не перенос.  F7 - резерв для каталогов, сейчас ничего не делает.  F8 - удалить выбранный файл после подтверждения.  Enter - запустить выбранный файл или введённую строку.  Ctrl+Enter - вставить имя выбранного файла в строку.  Esc - очистить командную строку.  Backspace - стереть последний введённый символ.Функциональные клавиши здесь отличаются от PC NortonCommander: F3 не является просмотром файла.Для копирования выберите источник, нажмите F5 и проверьтеимя назначения. Можно явно указать другую букву диска,например H:FILE.TXT. Enter подтверждает, Esc отменяетдиалог. Копирование идёт порциями через нижнее ОЗУ.Если имя занято, выводится File already exists;файл назначения остаётся без изменений.Для переименования F6 задавайте только новое имя.NC предупреждает при удалении System или Read-only;DOS отклоняет удаление таких файлов на любом диске.Read-only запрещает изменение; System можно изменять.AUTOEXEC.BAT имеет System, README.TXT - обычный файл.Ассоциации Enter задаются файлом A:NC.EXT:  TXT A:E.COM  RKS A:LAUNCH.COMВ каждой строке - три символа расширения, пробел,команда. Имя выбранного файла добавляется как аргумент.Ассоциации действуют при Enter на файле, но не заменяютразбор явно введённой команды. При отсутствии ассоциацииNC пытается обычный запуск через DOS.4. COM, EXE и RKSCOM и EXE в MXOS загружаются и запускаются одинаково:по адресу, записанному в каталоге для данного файла.Это не форматы PC DOS COM с адресом 0100h или PE/EXEWindows. Адрес не определяется одним расширением.Системные COM могут размещаться в системном ОЗУ;обычная программа должна соблюдать свою карту памяти.После нормального RET DOS возвращает управление оболочке.Программа, затёршая DOS, не может вернуться таким способом.Адрес загрузки хранится в байтах 12h-13h записи каталога,младшим байтом вперёд. Это расширение MXOS. Копированиечерез NC сохраняет метаданные; простое переименованиерасширения не преобразует программу в другой формат.MON2 позволяет прочитать/изменить адрес директивой A.RKS предназначены для обычного режима Специалиста.Запуск выбранного RKS по Enter использует NC.EXT.Явный запуск:  A:LAUNCH.COM H:GAME.RKSDOS сам по себе RKS не исполняет. LAUNCH загружает файл,затем A:MON2.MON и заменяет им DOS в области C000h.MON2.MON переключает машину в STD-режим и запускаетпрограмму. Возврат в MXOS требует перезагрузки системы;обычный RET игры не восстанавливает затёртое ядро.При включении RKS в образ сборщик извлекает его начальныйи конечный адреса из четырёхбайтного заголовка, сохраняетадрес в каталоге, а на диск записывает полезные данные.Не подменяйте их вручную полным PC-файлом RKS с заголовком.Режим и звук программы зависят также от её варианта:одинаковое имя не делает MXOS-, Ramfos- и STD-игрывзаимозаменяемыми.5. Загрузка и AUTOEXEC.BATПосле холодной загрузки DOS проверяет RAM-диск B:.При отсутствии служебной метки выполняется A:FORMAT.BAT.Штатный FORMAT.BAT содержит A:FORMAT.COM B R Y:он форматирует B: без запроса. Затем однократновыполняется A:AUTOEXEC.BAT, после него - A:NC.COM.Если AUTOEXEC отсутствует или команда не запускается,DOS прерывает BAT и запускает A:ROM.COM, затем NC.Зависания запущенной программы DOS не обнаруживает.Служебная метка не заменяет резервную копию RAM-диска.AUTOEXEC пропускается при активном сигнале клавиши,проверяемом загрузчиком через клавиатурный ВВ55.При обычном возврате из программы NC загружается снова,а AUTOEXEC повторно не выполняется. Повторная загрузкаDOS из ПЗУ снова включает начальную последовательность.BAT - простой список строк запуска файлов. Каждая строкапередаётся тому же исполнителю, что и командная строка.Допускаются CR, LF и CRLF; размер BAT - до 32 КБ.Не используйте синтаксис Windows: REM, ECHO, IF, GOTO,переменные, конвейеры, перенаправления и вложенные BATтекущим исполнителем не поддерживаются.Драйверы надо установить до команд, использующих их диск.Пример AUTOEXEC для платы внешнего flash-диска:  A:FLASHCHK.COMДля конвейерного варианта замените строку на:  A:FLASHFST.COMЭто альтернативы, выполнять обе строки подряд незачем.Обычный профиль эмулятора с 64-КБ ROM-диском использует:  A:ROM.COMПри ручном подключении системной flash можно выполнить:  A:FLASHSYS.COM  A:FLASHCHK.COMBAT временно загружается в 0000h-7FFFh; после каждойкоманды DOS загружает его снова. Программы могут свободноиспользовать эту область. Адрес из каталога не меняется.При системной flash более 64 КБ DOS загружает FLASHSYSдо AUTOEXEC, чтобы прочитать все страницы BAT.6. Диски и подключаемые драйверыВстроенный драйвер DOS обслуживает A: и RAM-диск B:.Дополнительный драйвер - резидентная COM-программа:при запуске она регистрирует обработчик для буквы дискаи возвращается, оставляя свой код в памяти.Она не становится обычной утилитой, которую можно затереть.Файловые функции DOS работают поверх физического драйвера;драйвер блоков не отвечает за каталог и FAT.FLASHCHK.COM - внешний H: на четырёх AT29C040A, до 2 МБ.Каждый сектор записывается последовательно; драйвер ждётзавершения программирования и сравнивает все 256 байт.При ошибке возвращает CF=1 и устанавливает признак BIOS.Это вариант с проверкой правильности записи.FLASHFST.COM - тот же носитель и та же разметка H:,но с отложенной записью. Пока один чип программируется,можно обслуживать другой. Перед обращением к занятомучипу драйвер ожидает его. Выигрыш зависит от расположенияданных: чипы занимают последовательные области по 512 КБ.Запись подряд в один чип не даёт четырёхкратного ускорения.В программном ABI B=4 ожидает все отложенные записи.Замер скорости должен включать это завершение.ROM.COM - H: только для чтения, протокол 64-КБ ROM-дискачерез ВВ55. Это другой аппаратный режим, не заменаFLASHCHK на настоящей плате с AT29.Эти три драйвера занимают DE00h-DFFFh и заменяют другдруга. Для смены на работающей системе запускайте с A:  A:FLASHCHK.COMили:  A:FLASHFST.COMНе меняйте драйвер во время незавершённого обмена.Загрузка с A: также переключает текущий диск, поэтомупри следующем выборе H: DOS получает новую точку входа.Драйвер действует до замены или перезагрузки DOS.Возврат в NC сам по себе его не переустанавливает.Смена драйвера не форматирует и не преобразует диск.FLASHSYS.COM - драйвер записи системного A: через маппер,а не через второй ВВ55. Поддерживает системные чипыAT29C010A/C020/C040A на совместимом оборудовании.Код размещён в DC00h-DDFFh и не заменяет драйвер H:.Он запрашивает подтверждение файловых изменений A:клавишами Enter/Esc через обёртки BIOS.В профиле Emu80 flash A: - записываемая AT29C040Aна 512 КБ, FLASHSYS.COM устанавливается при загрузке.Не запускайте FLASHSYS.COM повторно в той же сессии.Read-only (01h) и System (04h) - атрибуты записи каталога.System сам по себе не запрещает удаление или перезапись.Полной проверки Read-only во всех операциях DOS пока нет.Атрибуты не блокируют FORMAT или прямую запись секторов.7. MON2.COM - монитор памятиЗапуск: A:MON2.COM. Все числовые параметры - HEX,без h и 0x. Буква команды и цифры A-F - заглавные.Параметры отделяются запятыми, без пробелов:  D1000,10FFВо всех примерах начальный адрес не больше конечного.Ниже НАЧ,КОН,АДР - адреса, БАЙТ - значение 00-FF.  DНАЧ,КОН          - дамп памяти в HEX.  LНАЧ,КОН[,МАСКА]  - текстовый ASCII-дамп.  MАДР              - побайтовое редактирование.  FНАЧ,КОН,БАЙТ     - заполнение диапазона.  TНАЧ,КОН,АДР      - копирование вперёд.  CНАЧ,КОН,АДР      - сравнение двух блоков.  SНАЧ,КОН,Б1[,Б2[,Б3[,Б4]]] - поиск 1-4 байтов.  NНАЧ,КОН,БАЙТ     - вывести отличающиеся байты.  KНАЧ,КОН          - контрольная сумма BIOS.  HЧИСЛО1,ЧИСЛО2    - сумма и разность, 16 бит.  GАДР[,СТОП]       - запуск, необязательный останов.  X                 - снимок регистров после останова.  ?                 - каталог текущего диска.  A: ... H:         - выбрать диск.  U                 - загрузить файл по адресу каталога.  VАДР              - загрузить файл в заданный адрес.  BНАЧ,КОН          - сохранить блок в файл.  AАДР              - установить адрес загрузки файла.  Q                 - показать атрибуты файла.  YБАЙТ             - установить атрибуты файла.  J                 - выйти в NC.  WНАЧ,КОН          - историческая запись на ленту.  R[СМЕЩЕНИЕ]       - историческое чтение с ленты.Для дисковых U,V,B,A,Q,Y имя запрашивается отдельно.Для длинных имён удобнее сначала выбрать диск: запросимени в MON2 ограничен 13 символами вместе с префиксом.В M две HEX-цифры записывают байт и двигают адрес вперёд;стрелка вниз пропускает байт, влево возвращает назад.СТР завершает редактирование. Длинный вывод можноприостановить СТР; повторное СТР прекращает команду,другая клавиша продолжает вывод.Диапазоны обычно включают последний адрес. T копируетвперёд, поэтому перекрытие с назначением выше источникаопасно. S не предназначена для строк и имеет ограниченияна перекрывающиеся совпадения и конец диапазона.L фильтрует текст до ASCII: кириллица может стать точками.Список ? может быть неполным для большого каталога.G со вторым параметром меняет байт останова на RST 7и использует вектор 0038h. После останова нельзя простопродолжить программу с восстановленными регистрами.X не показывает регистры на момент ввода команды X.Загрузка U/V, запись B и редактирование памяти не защищаютэкран, стек и сам монитор. Не затрагивайте C000h-FFFFhбез понимания карты памяти. W/R требуют работоспособныхмагнитофонных обработчиков; штатно используйте TAPE.COM.MON2.MON - другой файл! Он нужен LAUNCH для RKS иработает вместо DOS. Не запускайте его как MON2.COM.8. E.COM - текстовый редакторЗапуск: A:E.COM [диск:]файл.TXT, либо F4 в NC.Файл редактируется в ОЗУ, а не непосредственно на диске.Предел буфера текущей сборки - примерно 27 КБ.  F1 - вставка/замена; начальный режим - замена.  F2/F3 - страница вверх/вниз.  F4 - открыть файл вместо текста.  F5 - сохранить текст; имя надо проверить самому.  F6 - добавить файл в конец текста.  F7 - поиск с учётом регистра.  F8 - отменить ещё не завершённую правку строки.  Home/End - начало/конец строки.  Tab/Shift+Tab - перемещение по позициям табуляции.  Del - удалить символ в позиции курсора.  СТР - выйти БЕЗ сохранения и без подтверждения.Esc отпускается перед второй клавишей:  Esc,Home / Esc,End - начало / последняя страница.  Esc,L - выделение строк; Esc,U - снять выделение.  Esc,C / Esc,M / Esc,D - копировать/перенести/удалить блок.  Esc,S - разделить строку; Esc,J - соединить две строки.  Esc,N - очистить документ, подтверждение латинской Y.После запуска с именем F5 не гарантирует подстановкуимени аргумента: введите нужное имя, например H:NOTES.TXT.Повторное открытие через F4/F6 в этой версии имеетизвестные ошибки; надёжнее выйти и запустить E с именем.9. Форматирование и прочие программыFORMAT.COM создаёт текущий формат MXOS и уничтожаетпрежнее содержимое выбранного диска.  A:FORMAT.COM B:       - форматировать с запросом.  A:FORMAT.COM B R Y    - RAM-диск B: без запроса.R устанавливает метку RAM DISK; Y убирает подтверждение.Диск должен иметь установленный драйвер нужного типа.Для H: с AT29 сначала установите FLASHCHK или FLASHFST.Не форматируйте A:, если не намерены уничтожить систему.TAPE.COM - самостоятельный обмен с магнитофоном:  A:TAPE.COM  L - принять с ленты и сохранить на выбранный диск.  S - передать дисковый файл на ленту.  Esc - выход в NC.Программа использует свой низкоуровневый драйвер и буфердо 36 КБ; старые команды ленты в других утилитах незаменяют её установкой по умолчанию.FONT.FNT - системный шрифт, NC.EXT - ассоциации оболочки.DOS.SYS и NC.COM нужны для загрузки и работы системы.DL-RED.COM и Test-*.COM - отдельные внешние программыи аппаратные тесты; они не добавляют команд в DOS.Часть тестов предназначена для конкретной схемы машины.В дополнительном Ramfos-образе могут присутствоватьRAMFOS.SYS и RAMRUN.COM. RAMRUN запускает программус отдельным ядром Ramfos; это не общий режим COM/EXEосновного системного образа. Совместимость экспериментальна.10. Сохранность данныхRAM-диск теряет данные при отключении питания.Не меняйте драйвер и не сбрасывайте машину во время записи.Перед FORMAT и опытами с MON2 сделайте резервную копию.Код эмулятора не заменяет проверку таймингов на железе.В Emu80 flash оба образа A: и H: и их файлы .sdpхранятся в runtime. Копируйте их при закрытом эмуляторе.Запуск с пересборкой заменяет оба образа новыми.Старые файлы сохраняются в flash-backups. Для продолженияработы без сброса используйте запуск без пересборки.
