SPECIALIST-OS / MXOS2Краткое руководство по системе1. Начало работыПосле загрузки открывается файловый менеджер NC.A: - системный ROM/flash-диск, B: - RAM-диск,H: - внешний ROM/flash-диск. Остальные буквы требуютсоответствующих драйверов. Содержимое B: сохраняетсяпри штатном теплом сбросе, но теряется без питания.DOS обслуживает файлы, каталоги и запуск программ.BIOS отвечает за экран, клавиатуру и оборудование.NC и консоль CLI используют общие команды DOS.Имена файлов и каталогов имеют формат 8.3:README.TXT, GAME.EXE. Длинных имен нет. Регистр буквпри поиске не учитывается. Тексты и русские именаиспользуют KOI8-R. Каждый диск помнит свой каталог.Длина пути или команды - не более 127 байт.Открыть эту памятку: F4 на README.TXT в NCили команда E A:\README.TXT.2. Файловый менеджер NCNC учитывает ширину установленного шрифта:4x8 - три колонки, 6x8 - две, 8x8 - однас размером файла или <DIR> справа.FONT Cpm4 / FONT Rotate / FONT Fast8 меняют шрифт.После возврата NC перестраивает свой интерфейс.Длинные пути сокращаются по целым каталогам:A:\Folder\...\File.txt. Сам путь не меняется.Статус при любом шрифте содержит имя и размер,а путь показывается в заголовке панели.Tab переключает активную панель. Ее диск и каталогиспользуются для команд. Другая панель по умолчаниюзадает назначение копирования и перемещения.Обе панели могут показывать разные каталоги одногодиска. Вверх/вниз перемещают выделение и при набраннойкоманде. Текст, позиция курсора и прокрутка строкипри этом сохраняются. Влево/вправо, Home и Endперемещают выделение, когда строка пуста.  Enter    Открыть каталог или запустить файл.           При введенной команде - выполнить ее.  ..       Перейти к родительскому каталогу.В статусе пункта ..: Go to parent dir.Для перехода в корень наберите CD /.  F1/F2    Выбрать диск левой/правой панели.  Shift+F1 Сортировка левой панели.  Shift+F2 Сортировка правой панели.  F3       Информация о диске на другой панели.F3: MAIN - память основного банка; BANK - страницы ДОЗУ. Резерв страниц включает DOS и пул RAM-диска, остальные страницы показаны как свободные. Для накопителя указаны полный и свободный объёмы в КиБ, метка, драйвер, тип и описание. Счётчик файлов текущего каталога здесь не выводится.Режим F3 сохраняется после возврата из программ и CLI. Быстрые сведения показываются до подсчета свободного места; число свободных КиБ дописывается последним.При каждом запуске NC восстанавливает KOI-8.  F4       Открыть выбранный файл в E.COM.  Shift+F4 Новый пустой документ в E.COM.  F5       Копировать файл или дерево каталогов.  F6       Переместить файл или каталог.  Shift+F6 Переименовать на текущей панели.  F7       Создать каталог.  F8       Удалить файл или пустой каталог.  F10      Перейти из NC в консоль CLI.  Ctrl+Enter Добавить полный путь выбранного файла             в командную строку.  Escape   Очистить строку или отменить диалог.На клавиатуре Специалиста роль Ctrl выполняет ПС.В непустой строке влево/вправо двигают курсор текста,Home/End - к началу/концу. Backspace удаляет символслева от курсора; удаления справа по Delete пока нет.Вверх/вниз по-прежнему выбирают файлы панели.Ctrl+Enter добавляет путь выбранного файла. Введитепробел, выберите другой файл и снова нажмитеCtrl+Enter, чтобы добавить ещё один аргумент.Shift показывает второй набор подсказок F-клавиш.В выборе диска буквы A/a, B/b и т. д. сразу выбираютдоступный диск и закрывают диалог.Enter запускает COM/EXE/BAT и файлы с ассоциациейв A:\CLI.EXT. Без ассоциации ничего не происходит:панели и выделение сохраняются. F4 открывает файлв редакторе независимо от его расширения.Сортировка: по имени, расширению или без сортировки.Стрелки/Tab выбирают вариант, Enter/пробел применяют,Escape отменяет. У каждой панели свой порядок.NC показывает до 255 записей; полный список - DIR.Магнитофонные операции в панелях пока не реализованы.Для F5/F6 проверьте путь назначения в диалоге.При совпадении файлов предлагаются:  Yes        Y - заменить файл.  No         N - пропустить файл.  All        A - заменять все совпадающие файлы.  Skip       S - пропускать все совпадения.По умолчанию выбран No; Escape пропускает файл.Ответ для всех действует только в текущей операции.Существующие каталоги объединяются. При ошибке ужескопированные файлы сохраняются, отката нет.При запуске читаются A:\NC.CFG, затемB:\NC-STATE.CFG. Второй переопределяет первый.FileColorUser задаёт цвет группы расширений,FileColorSys - остальных Hidden/System,FileColorDef - остальных файлов. Каталоги белые.COM/EXE/RKS/MON/FNT светло-зелёные, BAT/CFGсветло-красные, TXT голубые, архивы пурпурные.DefaultSortMode: 0 без сортировки, 1 имя, 2 тип.Состояние хранит пути, выбранные имена,прокрутку, сортировку и F3 обеих панелей.Повторное правило расширения меняет его цвет.После выхода из папки курсор остаётся на нейв обновлённом списке родителя.Цвет сохраняется при прокрутке.Инверсия курсора работает и без цвета.При закрытии диалога восстанавливаются изображениеи цвета под ним. Отмена не перерисовывает панели;операция обновляет только затронутый список.3. Консоль CLIF10 или команда CLI открывает консоль.NC или EXIT возвращает файловые панели.CLI не очищает экран после внешней программы;для очистки введите CLS.Стрелки вверх/вниз перебирают последние 32 команды.Вызванную команду можно редактировать: влево/вправодвигают курсор, Home/End - к началу/концу. Backspaceудаляет слева; Delete справа пока не поддерживается.Ввод вставляет символы в позицию курсора, Enterвыполняет команду. Escape очищает строку. История сохраняется в B:\CLI.HST перед внешнейпрограммой и выходом. Если B: недоступен, историятекущего запуска продолжает работать в памяти.Команды ниже работают в CLI, строке NC и BAT.Квадратные скобки обозначают необязательные части;сами скобки вводить не нужно.4. Диски, каталоги и командыDIR [путь] - показать список файлов и каталогов.  DIR H:       Текущий каталог диска H:.  DIR H:\      Корень диска H:.  DIR B:\WORK  Указанный каталог.DIR не меняет диск и каталог приглашения.CD [путь], CHDIR [путь] - сменить каталог.  CD H:\GAMES  Сменить сразу диск и каталог.  CD ..        Перейти к родителю.  CD \         Перейти к корню текущего диска.Без аргумента CD печатает текущий путь, как PWD.Команда H: выбирает сохраненный текущий каталог H:.В путях допустимы разделители \ и / и компоненты . и ..Здесь . означает текущий каталог, .. - родительский.MD путь, MKDIR путь - создать один каталог.RD путь, RMDIR путь - удалить пустой каталог.  MD B:\WORK  RD B:\EMPTYРодительские каталоги должны уже существовать.Корень и текущий каталог удалять нельзя.COPY источник назначение - копировать файл/дерево.  COPY A:\README.TXT B:\WORKНазначением может быть существующий каталог.MOVE источник назначение - переместить файл/каталог.  MOVE B:\WORK\NOTE.TXT B:\NOTE.TXTВнутри тома меняется запись каталога без копированияданных. Между томами сначала выполняется копирование,потом удаляются успешно перенесенные источники.REN источник имя, RENAME источник имя - переименоватьфайл или каталог в том же каталоге.  REN B:\NOTE.TXT NOTES.TXTСуществующее имя назначения не заменяется.DEL файл, ERASE файл - удалить файл.  DEL B:\NOTES.TXTРекурсивное удаление каталогов не поддерживается.ATTRIB [+-R] [+-H] [+-S] [+-A] путь - атрибуты.Без масок показывает атрибуты указанного объекта.  ATTRIB B:\NOTE.TXT  ATTRIB +R B:\NOTE.TXT  ATTRIB -R B:\NOTE.TXTR - только чтение, H - скрытый, S - системный,A - архивный. R/S защищают от удаления. Перед заменойфайла с R сначала снимите этот атрибут.TYPE файл - вывести точное содержимое файла.  TYPE A:\AUTOEXEC.BATОкончания строк не преобразуются: LF переводит строку,CR возвращает курсор к ее началу. Для чтения этойпамятки с окончаниями CR используйте E.COM.PATH [каталоги] - путь поиска программ через ;.  PATH A:\;A:\DRIVERS;B:\TOOLSPATH без аргумента показывает список.PATH ; очищает его. Начальное значение - A:\.CLS - очистить экран.ECHO текст - вывести сообщение.REM текст - комментарий в сценарии.HELP - показать список команд.Шаблоны * и ? пока не поддерживаются. Копированиеили перенос каталога в собственное поддерево запрещен.Заполненный подкаталог пока не расширяется.Ошибки DOS выводятся числовыми кодами.Пример работы:  MD B:\WORK  COPY A:\README.TXT B:\WORK  CD B:\WORK  DIR  E README.TXT5. Запуск программ и утилитыВведите имя программы с аргументами или выберите еев NC и нажмите Enter. Без расширения ищутся COM, EXE,BAT: сначала в текущем каталоге, затем по PATH.Явный диск или разделитель пути отключает поиск PATH.  E B:\WORK\NOTE.TXT  A:\DEBUG.COMCOM/EXE MXOS2 содержат собственный 16-байтный заголовок.Программы с флагами MAIN/DRIVER/BANK запускает DOS.Обычный RET возвращает управление оболочке.DLL предназначены для программ и не запускаютсякак самостоятельная команда.Для старых программ и RKS используется RUN.COM:  RUN -MX H:\GAME.EXE    Режим MX, ядро MXOS2.  RUN -STD H:\GAME.EXE    Стандартный режим, ядро MXOS2.  RUN -MON H:\GAME.RKS    Стандартный режим, ядро A:\MONITOR2.MON.  RUN -RF H:\GAME.EXE    Режим MX, ядро A:\RAMFOS.MON.  RUN H:\GAME.EXE    Меню среды для EXE/COM без флага совместимости.RKS без ключа запускается через Monitor-2.-MON:имя выбирает другое совместимое ядро Monitor-2:  RUN -MON:Monitor2 H:\GAME.RKSБез диска берется A:, без расширения - .MON.Произвольное ядро может оказаться несовместимым.Ключ режима можно ставить до или после имени файла.-KOI7 переключает вывод BIOS в KOI-7 для старых игр:  RUN -MX -KOI7 H:\GAME.EXEMAIN/DRIVER/BANK всегда запускаются нативно, дажечерез RUN. Выбор среды не гарантирует совместимость.Файловые службы RAMFOS к дискам MXOS не подключены.E.COM - текстовый редактор. F4 в NC открывает файл,Shift+F4 - пустой документ. DEBUG.COM - монитор памятии отладчик поверх MXOS. Monitor-2 - отдельное ядродля запуска программ через RUN.6. Настройка: AUTOEXEC и драйверыПри аппаратном запуске выполняется A:\AUTOEXEC.BAT.Он подключает драйверы и подготавливает RAM-диск.При теплом Reset сценарий запускается снова;готовые DOS и B: сохраняются. Обычный возврат изпрограммы AUTOEXEC заново не выполняет.Драйверы находятся в A:\DRIVERS:  AT512KS.COM  Системная flash A:, 128/256/512 КиБ.               AT29C010A/C020/C040A.  AT2MX.COM    Внешний H:, 1-4 AT29C040A, до 2 МиБ.  AT2MXF.COM   Та же MMX-плата; ускоренная запись               с распределением между чипами.  ROM2M.COM    Чтение готового тома MMX, до 2 МиБ.  ROM64K.COM   Простая ROM-плата H:, до 64 КиБ.  RAMDISK.COM  Подготовка RAM-диска B:.Подробности о платах: A:\DRIVERS\README.TXT.Установка внешнего драйвера не форматирует диск.Драйверы MMX не гарантируют работу с другой схемой.Пример AUTOEXEC для системной и внешней flash MMX:  A:\DRIVERS\AT512KS.COM  A:\DRIVERS\AT2MXF.COM  A:\DRIVERS\RAMDISK.COM -P 4  PATH A:\;A:\DRIVERSДля ROM-платы H: выберите ROM64K или ROM2M.До AT512KS встроенный драйвер A: работает на чтение.-P 4 выделяет четыре банка данных по 64 КиБ для B:.Отдельный банк нужен самой DOS. При 16 банках послеэтого свободны 11 для банковых программ и FAR-памяти.Минимум для DOS и B: - два банка, с RAMDISK -P 1.Размер B: выбирается при первоначальной подготовкеи фиксируется до холодного старта. Готовый томпринимается без форматирования. Новую неразмеченнуюпамять RAMDISK подготавливает через FORMAT.7. BAT и ассоциации файловBAT содержит последовательность обычных команд.@ перед командой скрывает только эту строку.ECHO OFF/ECHO ON выключают/включают эхо команд.Можно запускать другой BAT с возвратом к родителю;допускается до восьми уровней вложенности.Ошибка останавливает цепочку: выводятся имя BAT,номер строки и код DOS. Строка команды - до 127 байт.Поддерживаются CR, LF, CRLF и последняя строка безперевода. IF/GOTO/CALL, параметры %1, перенаправления< и > и конвейеры пока не реализованы.В BAT совпадающее имя COPY вызывает ошибку без замены.A:\CLI.EXT задает обработчики расширений для CLI и NC.Формат строки: расширение, пробел, команда.Штатный файл:  TXT A:\E.COM  RKS A:\RUN.COM  EXE A:\RUN.COMИзменения учитываются при следующем запуске файла.Подтвержденные MAIN/DRIVER/BANK обходят ассоциации.Для игры с известным режимом удобно создать BAT:  RUN H:\GAME.EXE -RFAUTOEXEC.BAT и CLI.EXT можно редактировать в E.COMна записываемом A:. Сохраняйте кодировку KOI8-R.8. Форматирование и сохранность данныхFORMAT создает новую файловую систему и уничтожаетпрежний каталог. Для обычного запуска он не нужен.  FORMAT B: -R  Форматировать RAM-диск с вопросом.  FORMAT H:     Форматировать внешний диск с записью.-Y отключает подтверждение. Форматирование A: запрещено.Нынешний FORMAT создает MXOS-256. DOS поддерживаетFAT16 и расширения MXOS-128/256 для малых томов.FAT12, длинные имена, разбор MBR и стандартные драйверыдискет/SD пока отсутствуют. Полная совместимость совсеми FAT16-носителями еще не обеспечена.Перед выключением скопируйте нужные файлы с B:на записываемый энергонезависимый диск. Дождитесьзавершения операций; при ошибке не считайте копиюполной. Теплый Reset не заменяет резервное копирование.Запуск мониторов----------------RUN MONITOR2.MON - Монитор-2, STD.RUN MONWIN.MON - оконный монитор, STD.RUN RAMFOS.MON - оболочка RAMFOS, MX; диски MXOS изолированы.Файлы .MON также запускаются по Enter в NC.Загрузка скрыта чёрным цветом; для возврата из STD-монитора - перезагрузка.FILEOPS.DLL is loaded automatically for COPY/MOVE. ESC cancels COPY, MOVE, DIR and TYPE.DIR, COPY И MOVE: МАСКИ ИМЕНИDIR B:\BENCH\*.COMDIR B:\BENCH\*.COM -SCOPY B:\DATA\*.TXT B:\BACKUPMOVE B:\DATA\*.TXT B:\BACKUPДля COPY/MOVE каталог назначения должен уже существовать.*.* включает имена без расширения, ? означает один символ.-S в DIR включает подкаталоги и вывод полных путей.DEL/ERASE удаляют файлы и деревья каталогов.RD/RMDIR удаляет только пустые каталоги.MKDIR Games/Almaz-2/MXOSСоздаёт недостающие каталоги; тот же путь доступен в F7 NC.
