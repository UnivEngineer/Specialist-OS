SPECIALIST-OS / MXOS2Краткое руководство по системе1. Начало работыAUTOEXEC устанавливает Fast12K, затем запускаетсябанковый файловый менеджер NC.COM.C: - системный ROM/flash-диск, B: - RAM-диск,H: - внешний ROM/flash-диск. Остальные буквы требуютсоответствующих драйверов. Содержимое B: сохраняетсяпри штатном теплом сбросе, но теряется без питания.DOS обслуживает файлы, каталоги и запуск программ.BIOS отвечает за экран, клавиатуру и оборудование.NC и консоль CLI используют общие команды DOS.Имена файлов и каталогов имеют формат 8.3:README.TXT, GAME.EXE. Длинных имен нет. Регистр буквпри поиске не учитывается. Тексты и русские именаиспользуют KOI8-R. Каждый диск помнит свой каталог.Длина пути или команды - не более 127 байт.Открыть эту памятку: F4 на README.TXT в NCили команда EDIT C:\README.TXT.2. Файловый менеджер NCShift+F3 или F9 открывает справку из C:\DOS\NC.HLP.NC учитывает ширину установленного шрифта:4x8 - три колонки, 6x8 - две, 8x8 - однас размером файла или <DIR> справа.FONT Cpm4 / FONT Rotate / FONT Fast8 меняют шрифт.После возврата NC перестраивает свой интерфейс.Длинные пути сокращаются по целым каталогам:A:\Folder\...\File.txt. Сам путь не меняется.Статус при любом шрифте содержит имя и размер,а путь показывается в заголовке панели.Tab переключает активную панель. Ее диск и каталогиспользуются для команд. Другая панель по умолчаниюзадает назначение копирования и перемещения.Обе панели могут показывать разные каталоги одногодиска. Вверх/вниз перемещают выделение и при набраннойкоманде. Текст, позиция курсора и прокрутка строкипри этом сохраняются. Влево/вправо, Home и Endперемещают выделение, когда строка пуста.  Enter    Открыть каталог или запустить файл.           При введенной команде - выполнить ее.  ..       Перейти к родительскому каталогу.В статусе пункта ..: Go to parent dir.Для перехода в корень наберите CD /.  F1/F2    Выбрать диск левой/правой панели.  Shift+F1 Сортировка левой панели.  Shift+F2 Сортировка правой панели.  F3       Информация о диске на другой панели.F3: MAIN - память основного банка; BANK - страницы ДОЗУ. Резерв страниц включает DOS и пул RAM-диска, остальные страницы показаны как свободные. Для накопителя указаны полный и свободный объёмы в КиБ, метка, драйвер, тип и описание. Счётчик файлов текущего каталога здесь не выводится.Режим F3 сохраняется после возврата из программ и CLI. Быстрые сведения показываются до подсчета свободного места; число свободных КиБ дописывается последним.При каждом запуске NC восстанавливает KOI-8.  F4       Открыть выбранный файл в EDIT.COM.  Shift+F4 Новый пустой документ в EDIT.COM.  F5       Копировать файл или дерево каталогов.  F6       Переместить файл или каталог.  Shift+F6 Переименовать на текущей панели.  F7       Создать каталог.  F8       Удалить файл или пустой каталог.  F10      Перейти из NC в консоль CLI.  Ctrl+Enter Добавить полный путь файла и пробел             в командную строку.  Escape   Очистить строку или отменить диалог.На клавиатуре Специалиста роль Ctrl выполняет ПС.В непустой строке влево/вправо двигают курсор текста,Home/End - к началу/концу. Backspace удаляет символслева от курсора; удаления справа по Delete пока нет.Вверх/вниз по-прежнему выбирают файлы панели.Ctrl+Enter добавляет полный путь файла и пробел.Выберите другой файл и снова нажмите Ctrl+Enter,чтобы добавить ещё один аргумент.Shift показывает второй набор подсказок F-клавиш.В выборе диска буквы A/a, B/b и т. д. сразу выбираютдоступный диск и закрывают диалог.Enter запускает COM/EXE/BAT и файлы с ассоциациейв C:\DOS\CLI.EXT. Без ассоциации ничего не происходит:панели и выделение сохраняются. F4 открывает файлв редакторе независимо от его расширения.Сортировка: по имени, расширению или без сортировки.Стрелки/Tab выбирают вариант, Enter/пробел применяют,Escape отменяет. У каждой панели свой порядок.NC показывает до 255 записей; полный список - DIR.Магнитофонные операции в панелях пока не реализованы.Для F5/F6 проверьте путь назначения в диалоге.При совпадении файлов предлагаются:  Yes        Y - заменить файл.  No         N - пропустить файл.  All        A - заменять все совпадающие файлы.  Skip       S - пропускать все совпадения.По умолчанию выбран No; Escape пропускает файл.Ответ для всех действует только в текущей операции.Существующие каталоги объединяются. При ошибке ужескопированные файлы сохраняются, отката нет.При запуске читаются C:\DOS\NC.CFG, затемB:\NC-STATE.CFG. Второй переопределяет первый.FileColorUser задаёт цвет группы расширений,FileColorSys - остальных Hidden/System,FileColorDef - остальных файлов. Каталоги белые.COM/EXE/RKS/MON/FNT светло-зелёные, BAT/CFGсветло-красные, TXT голубые, архивы пурпурные.DefaultSortMode: 0 без сортировки, 1 имя, 2 тип.Состояние хранит пути, выбранные имена,прокрутку, сортировку и F3 обеих панелей.Повторное правило расширения меняет его цвет.После выхода из папки курсор остаётся на нейв обновлённом списке родителя.Цвет сохраняется при прокрутке.Инверсия курсора работает и без цвета.При закрытии диалога восстанавливаются изображениеи цвета под ним. Отмена не перерисовывает панели;операция обновляет только затронутый список.3. Консоль CLIF10 или команда CLI открывает консоль.EXIT возвращает предыдущий профиль NC.NC запускает банковый профиль. Для тестов доступныNC_MN.COM и EDIT_MN.COM. Для запуска NC_MN сначалаустановите FONT 6x8/Rotate.CLI не очищает экран после внешней программы;для очистки введите CLS.Стрелки вверх/вниз перебирают последние 32 команды.Вызванную команду можно редактировать: влево/вправодвигают курсор, Home/End - к началу/концу. Backspaceудаляет слева; Delete справа пока не поддерживается.Ввод вставляет символы в позицию курсора, Enterвыполняет команду. Escape очищает строку. История сохраняется в B:\CLI.HST перед внешнейпрограммой и выходом. Если B: недоступен, историятекущего запуска продолжает работать в памяти.Команды ниже работают в CLI, строке NC и BAT.Квадратные скобки обозначают необязательные части;сами скобки вводить не нужно.4. Диски, каталоги и командыDIR [путь] - показать список файлов и каталогов.  DIR H:       Текущий каталог диска H:.  DIR H:\      Корень диска H:.  DIR B:\WORK  Указанный каталог.DIR не меняет диск и каталог приглашения.CD [путь], CHDIR [путь] - сменить каталог.  CD H:\GAMES  Сменить сразу диск и каталог.  CD ..        Перейти к родителю.  CD \         Перейти к корню текущего диска.Без аргумента CD печатает текущий путь, как PWD.Команда H: выбирает сохраненный текущий каталог H:.В путях допустимы разделители \ и / и компоненты . и ..Здесь . означает текущий каталог, .. - родительский.MD путь, MKDIR путь - создать один каталог.RD путь, RMDIR путь - удалить пустой каталог.  MD B:\WORK  RD B:\EMPTYРодительские каталоги должны уже существовать.Корень и текущий каталог удалять нельзя.COPY источник назначение - копировать файл/дерево.  COPY C:\README.TXT B:\WORKНазначением может быть существующий каталог.MOVE источник назначение - переместить файл/каталог.  MOVEDIT B:\WORK\NOTE.TXT B:\NOTE.TXTВнутри тома меняется запись каталога без копированияданных. Между томами сначала выполняется копирование,потом удаляются успешно перенесенные источники.REN источник имя, RENAME источник имя - переименоватьфайл или каталог в том же каталоге.  REN B:\NOTE.TXT NOTES.TXTСуществующее имя назначения не заменяется.DEL файл, ERASE файл - удалить файл.  DEL B:\NOTES.TXTРекурсивное удаление каталогов не поддерживается.ATTRIB [+-R] [+-H] [+-S] [+-A] путь - атрибуты.Без масок показывает атрибуты указанного объекта.  ATTRIB B:\NOTE.TXT  ATTRIB +R B:\NOTE.TXT  ATTRIB -R B:\NOTE.TXTR - только чтение, H - скрытый, S - системный,A - архивный. R/S защищают от удаления. Перед заменойфайла с R сначала снимите этот атрибут.TYPE файл - вывести точное содержимое файла.  TYPEDIT A:\AUTOEXEC.BATОкончания строк не преобразуются: LF переводит строку,CR возвращает курсор к ее началу. Для чтения этойпамятки с окончаниями CR используйте EDIT.COM.PATH [каталоги] - путь поиска программ через ;.  PATH A:\;C:\DRIVERS;B:\TOOLSPATH без аргумента показывает список.PATH ; очищает его. Начальное значение - A:\.CLS - очистить экран.ECHO текст - вывести сообщение.REM текст - комментарий в сценарии.HELP - показать список команд.Шаблоны * и ? пока не поддерживаются. Копированиеили перенос каталога в собственное поддерево запрещен.Заполненный подкаталог пока не расширяется.Ошибки DOS выводятся числовыми кодами.Пример работы:  MD B:\WORK  COPY C:\README.TXT B:\WORK  CD B:\WORK  DIR  EDIT README.TXT5. Запуск программ и утилитыВведите имя программы с аргументами или выберите еев NC и нажмите Enter. Без расширения ищутся COM, EXE,BAT: сначала в текущем каталоге, затем по PATH.Явный диск или разделитель пути отключает поиск PATH.  EDIT B:\WORK\NOTE.TXT  C:\DOS\DEBUG.COMCOM/EXE MXOS2 содержат собственный 16-байтный заголовок.Нативные MAIN/DRIVER/BANK загружает DOS.RET возвращает программу в вызывающую оболочку.DLL загружаются как модули.Совместимые COM/EXE и RKS запускает RUN.COM:  RUN -MX H:\GAME.EXE    Ядро MXOS2, BIOS RAMFOS, аппаратура MX.  RUN -STD H:\GAME.EXE    Ядро MXOS2, BIOS Monitor-2, аппаратура STD.    RET или JMP C000h восстанавливает MX и оболочку.  RUN -MON H:\GAME.RKS    Подмена ядра C:\DOS\MONITOR2.MON, аппаратура STD.  RUN -RF H:\GAME.EXE    Подмена ядра C:\DOS\RAMFOS.MON, аппаратура MX.  RUN H:\GAME.EXE    Режим из заголовка. AUTO и RKS используют RAMFOS/MX.-MON:имя задаёт сменный Monitor-2:  RUN -MON:Monitor2 H:\GAME.RKSБез диска используется C:\DOS\, расширение по умолчанию .MON.Явный ключ имеет приоритет над режимом в заголовке.Оболочка сменного ядра принимает RET. Для MXOS нужен Reset.Ключ режима можно указать до или после имени файла.-KOI7 выбирает кодировку KOI-7 в режиме MX:  RUN -MX -KOI7 H:\GAME.EXEПодключённые BANK и DRIVER используют только DOS.Сменные ядра не используют файловые службы MXOS.EDIT.COM 6.0 - текстовый редактор. F4 в NC открывает файл,Shift+F4 - новый документ. Шрифты 6x8 и 8x8:64 и 48 колонок; 23 строки, длинные строкипрокручиваются горизонтально. Ln/Col имеют 4 места.Большие значения показаны ####, без усечения позиции.В меню также TAB, INSERT/OVR и реальный LAT/RUS.При необходимости справа и снизу видны полосыпрокрутки. Нижняя учитывает все видимые строки.Удерживайте Shift для файлового набора.Без Shift:  F1 Ins    F2 Help     F3 Find   F4 Mark  F5 Copy   F6 Move     F7 Next   F8 DelС Shift:  F1 Tab    F2 Help     F3 New    F4 Load  F5 Save   F6 App      F9 Hex    F10 ExitApp (Append) добавляет файл в конец документа.Shift+F9 открывает HEX, F9 возвращает в текст.F10 выходит из редактора.HEX: адрес, байты, сумма блока через каждые 256 байт.0-9 и A-F заменяют тетраду сразу. Сначала старшая,затем младшая. Стрелки начинают со старшей.Суммы строки и блока обновляются после ввода.6x8: F6 переключает CS, KOI7-R, KOI8-R и All.В 4x8 и 8x8 F6 меняет кодировку символов.F7 переключает файл и режим контейнера.Заголовок адресуется от начала файла, тело - от Load.F8 пересчитывает и записывает суммы контейнера.Вверх/вниз перемещают курсор на один ряд данных.F4 выделяет байты, F5 сохраняет файл.F4: начать выделение символов, зафиксировать, снять.F5/F6 вставляют копию/переносят диапазон у курсора.Можно выбирать части строк, Tab и переводы строк.Backspace/Delete/F8 удаляют выбранный диапазон.При выделении стрелки расширяют блок. Послефиксации можно выбрать место Copy/Move курсором.F8 удаляет блок, а без блока - символ справа.Esc-меню и Esc-команды удалены.Shift+F1 меняет ширину Tab 2/4/6/8.Справка Help выводится без курсора. Текст в C:\DOS\EDIT.HLP.Стрелки листают справку по строке, Ctrl+вверх/вниз -по странице, Home/End - к началу и концу.Для файлов больше 4096 байт появляются окнаLoading... и Saving... При запуске с именемфайла сначала открывается окно редактора.По умолчанию Tab=4; в файле хранится байт 09h.На экране Tab развёрнут пробелами, Col учитывает ширину.F3 Find ищет от курсора, F7 Next - после курсора,с переходом через конец документа к началу.Поиск регистрозависимый; Enter - поиск, Esc - отмена.Текст не найден - информация, а не ошибка.Help и Information используют чёрный текст.Стрелки переходят через границы строк.Ctrl+вверх/вниз - PgUp/PgDn, шаг 21 строка.Ctrl+влево/вправо - предыдущее/следующее слово,включая переход через границы и пустые строки.Home/End - начало/конец строки.Ctrl+Home/End - начало/конец документа (Ctrl = ПС).Backspace удаляет слева, Shift+Backspace - справа.На границе удаление соединяет строки.Enter разбивает строку у курсора без автоотступа.Ctrl+Z отменяет правки последней строки.Навигация сохраняет снимок, новая правка другойстроки заменяет его. Разбиение и слияние сбрасывают.Отмена возвращает курсор в строку снимка.РУС/ЛАТ меняет язык, Shift - регистр и знаки на цифрах.Shift+РУС/ЛАТ - Caps Lock. LAT/RUS не зависит от Shift.F10 или СТР (F12) - выход. New/Load и выход приизменениях задают Save changes? Save/Discard/Cancel.Esc отменяет; Enter или S/D/C подтверждают.CR/LF/CRLF сохраняются в исходном виде.Пустой файл сохраняется с длиной 0. Управляющиесимволы, включая NUL, видны как пробелы.FFh - обычный глиф.Правка печатает хвост поверх старого без стирания,удалённый Tab учитывается по полной визуальной ширине.Gap buffer ускоряет ввод рядом; навигация текстне переносит. Размер файла ограничен свободной MAIN.Ошибки редактора - окна NC, закрыть Enter/Esc.Ошибки запуска - обычный текст до Enter; копирайтвыводится без очистки консоли. Магнитофонных функций нет.DEBUG.COM - монитор памяти и отладчик MXOS.Monitor-2 - отдельное ядро для запуска через RUN.6. Настройка: AUTOEXEC и драйверыПри загрузке MX с дискеты A: команда SYSROM C:подключает системное ПЗУ 32/48 КБ только для чтения.Её можно ввести в NC, CLI или в A:\AUTOEXEC.BAT.Чтобы скрыть C:, уберите команду из AUTOEXEC иперезагрузитесь. В MMX загрузочный C: уже доступен;AT512KS.COM -LETTER C включает запись во flash.При аппаратном запуске выполняется A:\AUTOEXEC.BAT.Он подключает драйверы и подготавливает RAM-диск.При теплом Reset сценарий запускается снова;готовые DOS и B: сохраняются. Обычный возврат изпрограммы AUTOEXEC заново не выполняет.Драйверы находятся в C:\DRIVERS:  AT512KS.COM  Системная flash A:, 128/256/512 КиБ.               AT29C010A/C020/C040A.  AT2MX.COM    Внешний H:, 1-4 AT29C040A, до 2 МиБ.  AT2MXF.COM   Та же MMX-плата; ускоренная запись               с распределением между чипами.  ROM2MX.COM    Чтение готового тома MMX, до 2 МиБ.  ROM64KX.COM   Простая ROM-плата H:, до 64 КиБ.  RAMDISK.COM  Подготовка RAM-диска B:.Подробности о платах: C:\DRIVERS\README.TXT.Установка внешнего драйвера не форматирует диск.Драйверы MMX не гарантируют работу с другой схемой.Пример AUTOEXEC для системной и внешней flash MMX:  C:\DRIVERS\AT512KS.COM  C:\DRIVERS\AT2MXF.COM  C:\DRIVERS\RAMDISK.COM -P 4  PATH A:\;C:\DRIVERSДля ROM-платы H: выберите ROM64KX или ROM2MX.До AT512KS встроенный драйвер A: работает на чтение.-P 4 выделяет четыре банка данных по 64 КиБ для B:.Отдельный банк нужен самой DOS. При 16 банках послеэтого свободны 11 для банковых программ и FAR-памяти.Минимум для DOS и B: - два банка, с RAMDISK -P 1.Размер B: выбирается при первоначальной подготовкеи фиксируется до холодного старта. Готовый томпринимается без форматирования. Новую неразмеченнуюпамять RAMDISK подготавливает через FORMAT.7. BAT и ассоциации файловBAT содержит последовательность обычных команд.@ перед командой скрывает только эту строку.ECHO OFF/ECHO ON выключают/включают эхо команд.Можно запускать другой BAT с возвратом к родителю;допускается до восьми уровней вложенности.Ошибка останавливает цепочку: выводятся имя BAT,номер строки и код DOS. Строка команды - до 127 байт.Поддерживаются CR, LF, CRLF и последняя строка безперевода. IF/GOTO/CALL, параметры %1, перенаправления< и > и конвейеры пока не реализованы.В BAT совпадающее имя COPY вызывает ошибку без замены.C:\DOS\CLI.EXT задает обработчики расширений для CLI и NC.Формат строки: расширение, пробел, команда.Штатный файл:  TXT C:\DOS\EDIT.COM  RKS C:\DOS\RUN.COM  EXEDIT C:\DOS\RUN.COMИзменения учитываются при следующем запуске файла.Подтвержденные MAIN/DRIVER/BANK обходят ассоциации.Для игры с известным режимом удобно создать BAT:  RUN H:\GAME.EXE -RFAUTOEXEC.BAT и CLI.EXT можно редактировать в EDIT.COMна записываемом A:. Сохраняйте кодировку KOI8-R.8. Форматирование и сохранность данныхFORMAT создает новую файловую систему и уничтожаетпрежний каталог. Для обычного запуска он не нужен.  FORMAT B: -R  Форматировать RAM-диск с вопросом.  FORMAT H:     Форматировать внешний диск с записью.-Y отключает подтверждение. Форматирование A: запрещено.Нынешний FORMAT создает MXOS-256. DOS поддерживаетFAT16 и расширения MXOS-128/256 для малых томов.FAT12, длинные имена, разбор MBR и стандартные драйверыдискет/SD пока отсутствуют. Полная совместимость совсеми FAT16-носителями еще не обеспечена.Перед выключением скопируйте нужные файлы с B:на записываемый энергонезависимый диск. Дождитесьзавершения операций; при ошибке не считайте копиюполной. Теплый Reset не заменяет резервное копирование.Запуск мониторов----------------RUN MONITOR2.MON - Монитор-2, STD.RUN MONWIN.MON - оконный монитор, STD.RUN RAMFOS.MON - оболочка RAMFOS, MX; диски MXOS изолированы.Файлы .MON также запускаются по Enter в NC.Загрузка скрыта чёрным цветом; для возврата из STD-монитора - перезагрузка.FILEOPS.DLL is loaded automatically for COPY/MOVE. If neither shell can load, BIOS asks:Shell path:Enter a native shell path, for example B:\NC.COM.An invalid path returns to the same BIOS input prompt.This prompt accepts a shell filename, not DOS commands.DIR prints No matching files for an empty result.This is success: BAT continues to its next command.An invalid parent path returns an error and stops BAT.Банковый NC-----------NC.COM загружает NC_CORE.DLL и UI_GFX.DLLиз корня своего диска.F10 возвращает в CLI с сохранением панелей.Ctrl+F10 освобождает банковый NC.EXIT в CLI возвращает предыдущий профиль.
EXE source target converts RKS/RAW/EXE and edits image headers.
EXE H:\GAME.RKS B:\GAME.EXE -F:MAIN -B:0 -MODE:MX
The source is preserved. -MODE:STD/MON/RF selects a legacy environment.
FONT is restored after whole-MAIN applications and warm Reset.
Штатный EDIT.COM загружает банковый EDIT.Запуск: EDIT H:/ELITE.TXT. Нужен свободный банк вне пула B:.Документ и поиск находятся в EXEC, вывод и кэш строк - в MAIN.Банковый буфер вмещает около 40 КБ. Буфер EDIT_MN зависит от memTop.F4 в NC открывает файл в банковом редакторе.Enter на TXT делает то же при штатной ассоциации.F10 возвращает на выбранный файл, а при запуске из CLI - в CLI.EDITCORE.DLL лежит рядом с EDIT.COM, UI_GFX.DLL - на A:.В MAIN редактор закрывает окна перерисовкой, без буфера фона.В BANK фон окна хранится в MAIN и возвращается битмапом.
