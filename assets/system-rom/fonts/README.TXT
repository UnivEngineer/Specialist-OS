Сменные шрифты MXOS==================Установка из командной строки:  FONT 6x8/Rotate  FONT 6x8/Compact  FONT 6x8/Packed6K  FONT 6x8/Fast12K  FONT 8x8/Fast8  FONT 4x8/Cpm4Путь без буквы диска отсчитывается от A:\FONTS.Расширение .dll можно опустить. / и \ равнозначны.Алгоритмы---------Rotate 6x8: полный шрифт, сдвиги вычисляются при выводе.Четверка символов дает три байта без чтения экрана.Для одиночных символов и краев используются маски.Compact 6x8: компактный FONTKOI, 162 глифа, включаяе с точками (коды A3/B3). Таблица индексов 256 байт.Посимвольные сдвиги; строки сохраняют регистры одинраз. Нет четверок и пререндера. Недостающие глифырисуются пробелом, в том числе часть псевдографики.Packed6K 6x8: четыре копии 6-битной строки упакованыв три байта. Всего 6 КБ данных: 2 КБ сверху и 4 КБв MAIN. Четверки объединяются масками без чтенияэкрана. Одиночные глифы используют упакованный COL6PRE.Fast12K 6x8: исходная фаза в верхнем шрифте, пятьсдвинутых плоскостей занимают 10 КБ MAIN. Четверкисливаются через OR, скалярный COL6PRE рисует постолбцам. Обычные и инверсные ядра разделены.Fast8 8x8: полный шрифт оконного монитора. Восемьстраниц по 256 байт. Глиф копируется без сдвигов имасок; восемь строк развернуты. Строковый путь держитуказатели текста и экрана в регистрах.Cpm4 4x8: шрифт CP/M Сябра. В каждом байте повтореныдва одинаковых полубайта. Пары дают полный байт безчтения экрана; одиночные символы сохраняют соседнийполубайт. Все восемь строк развернуты.У всех движков пять текстовых входов BIOS, инверсия,управляющие коды и физическое переключение KOI7/8.Управляющие коды и ESC обрабатывает BIOS. Raw рисуетих как глифы; RawZ заканчивается нулем, RawLim - длиной.Межстрочный шаг пока общий: 10 пикселей. Вывод 8x8/4x8выровнен на знакоместо: произвольный X округляетсявлево. Старые интерфейсы с координатами под 6x8,включая панели NC, не адаптируются автоматически.Память------Движок и шрифт занимают слот D800-EC7F, ниже F000.Компактный модуль: 3088 байт; остальные: 5120 байт,включая выравнивание. Временный Init*.dll не резидентен.Движок       MAIN, байт   memTop без иных резервацийRotate               0   8BFFCompact              0   8BFFPacked6K          4096   7BFFFast12K          10240   63FFFast8                0   8BFFCpm4                 0   8BFFFONT меняет резервацию через MEM. После его выходаNC перечитывает memTop и меняет емкость каталогов.STD-программы могут игнорировать memTop: совместимостьс таблицами MAIN проверяется для каждой программы.Скорость вывода, мс------------------FontBen, Emu80, CPU и ВИ53 2 МГц, 2026-11-13; Fast8: 2026-11-14.MAIN, прямой BIOS ABI, обычный цвет, без подготовки.Один корпус README: 24 строки по 46 символов + CRLF,1152 байтов. StringZ обрабатывает CRLF, RawLim рисуетих глифы. При разной ширине площадь вывода разная.Это эмуляторный замер, не физическое оборудование.Движок         StringZ     RawLimRotate         398.208    352.384Compact        654.336    628.096Packed6K       289.152    235.648Fast12K        242.048    187.392Fast8          181.248    158.848Cpm4           172.288    139.136Обычные и инверсные ядра раздельны во всех модулях.В обычном пиксельном цикле нет проверки инверсиии пустых XOR/NOP. Cpm4 обрабатывает пары через стек;Fast8 держит указатели в регистрах. Счётчик пакета8-битный, курсор обновляется после пакета.FontBen актуальные standalone собирает тот же код, что FONT DLL.KOI7/8: штатный bios_setFontEncoding, A=0 для KOI8,A<>0 для KOI7; регистры сохраняются. Переставляютсябитмапы и пререндер, у Compact - индексы. В горячемцикле нет перекодирования. Повторный выбор безопасен.Короткое имя ищется в A:\FONTS, затем в 6x8, 8x8, 4x8.Например: FONT Packed6K или FONT Fast8.Явный путь используется без поиска.Файлы и импорт--------------.fnt - готовый движок со шрифтом; .pf - плоские256 глифов по 8 байт; .pre - нижние таблицы без CS.FONT 6x8/Fast12K -FILEчитает готовый .pre вместо генерации. Без -FILEтаблицы строит временный инициализатор.FONT 8x8/Fast8 -IMPORT A:/MyFont.pfимпортирует 2048 байт и устанавливает результат.Для Cpm4 используются младшие 4 бита каждой строки.Новый комплект сохраняется на доступный RAM-диск,обычно B:. Явное назначение: -OUT B:/Custom.fnt.Инициализатор сохраняется рядом; .pre - если нужен.Если RAM-диска нет, шрифт установлен, но не сохранен.При ошибке записи могут остаться частичные файлы.Пример загрузки сохраненного комплекта:  FONT B:/Custom.fnt -FILEBootstrap загружает выбранный сборщиком модуль безнижних таблиц; по умолчанию Rotate. Fast12K/Packed6Kустанавливаются командой FONT после старта DOS..DLL - ВРЕМЕННЫЕ ИНИЦИАЛИЗАТОРЫ, НЕ ДВИЖКИ.FONT ИЩЕТ КОРОТКИЕ ИМЕНА ТОЛЬКО С .FNT.COMPACT: НЕТ СИМВОЛА - РИСУЕТСЯ DEL (7F),ПУСТОЙ ПРЯМОУГОЛЬНИК.ENTER НА .FNT В NC УСТАНАВЛИВАЕТ ШРИФТ..PF - ПИКСЕЛЬНЫЙ ШРИФТ ДЛЯ ИМПОРТА.FAST8: KOI8-R, Е С ТОЧКАМИ В A3/B3, ТВЕРДЫЙ ЗНАК FF.ПСЕВДОГРАФИКА 80-BF СООТВЕТСТВУЕТ KOI8-R.
