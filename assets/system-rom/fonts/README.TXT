Сменные шрифты MXOS==================Установка движков из командной строки  FONT 6x8/Rotate  FONT 6x8/Packed  FONT 6x8/Fast  FONT 8x8/Rotate  FONT 8x8/Packed  FONT 8x8/Fast  FONT 4x8/FastПуть без буквы диска отсчитывается от A:\FONTS.Укажите папку, например FONT 6x8/Packed.Разделители / и \ равнозначны. Суффикс .fnt необязателен.В NC нажмите Enter на файле .fnt.Алгоритмы---------Rotate 6x8: полный шрифт, сдвиги вычисляются при выводе.Четверки рисуются по три байта на пиксельную строку.Полные байты пишутся без чтения экрана.Для одиночных символов и краев используются маски.6x8/Packed: четыре копии 6-битной строки упакованыв три байта. Всего 6 КБ данных: 2 КБ сверху и 4 КБв MAIN. Четверки объединяются масками без чтенияэкрана. Одиночные глифы используют упакованный COL6PRE.6x8/Fast: всего 12 КБ данных. Исходная фазазанимает 2 КБ сверху, пять плоскостей сдвигов -10 КБ в MAIN. Четверкисливаются через OR, скалярный COL6PRE рисует постолбцам. Обычные и инверсные ядра разделены.8x8/Rotate: точный X с шагом два пикселя. Выровненныйглиф копируется целиком. При смещении движок вращаетглифы на лету, пишет по четыре байта за итерациюи читает экран только на краях текстового участка.8x8/Packed: готовые повороты глифов в 6 КиБ памяти MAIN.8x8/Fast: раздельные части глифов в 12 КиБ памяти MAIN.Оба используют ещё 2 КиБ исходного шрифта в верхнем слоте.4x8/Fast: шрифт CP/M Сябра. В каждом байте повтореныдва одинаковых полубайта. Пары дают полный байт безчтения экрана; одиночные символы сохраняют соседнийполубайт. Все восемь строк развернуты.У всех движков пять текстовых входов BIOS, инверсия,управляющие коды и физическое переключение KOI7/8.Управляющие коды и ESC обрабатывает BIOS. Raw рисуетих как глифы; RawZ заканчивается нулем, RawLim - длиной.Межстрочный шаг общий: 10 пикселей. Для 4x8 Xокругляется влево до границы знакоместа. NC подстраивает панели под ширину шрифта.Другим программам может понадобиться адаптация.Память------Движок и шрифт занимают слот D800-EC7F, ниже F000.Тела движков занимают 5120 байт с выравниванием.Временный Init*.dll не резидентен.Движок       MAIN, байт  memTop без иных резерваций6x8/Rotate           0   8BFF6x8/Packed        4096   7BFF6x8/Fast         10240   63FF8x8/Rotate           0   8BFF8x8/Packed        6144   73FF8x8/Fast         12288   5BFF4x8/Fast             0   8BFFFONT меняет резервацию через MEM. После его выходаNC перечитывает memTop и меняет емкость каталогов.STD-программы могут игнорировать memTop: совместимостьс таблицами MAIN проверяется для каждой программы.Исторические замеры FontBen, мс-------------------------------FontBen, Emu80, CPU и ВИ53 2 МГц, 2026-11-13; Fast8: 2026-11-14.MAIN, прямой BIOS ABI, обычный цвет, без подготовки.Один корпус README: 24 строки по 46 символов + CRLF,1152 байтов. StringZ обрабатывает CRLF, RawLim рисуетих глифы. При разной ширине площадь вывода разная.Это эмуляторный замер, не физическое оборудование.Движок         StringZ     RawLimRotate         398.208    352.384Compact        654.336    628.096Packed6K       289.152    235.648Fast12K        242.048    187.392Fast8          181.248    158.848Cpm4           172.288    139.136Обычные и инверсные ядра раздельны во всех модулях.В обычном пиксельном цикле нет проверки инверсиии пустых XOR/NOP. Cpm4 обрабатывает пары через стек;Fast8 держит указатели в регистрах. Счётчик пакета8-битный, курсор обновляется после пакета.FontBen и установленные движки используют общий код.KOI7/8: штатный bios_setFontEncoding, A=0 для KOI8,A<>0 для KOI7; регистры сохраняются. Переставляютсябитмапы и пререндер, у Compact - индексы. В горячемцикле нет перекодирования. Повторный выбор безопасен.Файлы и импорт--------------.fnt - готовый движок со встроенным шрифтом..dll - временный инициализатор Init*.dll..pf  - плоский шрифт, 256 глифов по 8 байт..pre - готовые таблицы для MAIN.FONT 6x8/Fast -FILEчитает готовый .pre вместо генерации. Без -FILEтаблицы строит временный инициализатор.FONT 8x8/Rotate -IMPORT A:/MyFont.pfимпортирует 2048 байт и устанавливает результат.Для Cpm4 используются младшие 4 бита каждой строки.Новый комплект сохраняется на доступный RAM-диск,обычно B:. Явное назначение: -OUT B:/Custom.fnt.Инициализатор сохраняется рядом; .pre - если нужен.Если RAM-диска нет, шрифт установлен, но не сохранен.При ошибке записи могут остаться частичные файлы.Пример загрузки сохраненного комплекта:  FONT B:/Custom.fnt -FILEBootstrap загружает выбранный сборщиком модуль безнижних таблиц; по умолчанию 6x8/Rotate. Вариантыс пререндером устанавливаются после старта DOS.В Raw-выводе Tab (09h) рисуется стрелкой со стенкой->|.
