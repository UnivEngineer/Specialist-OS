ДРАЙВЕРЫ НАКОПИТЕЛЕЙ MXOSЧисла в именах задают максимальную ёмкость накопителя.AT512KS.COM - системная flash, диск A: Чип на плате,отображённый в память CPU. AT29C010A: 128 КиБ; AT29C020: 256КиБ; AT29C040A: 512 КиБ. Размер и страница записи определяютсяпо ID. Чтение, запись и запись с проверкой. Драйвер явнозапускается первой командой AUTOEXEC.BAT. До этого работаетвстроенный ROM-Sys только для чтения. Если ID не распознан,остаётся встроенное чтение ROM.AT2MX.COM - драйвер для платы ROM/Flash диска Специалист-MMX,подключающегося через порт программатора ВВ 55 с адреснойзащёлкой ИР22. Назначается на диск H:. От 1 до 4 AT29C040Aпо 512 КиБ, всего до 2 МиБ. Последовательная запись с ожиданиемготовности. Есть чтение и запись с проверкой. Число чиповопределяется по ID.AT2MXF.COM - конвейерная версия AT2MX.COM. Программированиеразных чипов перекрывается во времени. Драйвер поддерживаетFLUSH для завершения незаконченных записей. DOS вызывает егопри завершении файловых операций и перед заменой драйвера.Один чип не даёт параллелизма, четыре - дают. Файлы читаютсяобоими драйверами независимо от распределения кластеров.ROM2M.COM - драйвер для той же платы MMX ROM/Flash-диска толькодля чтения. Размер готового FAT-тома берётся из BPB, до 2 МиБ.Определения чипов и записи нет. Чипы по 512 КиБ должны стоятьподряд с первого гнезда. Пустые промежуточные гнёзда непропускаются. Можно установить вместо AT2MX/AT2MXF, сохранивчтение H: и потеряв запись.ROM64K.COM - классическая плата ROM-диска через ВВ55 безадресных защёлок. ВВ55 порт A: данные; B: A0-A7; C: A8-A15.До 64 КиБ, только чтение. Подходит и для 32-КиБ чипа, еслиFAT-образ и BPB рассчитаны на 32 КиБ. Ёмкость берётся из BPB,аппаратно не определяется.RAMDISK.COM - подготовка RAM-диска B:. Выделяет банки ДОЗУчерез менеджер памяти DOS. Банк DOS не входит в B:.Форматирование выполняется только при первоначальной подготовкенеразмеченной памяти. Параметр -P 4 выделяет четыре банка по64 КБ; размер уже готового тома автоматически не меняется.Примеры запуска из NC/CLI:A:\DRIVERS\AT2MX.COMA:\DRIVERS\AT2MXF.COMA:\DRIVERS\ROM2M.COMA:\DRIVERS\ROM64K.COMA:\DRIVERS\RAMDISK.COM -P 4Можно открыть DRIVERS в NC и нажать Enter на нужном COM.Установка не требует RUN. Драйверы H: заменяют друг друга; A:и B: обслуживаются независимо. Сведения о текущем драйвере,технологии и возможностях показывает информационная панель NC.ОГРАНИЧЕНИЯУстановка драйвера H: не форматирует носитель. Образ долженсоответствовать реальной ёмкости и разводке платы. Проверказаписи не заменяет резервную копию. Запись flash расходуетресурс микросхем.При неподдерживаемом или недоступном ID AT2MX/AT2MXF незаменяют установленный ROM-драйвер. Но ошибка команды сейчаспрекращает BAT: последовательность ROM2M, затем AT2MX ещё необеспечивает продолжения всех следующих команд AUTOEXEC.BAT.Flash-диск HardrwareMan, скорее всего, не поддерживаетсядрайверами AT2MX.COM и AT2MXF.COM. Возможно, для негопотребуется свой драйвер.RAMDISK.COM выделяет банки, готовит том B: и передаётих DOS. DLL и отдельный резидент больше не нужны.-P 4: четыре банка данных плюс банк DOS; из 16свободны 11. Reset сохраняет владение DOS и данные.Размер пула фиксирован до холодного старта.
