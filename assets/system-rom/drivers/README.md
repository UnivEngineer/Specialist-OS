# Драйверы накопителей

Одноразовые инициализаторы с флагом DRIVER исполняются в банке DOS. Сборщик измеряет каждую программу и прижимает её к исключающему концу арены D780h; фактический адрес находится в заголовке COM. После RET занятый интервал освобождается. DOS проверяет пересечения с DLL и активными службами, поэтому непересекающийся FILEOPS остаётся в кэше. Область 9000h–BFFFh отведена кэшу и рабочим буферам DOS; это не экран основной памяти.

В системном образе все устанавливаемые драйверы находятся в одном каталоге `C:\DRIVERS`. Файл `README.TXT` рядом с ними хранится в KOI8-R с переводами строк CR для просмотра на «Специалисте»; его не следует перекодировать в UTF-8. Этот README — документация исходного комплекта, а не дополнительный файл образа.

| Файл в образе | Исходник | Назначение |
|---|---|---|
| AT512KS.COM | source/flash/FlashSys.asm | Системная flash C:, отображение в память, AT29C010A/C020/C040A на 128/256/512 КиБ |
| AT2MX.COM | source/flash/Flash.asm | Внешняя MMX-плата H:, 1–4 AT29C040A по 512 КиБ, последовательная запись |
| AT2MXF.COM | source/flash/FlashFst.asm | Та же MMX-плата, конвейерная запись по чипам |
| ROM2M.COM | source/flash/Rom.asm | MMX-плата H: только для чтения, размер готового тома из BPB, до 2 МиБ |
| ROM64K.COM | source/flash/Rom64.asm | Плата без защёлок: PB=A0–A7, PC=A8–A15, до 64 КиБ; допускается том 32 КиБ |
| RAMDISK.COM | source/ramdisk/RAMDISK.asm | Одноразовый установщик B:, подготовка фиксированного пула и передача DOS |

Имена исходников и выходных CPU/I80 в bin сохранены; новые имена COM назначаются манифестом C-System.txt. Старые копии COM в корень образа не добавляются. Из NC драйвер запускается по Enter на файле либо полным путём из командной строки. Информация о технологии и возможностях доступна в информационной панели NC. Числа в именах обозначают верхний предел ёмкости, а не обязательный объём носителя.

AT512KS определяет ёмкость и размер страницы записи по software ID чипа. AT2MX и AT2MXF определяют установленные AT29C040A и поддерживают чтение, запись и запись с проверкой. AT2MXF распределяет незавершённые операции по чипам; FAT-цепочки и формат образа совместимы с AT2MX. При одном чипе аппаратного параллелизма нет. Неподдерживаемый или недоступный ID отклоняется до замены прежнего драйвера.

ROM2M и ROM64K не выполняют идентификацию, программирование или форматирование. Они читают готовый том MXOS, получают его размер из BPB и запрещают запись. ROM2M предполагает непрерывную установку 512-КиБ чипов с первого гнезда; промежуточные пустые гнёзда не пропускаются.

Все внешние драйверы загружаются только явными командами AUTOEXEC.BAT. До его запуска C: обслуживает встроенный ROM-Sys только для чтения; BIOS не содержит имён файлов устанавливаемых драйверов. В flash-профилях после PATH в AUTOEXEC запускается `C:\DRIVERS\AT512KS.COM`, затем драйвер H:, FLOPPY и RAMDISK. После аппаратного Reset AUTOEXEC выполняется заново, поскольку BIOS восстановил встроенный драйвер C:. Готовый B: сохраняется и не форматируется повторно. AT2MX, AT2MXF, ROM2M и ROM64K заменяют службу H:; замена не форматирует том. RAMDISK — отдельный установщик B:, параметр `-P 4` выбирает четыре банка при первоначальной подготовке. Текущие команды приведены в README.TXT.

AT2MH.COM и AT2MHF.COM для платы HardwareMan пока не реализованы и в образ не включаются. Опубликованная схема отличается регистром 74ALS374 и обозначением чипов AT29C040 без A; существующие MMX-драйверы не объявляются совместимыми с ней.

RAMDISK.COM — одноразовый установщик с флагом DRIVER, исполняемый в банке DOS с адреса, подобранного сборщиком вплотную к концу арены. Он резервирует фиксированный пул через RAMLIMIT, монтирует готовый том либо размечает новую память через FORMAT, затем передаёт пул самой DOS через MEMORY/RAMDISK COMMIT. DLL, модульный handle и отдельный резидент не создаются; после RET область установщика доступна другим драйверам. RAMDISK.COM -P 4 резервирует четыре банка данных; вместе с банком DOS заняты пять из шестнадцати, одиннадцать остаются свободны. Дополнительный банк кода и резидентный слот DOS не требуются. Пул и содержимое B: сохраняются при тёплом Reset. Размер закреплённого пула фиксирован до холодного старта; динамических SHRINK/GROW и сжатия нет.
По умолчанию используются C: для системного ROM/flash, A: для дисковода, B: для RAM-диска и H: для внешнего ROM/flash. В AUTOEXEC параметр `-LETTER` задаётся явно. Системный накопитель привязан к загрузочному C:. RAMDISK допускает B: или D: при первой установке. FLOPPY и внешние драйверы принимают A:–H: с учётом занятых букв. Повторная установка допускается на той же букве. Для изменения занятой буквы задайте её в AUTOEXEC и перезапустите систему.

Для RAMDISK указывайте `-LETTER` перед `-P`.
