# Входные данные системного ROM

В этом каталоге находятся негенерируемые входные файлы системного и flash- образов: шаблоны загрузочных секторов, AUTOEXEC/FORMAT, NC.EXT и шрифты.

Собираемые бинарники DOS и системных программ берутся из каталога `bin` согласно `scripts/images/manifests/A-System.txt`.

Первичную подготовку B: выполняет RAMDISK.COM из AUTOEXEC: готовый том сохраняется, для неразмеченной памяти вызывается `A:\FORMAT.COM B: -R -Y`. FORMAT.BAT исключён из штатного манифеста и больше не запускается BIOS. Файл сценария сохранён как прежний ручной пример. Диск задаётся с двоеточием, `-R` включает особенности RAM-диска, `-Y` отключает запрос подтверждения. Без буквы диска FORMAT спрашивает её; без `-Y` сохраняется подтверждение. Системный A: форматировать запрещено при любых ключах.

NC.EXT передаёт RKS и EXE в `A:RUN.COM`; COM исполняется DOS. В образе COM/EXE имеют общий 16-байтный заголовок, RKS хранится со своим стандартным заголовком и суммой. Сменные ядра — `MONITOR2.MON` и `RAMFOS.MON`, SYS используется для DOS. Сырые бинарники и CPU/I80 служат входом сборщика, а не готовыми COM/EXE.
