# Входные данные системного ROM

В этом каталоге находятся негенерируемые входные файлы системного и flash-
образов: шаблоны загрузочных секторов, AUTOEXEC/FORMAT, NC.EXT и шрифты.

Собираемые бинарники DOS и системных программ берутся из каталога `bin`
согласно `scripts/images/manifests/A-System.txt`.

В `FORMAT.BAT` используется общий стиль аргументов:
`A:FORMAT.COM B: -R -Y`. Диск задаётся с двоеточием, `-R` включает
особенности RAM-диска, `-Y` отключает запрос подтверждения. Порядок диска
и ключей свободный, регистр не важен. Без буквы диска FORMAT спрашивает её;
без `-Y` сохраняется подтверждение. Старый синтаксис `B R Y` больше не используется.

NC.EXT передаёт RKS и EXE в `A:RUN.COM`; COM исполняется DOS. В образе COM/EXE имеют общий 16-байтный заголовок, RKS хранится со своим стандартным заголовком и суммой. Сменные ядра — `MONITOR2.MON` и `RAMFOS.MON`, SYS используется для DOS. Сырые бинарники и CPU/I80 служат входом сборщика, а не готовыми COM/EXE.
