# Входные данные системного ROM

В этом каталоге находятся негенерируемые входные файлы системного и flash-
образов: шаблоны boot sector, AUTOEXEC/FORMAT, NC.EXT и шрифты.

Собираемые бинарники DOS и системных программ берутся непосредственно из
каталогов исходников согласно `scripts/images/manifests/system.csv`.
