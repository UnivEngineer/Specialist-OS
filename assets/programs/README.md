# Внешние программы

Здесь хранятся программы и тесты, которые не собираются из исходников данного
репозитория.

`catalog.csv` сохраняет адрес загрузки, исходное имя и статус проверки.
Статус `included` означает включение в системный ROM, а `unverified` — что
работоспособность файла ещё не подтверждена.
