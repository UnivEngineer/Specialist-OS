# Коллекция движков FontLab

Все standalone-реализации сохраняются в бенчмарке независимо от того, какие из них будут перенесены в BIOS. Их машинный код исполняется в main через временно заменённые входы BIOS и таблицу MXOS_CALL. Они используют согласованные координаты/шрифт BIOS, но сами рисуют пиксели в экран. Подмена действует только во время этапа; после замера исходные адреса восстанавливаются.

| Исходник | Движок |
|---|---|
| monitor.inc | Самостоятельная копия штатного пиксельного ядра 6×8, адресации глифов и normal/inverse из BIOS. Печатный корпус обрабатывается локально; управляющие коды вне корпуса передаются штатному BIOS. Это имя движка теста, не загрузка ядра Monitor-2. |
| OPT_DRAW.asm | Оптимизированная замена пиксельной части monitor, с развёрнутыми циклами; меняется только локальный вход копии |
| SHIFT.asm | Посимвольный пререндер 12 КБ |
| legacy.inc | Пакетные входы monitor, пререндера и кеша; регистры сохраняются один раз на пакет |
| cache.inc | Ограниченный кеш с генерацией требуемых сдвигов |
| quad.inc | Четвёрки с пререндером/кешем |
| quad-direct.inc | Четвёрки с вращениями на лету и половинным пререндером |
| quad-packed.inc | Упакованный FONTKOI |
| aligned8.inc | Выровненный 8×8 |
| paged.inc | Построчный полный шрифт; сборка FontMap.com добавляет перекодировку восьмибайтной таблицей блоков при чтении четвёрки |
| block32.inc, block32-support.inc | Компактный 160-глифовый 6×8, таблица из восьми страниц; отдельная сборка FontBlk.com |
| font4.inc | Три формата 4×8, пакетный вывод парами |
| kernel-api.inc | Отдельная группа системных движков: только публичные MXOS_CALL PRINT_CHAR, PRINT_CHAR_REAL, PRINT_STRING_BANK/MAIN |

Monitor содержит копию исходного кода, а не INCLUDE файлов BIOS. В standalone нет скрытого автоматического перевода на новые системные ядра. Новое системное ядро добавляется отдельным API-входом и строками CASE; оно не заменяет одноимённую экспериментальную реализацию.
