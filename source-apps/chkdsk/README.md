# CHKDSK.COM

Диагностика текущего FAT16-подобного формата MXOS, без исправлений и записи на диск.
Запуск: `A:CHKDSK.COM B:`. Без аргумента программа спрашивает букву A–H: штатный ввод отображает
символ, выбор подтверждается Enter.
После результата выводится `Press any key to exit`; любая клавиша через
`bios_getch` возвращает в NC.

Первый проход проверяет BPB и границы FAT/корня/данных, зарезервированные
FAT[0]/FAT[1], дубликаты имён, номера и длины цепочек, свободные/плохие
ячейки внутри цепочки, циклы, пересечения файлов и потерянные кластеры.
Для повреждённой цепочки печатается имя, для потерянного кластера — его номер.
Подкаталоги и LFN считаются неподдерживаемыми записями; утилита их не обходит.

Только при отсутствии ошибок структуры второй проход проверяет встроенные суммы:

- простой RKS: два адреса little-endian, нагрузка, двухбайтовая сумма;
- MXEX v1 с префиксом `CD 20 MXEX`: сумма 64-байтного заголовка с обнулённым
  полем суммы и отдельная сумма образа. Проверяются версия, размер заголовка
  и согласованность длины файла; это не проверка возможности запуска программы.

Используется существующий `bios_calcCS`; большие файлы проверяются порциями
по 256 байт с объединением состояния исторической суммы. Весь файл в ОЗУ
не загружается. Объём BSS в MXEX в сумму не входит.

COM/SYS/MON и старые сырые EXE без встроенной суммы получают `NO STORED CS`.
Никакая вычисленная сумма без эталона не объявляется успешной проверкой.
Исторический сборщик мог удалить контейнер и сумму RKS: такой payload обычно
тоже получает `NO STORED CS`. Для формата без magic контейнер распознаётся по
расширению RKS и точному соответствию адресов и длины. Усечённый контейнер
без иных признаков нельзя надёжно отличить от исторического сырого payload.
Файла внешних эталонных сумм нет.

## Поддерживаемая геометрия

Сектор и кластер 256 байт, одна FAT, 16..8192 секторов (до 2 МиБ),
до 64 секторов FAT и до 256 записей корня. Корень кратен восьми записям.
Сохраняются текущие соглашения MXOS: размер N−1, FFh как свободная запись,
самоссылка в конце цепочки; также распознаётся EOC FFF8h..FFFFh. FFF7h — bad.
Пустая запись каталога не означает пустой файл: первый кластер 0 у обычного
файла считается ошибкой текущего формата. Стандартные FAT12/16/32 здесь
не реализованы. Формат тома и файловые функции DOS не изменены.

Утилита не вызывает файловые операции, не использует и не изменяет кэш DOS.
Перед запуском не должно быть других операций с томом. Геометрия дополнительно
сопоставляется с размером, который сообщает установленный физический драйвер;
у некоторых драйверов этот размер сам берётся из BPB.

## Память и сборка

Код загружается по 0000h и занимает менее 2000h. Имена — 2000h..2AFFh,
FAT — 4000h..7FFFh, карта занятости — 8000h..83FFh, секторные буферы и
заголовок — 8400h..8A3Fh, стек начинается с 8FDFh. Системная область не
используется для собственных данных. Достаточно базовых 36 КБ ОЗУ.

Из этого каталога:

```powershell
../../scripts/build/build-if-needed.ps1 CHKDSK com 0
```

Входит в `build: OS`, результат `bin/CHKDSK.com`, в системный манифест добавлен
`CHKDSK.COM`. Тест с записью только в RAM изолированного Emu80:

```powershell
python source-apps/chkdsk/check-emulator.py --runtime D:/Projects/RetroPC/Specialist/Emulator/Emu80-flash-test
python source-apps/chkdsk/check-interface.py --runtime D:/Projects/RetroPC/Specialist/Emulator/Emu80-flash-test
```
