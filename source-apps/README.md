# Прикладные программы

Здесь находятся исходники самостоятельных приложений. Системные компоненты
MXOS остаются в `source/`, игровые оригиналы и распространяемые варианты —
в `assets/games/`, результаты сборки — в `bin/`.

- [Алмаз-2](almaz2/README.md): восстановленный исходник Intel 8080,
  чёрно-белая и цветная графика, программный звук и ВИ53, ABI MXOS и Ramfos.

Задача VS Code `build: apps` собирает приложения; `build: all` также включает
эту задачу. Сборка приложений не запускает эмулятор.
