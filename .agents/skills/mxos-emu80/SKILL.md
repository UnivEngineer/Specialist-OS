# Проверка в Emu80

Тестовый экземпляр должен быть **видимым и без звука**. Запускай собственный Emu80 из локальной рабочей копии. `run.ps1 -Mcp` выключает звук, для обычного EXE используй `-Mute`. Проверь ВИ53 и мониторинг ленты. После запуска можно сразу включить фиксированную скорость **32×**: в окне своего Emu80 нажимай **Alt+PgUp** (Speed up) до 32× в строке состояния. В MCP текущей версии `sys_info` показывает `cpu.speed_factor` и `cpu.full_throttle`. **Full throttle пока не используй** из-за ошибки эмуляции таймера.

## Собственный MCP-слот

1. Выбирай свободный loopback-порт 19781–19796. При ручной работе проверь занятость через `Get-NetTCPConnection`, PID и путь EXE. Для одной машины используй `with lease(size=8) as slot` из `scripts/emu80/mcp_pool.py`. В игровой очереди используй `WorkerMachine.start` для каждого холодного старта и `close` в конце работы. Между играми сохраняются PID и видимое окно, аппаратный Reset используется при проверке возврата. Размер пула настраивается от 1 до 16. [Сборка и проверка пула](../../../scripts/emu80/README.md#пул-видимых-mcp-экземпляров).
2. Аренда держит файловую блокировку до конца пробы, готовит свой runtime, свежие копии A:/C:/H:, отдельные настройки и журнал, сверяет PID, путь EXE и порт. Направляй команды только на `slot.url`. При обрыве связи выйди из контекста аренды и повтори пробу с чистого старта. Контекст и повторная выдача после сбоя обслуживают только собственные процессы.
3. Для отдельного установленного слота используй `scripts/emu80/run-mcp-slot.ps1 -Port <порт>` и сверяй PID listener. Для новой сборки порт выбирает `run.ps1 -Flash -Mcp -McpPort <порт> -EmulatorDirectory <runtime>`. У прежних EXE порт зафиксирован при компиляции. Закрой свой вручную запущенный экземпляр в finally, если пользователь не попросил его оставить.
4. В новой сборке можно менять скорость своего процесса через `emu_speed(factor=32)`. Для оценки звука поставь 1× и получи до двух секунд PCM с источника платы с помощью `mx_audio(action="start")` и `mx_audio(action="stop")`. Во время записи оставь выход на динамики выключенным.

Для командной строки и запуска из NC обязательна [проверка через клавиатуру](references/nc-keyboard.md). Прямой `bios_fileExec` годится для отдельного теста ABI. Для подготовки образов, установки runtime и различий между обновлением C: и заменой C:/H: используй [профили запуска](../../../scripts/emu80/README.md#сборка-и-запуск-flash-профиля). Тестовые образы заменяются согласно выбранному профилю без резервных копий.

Зафиксируй, какие операции действительно проверены. Загрузка ОС подтверждает только загрузку. Аппаратные тайминги, flash-запись, ВИ53, теневое ПЗУ и переключение страниц на физической машине требуют отдельной проверки.
